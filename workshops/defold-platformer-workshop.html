Player Movement
Run and jump with physics
Locked
🎯
Goal for this step

Make the player run left/right and jump using physics forces.

📜 player.script — Movement
function init(self) self.run_speed = 300 self.jump_impulse = 700 self.grounded = false self.move_input = 0 end function update(self, dt) -- Apply horizontal velocity local vel = go.get(go.get_id(), "velocity") vel.x = self.move_input * self.run_speed -- Only allow jump if grounded if self.do_jump and self.grounded then vel.y = self.jump_impulse self.do_jump = false self.grounded = false end go.set(go.get_id(), "velocity", vel) end function on_input(self, action_id, action) if action_id == hash("right") then self.move_input = action.value elseif action_id == hash("left") then self.move_input = -action.value elseif action_id == hash("jump") and action.pressed then self.do_jump = true end end
💡
go.get() and go.set() access physics properties like velocity directly. This is more efficient than moving position manually.

📜 Animation State Machine
function update_animation(self) local vel = go.get(go.get_id(), "velocity") local anim = "idle" if math.abs(vel.x) > 10 then anim = "run" -- Flip sprite based on direction local flip = vel.x > 0 and 1 or -1 go.set(go.get_id(), "scale.x", flip) elseif not self.grounded then anim = vel.y > 0 and "jump" or "fall" end if anim ~= self.current_anim then self.current_anim = anim sprite.play_flipbook( go.get_id(), anim) end end
