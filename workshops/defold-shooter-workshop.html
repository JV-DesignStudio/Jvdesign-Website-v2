Player Ship Movement
Move the ship left, right and forward
Active
🎯
Goal for this step

Create a player ship that moves left/right with A/D and forward with W.

📜 player.script — Ship Movement
function init(self) self.speed = 300 self.move_dir = vmath.vector3(0, 0, 0) self.bounds_x = 480 self.bounds_y = 300 end function update(self, dt) local pos = go.get_position() pos = pos + self.move_dir * self.speed * dt -- Clamp to screen bounds pos.x = math.max(-self.bounds_x, math.min(self.bounds_x, pos.x)) pos.y = math.max(-self.bounds_y, math.min(self.bounds_y, pos.y)) go.set_position(pos) end function on_input(self, action_id, action) self.move_dir = vmath.vector3(0, 0, 0) if action_id == hash("right") then self.move_dir.x = 1 elseif action_id == hash("left") then self.move_dir.x = -1 elseif action_id == hash("up") then self.move_dir.y = 1 elseif action_id == hash("down") then self.move_dir.y = -1 end end

Factory Spawning
Dynamically create bullets with factories
Locked
🎯
Goal for this step

Use Defold's factory component to spawn bullet game objects when the player shoots.

  • 1Create a "bullet.collection" with a sprite and script. This is your bullet prefab.
  • 2Add a Factory component to the player game object pointing to bullet.collection.
  • 3Use factory.create() to spawn bullets dynamically:
📜 player.script — Shooting
function init(self) self.shoot_timer = 0 self.shoot_delay = 0.15 -- seconds between shots end function update(self, dt) self.shoot_timer = self.shoot_timer - dt end function on_input(self, action_id, action) if action_id == hash("shoot") and action.pressed then if self.shoot_timer <= 0 then self.shoot_timer = self.shoot_delay local pos = go.get_position() -- Spawn bullet at ship position factory.create( hash("/player#bullet_factory"), vmath.vector3(pos.x, pos.y + 30, 0) ) end end end
💡
factory.create() spawns a new instance of a collection. The factory component must be attached to the game object that calls it.

Enemy Spawning
Create enemies that appear in waves
Locked
🎯
Goal for this step

Spawn enemies in waves with increasing difficulty using a wave system.

📜 spawner.script — Wave System
function init(self) self.wave = 1 self.enemies_per_wave = 5 self.spawn_timer = 0 self.spawn_interval = 1.0 self.spawned = 0 end function update(self, dt) self.spawn_timer = self.spawn_timer + dt if self.spawn_timer >= self.spawn_interval and self.spawned < self.enemies_per_wave then self.spawn_timer = 0 self.spawned = self.spawned + 1 -- Random x position at top of screen local x = math.random(-400, 400) factory.create( hash("/spawner#enemy_factory"), vmath.vector3(x, 380, 0) ) end -- Start next wave when all enemies spawned if self.spawned >= self.enemies_per_wave then self.wave = self.wave + 1 self.spawned = 0 self.enemies_per_wave = self.enemies_per_wave + 2 self.spawn_interval = self.spawn_interval * 0.9 end end

Power-ups
Collect power-ups for temporary abilities
Locked
🎯
Goal for this step

Create power-up items that fall from destroyed enemies and give the player temporary abilities.

📜 powerup.script
function init(self) self.speed = 150 self.type = "spread" -- or "speed", "shield" end function update(self, dt) local pos = go.get_position() pos.y = pos.y - self.speed * dt if pos.y < -400 then go.delete() end go.set_position(pos) end function on_message(self, message_id, message, sender) if message_id == hash("contact_point_response") then if message.other_group == hash("player") then msg.post("/player", "activate_powerup", { type = self.type }) go.delete() end end end

Particle Effects
Add explosions and thruster effects
Locked
🎯
Goal for this step

Create particle effects for explosions when enemies are destroyed and engine trails.

📄 Particle Effect Configuration
-- Defold particle effects are configured in .particlefx files -- Key properties: -- rate: particles per second -- lifetime: how long each particle lives -- spread: random angle variation -- size: start/end size -- color: start/end colour (for fade effects)
  • 1Create a "explosion.particlefx" file in Defold.
  • 2Set emitter rate to 50, lifetime to 0.5, spread to 360 degrees.
  • 3Animate from bright orange to transparent for a fire effect.
  • 4Play it when an enemy is destroyed:
📜 Playing Particle Effects
-- In the enemy script on death: particlefx.play( go.get_id(), hash("explosion") )
