Open GDevelop & Start a New Project
Download GDevelop and create your first blank project
Active
🎯
Goal for this step

Get GDevelop open on your computer with a blank project ready to build in.

👨‍👧
Parent note: GDevelop is a free desktop app you download and install. Go to gdevelop.io and click Download. It works on Windows, Mac and Linux. No account needed to start building!

Get started

  • 1Go to gdevelop.io and click the Download button for your operating system.
  • 2Run the installer and follow the prompts. Open GDevelop when it's done.
  • 3Click "Create a new project". Choose "Start from a blank project".
  • 4Name your project "Pong Game" and click Create.
  • 5You'll see the Scene Editor in the middle (where you place objects) and the Events Sheet tab at the top (where you build game logic).
💡
GDevelop has two main areas: the Scene Editor where you place objects visually, and the Events Sheet where you tell the game what to do. We'll use both!

Add Paddle Objects
Create two paddles one for each player
Locked
🎯
Goal for this step

Add two paddle objects to the scene, one on the left and one on the right.

Create the paddle objects

  • 1In the Objects panel (right side), click "Add an object".
  • 2Choose "Sprite" as the object type. Name it "LeftPaddle".
  • 3Click "Edit the object" then "Add an animation". Click "Import from file" and choose a simple rectangle image, or click "Paint" to draw a tall thin rectangle (about 20 pixels wide, 100 pixels tall) in a bright colour.
  • 4Close the animation editor. Drag the LeftPaddle to the left side of the scene, about 30 pixels from the edge.
  • 5Right-click LeftPaddle in the Objects panel and choose "Duplicate". Rename it "RightPaddle". Drag it to the right side of the scene.
💡
In GDevelop, objects are templates. You can place multiple copies (instances) of the same object on the scene. Each paddle is one instance of a paddle object.

Make the Paddles Move
Add keyboard controls so players can move the paddles
Locked
🎯
Goal for this step

Use the Events Sheet to make paddles move up and down when keys are pressed.

👨‍👧
Parent note: In GDevelop, you build game logic on the Events Sheet. Each event has Conditions (when something is true) and Actions (what happens). Think of it like: "WHEN this happens, DO this."

Open the Events Sheet

  • 1Click the "Events" tab at the top of the editor to switch to the Events Sheet.
  • 2Click "Add an event" at the bottom. A new empty event row appears.
  • 3Click "Add condition" on the left side of the event. Search for "Key pressed" and select it.
  • 4In the key dropdown, choose "Up". This event now triggers when the Up key is held down.
  • 5Click "Add action" on the right side. Search for "Change the Y position" of an object.
  • 6Choose LeftPaddle as the object. Set the modification sign to "Add" and value to -5. (Negative Y = up in GDevelop.)
  • 7Repeat for Down key: add another event with condition "Key pressed: Down" and action "Change Y position of LeftPaddle, Add, 5".
💡
In GDevelop, Y goes up when negative and down when positive (opposite of what you might expect!). So -5 moves up, +5 moves down.

Your events should look like this:

🎮 Events Sheet — Left Paddle Movement
Condition: Key pressed: Up Action: Change LeftPaddle Y position: Add -5 Condition: Key pressed: Down Action: Change LeftPaddle Y position: Add 5

Add the Ball
Create a ball object that bounces around the screen
Locked
🎯
Goal for this step

Add a ball object and use a behavior to make it bounce off walls and paddles.

Add the ball object

  • 1Click "Add an object" in the Objects panel. Choose "Sprite", name it "Ball".
  • 2Edit the object, add an animation, and import or paint a small circle (about 20x20 pixels) in white or yellow.
  • 3Drag the ball to the centre of the scene.
  • 4With the Ball selected, click "Edit object behaviors" in the Properties panel.
  • 5Click "Add a behavior" and choose "Bounce on edges". This makes the ball bounce off the screen borders automatically!
  • 6Also add the "Platformer character" behavior? No we don't need that. Just "Bounce on edges" is enough for now.
💡
Behaviors in GDevelop are pre-built features you attach to objects. "Bounce on edges" handles all the wall-bouncing logic for you, no events needed!

Give the Ball Speed & Bounce Off Paddles
Set the ball moving and make it bounce off the paddles
Locked
🎯
Goal for this step

Make the ball start moving when the game begins and bounce off paddles when it hits them.

Set the ball moving

  • 1Switch to the Events Sheet. Click "Add a new event".
  • 2Add a condition: "At the beginning of the scene". This event runs once when the game starts.
  • 3Add an action: "Add a force" to Ball. Set X to 200 and Y to 150. This launches the ball diagonally.
  • 4Add a new event. Condition: "Collision" between Ball and LeftPaddle.
  • 5Action: "Bounce the object" on Ball. This makes it bounce back when it hits the left paddle.
  • 6Duplicate that event. Change the collision to Ball and RightPaddle.
🎮 Events — Ball Launch & Paddle Bounce
Condition: At the beginning of the scene Action: Add a force to Ball: X = 200, Y = 150 Condition: Ball is colliding with LeftPaddle Action: Bounce Ball Condition: Ball is colliding with RightPaddle Action: Bounce Ball

Add Score & Win Condition
Track points and detect when someone scores
Locked
🎯
Goal for this step

Create score variables and add events to detect when the ball passes a paddle.

Create score variables

  • 1In the Events Sheet, click "Project Manager" (hamburger menu, top left). Go to Variables → Scene variables.
  • 2Create a variable called LeftScore and set it to 0.
  • 3Create another called RightScore and set it to 0.
  • 4Add a new event. Condition: "X position of Ball" is < -400 (ball went past the left edge).
  • 5Actions: "Change variable RightScore, add 1". Then "Change the position of Ball" to X: 0, Y: 0 (reset to centre).
  • 6Add another event for the right side: Condition: "X position of Ball" is > 400. Actions: "Change variable LeftScore, add 1" and reset ball position.
💡
To show scores on screen, add two "Text" objects to the scene (one for each score). Then add events that set the text to the variable value every frame.

Test, Polish & Play!
Run the game and enjoy your first GDevelop creation
Locked
🎯
Goal for this step

Test the full game, add a background and make sure everything works properly.

Test your game

  • 1Click the Play button (green triangle) at the top to launch the game.
  • 2Test that both paddles move correctly with their keys.
  • 3Watch the ball bounce off walls and paddles. Does it behave correctly?
  • 4Check that scores update when the ball passes a paddle.
  • 5Go back to the Scene Editor. Right-click the background and choose "Change the background color" to something dark.
  • 6Try changing the ball's starting force values to make it faster or slower. Have fun!
