Questions & Answers

Do I need to know coding?
No. MUGEN is built from editable text files and assets. We explain the structure and walk through every edit , it is modding, not heavy programming.
Is MUGEN really free?
Yes. MUGEN is free software by Elecbyte, supported by a large fan community. Stick to well-known community sites for downloads.
What will I build?
You will install MUGEN, add fighters and stages, edit character stats, program fighter AI, design a stage, and package a complete game with a custom screenpack, roster, boss and lifebars.
Does it work on Mac?
MUGEN is Windows-native, but Mac and Linux users can run it through Wine. The workshops focus on the Windows version.
Can I share the game I make?
Yes. Because MUGEN is portable, you zip the whole folder and share it. Episode 5 covers packaging and crediting the content creators you include.
Is it really free?
All 5 episodes, forever. No ads, no paywall, no sign-up needed.
