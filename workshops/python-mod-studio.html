Python Mod Studio
Build a Pygame project in your browser

A little project maker for the Python World Workshop. Lay out a platformer level on a grid, tick the Pygame features you want, read a broken traceback and choose the fix, then download a real Pygame project you can run on any computer with Python.

🛠️ Open the Studio ← Back to the Python World Workshop
Make your own art and sounds: draw sprites in Pixel Studio and make music or sound effects in Sound Studio, then bring them into your project.
Ember says: a game in Python is just a loop that draws the screen again and again. This studio writes the whole main.py for you, using the level you build, so you can run it and see it move. Your work saves automatically.

Lay out your level

Pick an object below, then click squares on the grid to place it. Put the Player where you start and the Goal at the end. Click a square again, or use the eraser, to remove it.

Objects

Your level so far

Each object becomes a pygame.Rect in your code. The mini map below shows a bird's eye view of where they sit on screen.

What is in the level

    Add features

    Each feature folds a chunk of working Python into your game. Tick the ones you want. Keep Move the player on so you can get around, and Coins add score for a goal to chase.

      How this maps to real Python
      
        
      
          
      main.py is your whole game: set up, a loop, and drawing.
      
          
      pygame.Rect is a rectangle. Each object you placed is one.
      
          
      The while loop runs about 60 times a second. That is what makes things move.
      
          
      Run it: install Python, then in a terminal run pip install pygame and python main.py.
