Echo's recovery check

Stuck? Try this

These are the three things that most often stop a first Python mod. Check the symptom first, then try the fix.

The mod does not load

What you'll see: the game ignores it.

Fix: Check the mod folder name and the manifest file match the game expected structure.

My changes are not in the game

What you'll see: the old behaviour remains.

Fix: Copy the edited files into the game mod folder and restart the game.

The game crashes after the mod

What you'll see: an error on launch.

Fix: Remove the mod, check the log for the first error, and add changes back one at a time.

Still stuck? Reread the step, open the Python cheat sheet, or try the Debug It challenge.

      How this maps to real Python
      
        
      
          
      main.py is your whole game: set up, a loop, and drawing.
