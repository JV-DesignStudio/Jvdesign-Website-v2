What Is a Tile Property?
The rules attached to a tile
Active
🎯
Goal for this step

Understand that a property is a named rule on a tile.

  • 1A property is a name and a value on a tile, like Passable = true.
  • 2The game reads these rules to decide if you can walk, dig or water there.
  • 3Properties live on the tileset, so one rule applies to every copy of that tile.
  • 4Change the rule on the tileset, and every tile that uses it changes at once. Powerful.

Passable: Walk or Wall
The most important rule of all
Locked
🎯
Goal for this step

Know how Passable decides walking.

  • 1Passable is true or false. True means the player and animals can walk on it.
  • 2False means it is a wall. The player bumps into it.
  • 3Most ground tiles are Passable true. Most objects and water are Passable false.
  • 4If the player is stuck or walking through a fence, Passable is the first thing to check.

Water, Diggable & Type
The other rules that shape play
Locked
🎯
Goal for this step

Meet the other rules you will use most.

  • 1Water true marks a tile as water, so you can refill a watering can or fish there.
  • 2Diggable true lets the player use a hoe to till and dig the tile.
  • 3Type names the tile, e.g. Grass, Dirt, Stone, Water. It helps tools and the game pick sounds and behaviour.
  • 4You rarely need more than these four: Passable, Water, Diggable, Type.

Edit a Property in Tiled
Click a tile, open Properties
Locked
🎯
Goal for this step

Find where tile properties are edited.

  • 1In Tiled, click a tile in the Tilesets panel so it is selected (not painted).
  • 2Open the Properties panel (View > Properties if hidden).
  • 3You will see the tile's existing rules, like Passable or Type.
  • 4If the properties are on the map's tileset reference, Tiled edits them there.
💡
If a tile shows no properties, it means the game uses a default for it. Add the rule you want and set a value.

Add a Wall Rule
Turn a tile into something solid
Locked
🎯
Goal for this step

Add Passable = false and save.

  • 1Select a tile you want to become solid.
  • 2Add a property named Passable, of type bool, set to false.
  • 3Save the map. Remember to save the tileset too if Tiled asks.
  • 4Because rules live on the tileset, every copy of that tile becomes solid at once.
A tile's properties (concept)
Passable   (bool)  = false
Water      (bool)  = false
Diggable   (bool)  = true
Type       (string) = "Dirt"

Test the Rules In-Game
Walk, dig, water and check
Locked
🎯
Goal for this step

Prove your rules work by testing them.

  • 1Load your save through SMAPI and walk onto the tile you made a wall. You should be blocked.
  • 2Try digging a Diggable tile with your hoe.
  • 3Try refilling your watering can at a Water tile.
  • 4If something is off, check the console and re-check the property values. True and false are easy to flip by accident.
