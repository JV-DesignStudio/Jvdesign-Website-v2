Minecraft Mod Studio
Build a datapack in your browser

A real little datapack maker for the Minecraft World Workshop: design a crafting recipe on a 3x3 bench, add a function of commands, write your pack and recipe files, debug a broken datapack log, then download a datapack you can drop straight into a world. It runs on a locked-down school computer with no install and no account.

🛠️ Open the Studio ← Back to the Workshop
Make your own art and sounds: draw sprites in Pixel Studio and make music or sound effects in Sound Studio, then bring them into your project, or build a 3D model to copy in Voxel Studio.
Ember says: a datapack is the friendliest Minecraft mod of all. It is just a folder of text files, and you never have to install a mod loader. This studio writes those files for you. Your work saves automatically.

Design a crafting recipe

Pick an ingredient below, then click squares in the 3x3 bench to place it. The recipe is always read exactly how you lay it out, so a sword shape stacks the two diamonds above the stick.

Build a function

        
A function is a list of commands Minecraft runs when you call it, one per line. Tick the ones you want, then run it in-game with /function. Start with give so you can hold the thing you just made.

✅ Ready check

        
A datapack only loads if all of these are true. The Studio fills most of them in for you.

        
    
        
    How this maps to the real game
    
        
    
          
    pack.mcmeta tells Minecraft this folder is a datapack and which version it is for.
    
          
    data/<namespace>/recipe/ is where crafting recipes live. Singular recipe in 1.21 and newer.
    
          
    data/<namespace>/function/ holds your .mcfunction files. Run one with /function <namespace>:<name>.
    
          
    Drop the folder into saves/<your world>/datapacks/, then type /reload.
    
        
    
      
    
    
    
  
    

  
  
    
    
    
      
    
        
    The game log
    
        
    
        
    Click the red line, then choose the fix. Plain lines are normal.
    
      
    
      
    
        
    What is the fix?
    
        
    
        
    
        
    
          
        
    
      
    
    
    
  
    

  
  
    
    
    
      
    
        
    Download your datapack
    
        
    This bundles everything into a real datapack folder and downloads it as a zip: pack.mcmeta, your recipe file and your function. Unzip it into saves/<your world>/datapacks/ and run /reload.
