Echo's Debug It

Debug It: The score that resets itself

In the fruit-catch game the score goes up when you catch an apple, then drops back to zero a moment later.

when green flag clicked
forever
  set [score v] to (0)
  if <touching [apple v]?> then
    change [score v] by (1)
  end
end
  1. What did you expect? Catching an apple adds one point and the score keeps growing.
  2. What happened instead? The score flickers to 1 and snaps back to 0, so it can never climb.
  3. What evidence tells you where the problem is? Tick the score variable so it shows on stage. Watch it for two seconds without catching anything: it is being set back to 0 by the loop.
Hint 1: a nudge

One of these blocks should run once at the start, not on every pass of the forever loop.

Hint 2: what to look for

The set score to 0 block sits inside the forever loop, so it runs about 30 times a second and wipes the score before you can see it. Resetting belongs outside the loop.

Full answer

Move set [score v] to (0) above the forever block so it runs once when the game starts. Keep only change [score v] by (1) inside the loop.

Try the hints before the answer. Finding the bug is the skill, the fix is the easy part.
