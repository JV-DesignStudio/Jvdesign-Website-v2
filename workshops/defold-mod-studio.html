Defold Mod Studio
Build a game project in your browser

A little project maker for the Defold series. Lay out a 2D scene on a grid, tick the Lua scripts you want, read a broken console log and choose the fix, then download a real Defold project you can open in the free Defold editor on any computer.

🛠️ Open the Studio ← Back to all workshops
🔥
Ember says: Defold is a free game engine, and the projects it uses are just text files. This studio writes those files for you: a game.project, a collection and your Lua scripts. Your work saves automatically.

Lay out your scene

Pick an object below, then click squares on the grid to place it. Put the Player where you start and a Goal at the end. Click a square again, or use the eraser, to remove it.

Objects

Your scene so far

Each object becomes a game object in your Defold collection. The mini map below is a bird's eye view of where they sit in the game.

What is in the scene

    Add scripts

    A script is Lua that Defold runs for you. Tick the ones you want and the Studio writes the code. Start with Player move so you can move, and Coin spin so collecting looks alive.

    Your scripts

    Each ticked script becomes a .script (Lua) file in your project's main folder.

      How this maps to real Defold
      
        
      
          
      game.project tells Defold this folder is a project and which collection to run.
      
          
      main.collection is your scene: game object instances with positions.
      
          
      .go files are the game objects (a sprite plus a script).
      
          
      .script files are the Lua Defold runs, attached to a game object.
      
          
      Open it: Defold > File > Open Project > pick game.project, then press Build & Run.
