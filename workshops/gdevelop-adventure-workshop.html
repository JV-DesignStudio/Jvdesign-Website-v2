Top-Down Player Movement
Create a player that moves in all directions
Active
🎯
Goal for this step

Create a player with Top-Down movement behavior.

  • 1Create scene "World". Add Sprite "Player" (a character facing down).
  • 2Add "Top-Down movement" behavior. This gives you arrow key movement automatically!
  • 3In behaviors settings, set speed to 150.

World & Collisions
Add walls and obstacles the player can't walk through
Locked
🎯
Goal for this step

Add collision objects so the player can't walk through walls.

  • 1Add Sprite "Wall" (brown rectangles). Set "Solid" behavior on it.
  • 2Place walls around the edges of the scene and create buildings/trees.
  • 3The Top-Down behavior automatically collides with solid objects!
💡
You can also use GDevelop's Tilemap feature for complex worlds. Import a grid-based map image and GDevelop creates collisions from it automatically!

Add NPC Characters
Place characters that the player can talk to
Locked
🎯
Goal for this step

Add NPCs that display dialogue when the player interacts with them.

  • 1Add Sprite "NPC_Villager". Place it in the world.
  • 2Add event: Condition "Player is in collision with NPC_Villager" AND "Key pressed: E". Action: "Set DialogueText to "Hello traveler! Can you find my lost gem?".
  • 3Add event: Condition "Key pressed: Escape" OR "Timer DialogueTimer > 3". Action: "Hide DialogueText".

Collectible Items
Add gems and coins scattered around the world
Locked
🎯
Goal for this step

Add collectible items that the player can pick up.

  • 1Add Sprite "Gem". Place several around the map.
  • 2Create global variable "GemsCollected" = 0.
  • 3Event: Condition "Player collides with Gem". Actions: "Delete Gem", "Change GemsCollected: Add 1".

Quest System
Track quest progress and objectives
Locked
🎯
Goal for this step

Create a quest tracking system with objectives and rewards.

  • 1Create global variables: "Quest1Active" = 0, "Quest1Complete" = 0.
  • 2Event: Talk to Villager AND Quest1Active = 0 → Set Quest1Active = 1, show "Quest started!"
  • 3Event: GemsCollected >= 3 AND Quest1Active = 1 → Set Quest1Complete = 1, show "Quest complete!"

Trigger Zones
Detect when the player enters specific areas
Locked
🎯
Goal for this step

Create invisible trigger zones that activate events when entered.

  • 1Add Sprite "Zone_House". Make it semi-transparent. Set it as non-collidable.
  • 2Event: Condition "Player is in collision with Zone_House". Action: "Change scene to HouseInterior".
  • 3Create the HouseInterior scene with furniture objects and a "Back" door trigger.
💡
Use "Picked objects" conditions to trigger events only ONCE when entering a zone, not every frame the player is inside it.
🧠

HUD & UI

Locked
🎯
Goal for this step

Create a heads-up display showing health, gems and active quests.
