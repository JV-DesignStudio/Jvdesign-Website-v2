Episode 1: What a Datapack Is

A datapack is the friendliest Minecraft mod of all: just a folder of text files, no mod loader and no install. In this episode you make one, load it and see it work.

👶 Ages 10+ ⏱️ ~40 mins ⛏️ Minecraft ✓ Free workshop

Goal for this step

Understand what a datapack is and where it lives.

  • 1A datapack is a folder of text files that changes Minecraft using the game own systems.
  • 2It lives in a world folder at saves/<your world>/datapacks/.
  • 3You never touch the game own files, so a datapack is safe and easy to remove.

Goal for this step

Create a datapack the game accepts.

  • 1Make a folder for your pack inside datapacks.
  • 2Inside it, create a file called pack.mcmeta.
  • 3It needs a pack_format number matching your Minecraft version, and a description.
{
  "pack": {
    "pack_format": 48,
    "description": "My First Datapack"
  }
}

Goal for this step

See your pack loaded in the game.

  • 1Open your world and type /reload to load datapacks.
  • 2Type /datapack list and find your pack in the list.
  • 3If it is not there, check the folder is unzipped and holds pack.mcmeta at its top level.
