Create the Player Ship
Draw a spaceship that moves with arrow keys
Active
🎯
Goal for this step

Draw a triangular ship that moves freely around the screen with arrow keys.

  • 1Create px=64, py=100 for ship position. Speed: spd=2.
  • 2Draw with tri() or circfill() for a simple ship shape.
  • 3In _update(), use btn(0-3) for 4-directional movement. Clamp to screen bounds.
📝 Shooter - Player Ship
function _init() px=64 py=100 spd=2 end function _update() if btn(0) then px=px-spd end if btn(1) then px=px+spd end if btn(2) then py=py-spd end if btn(3) then py=py+spd end px=mid(4,px,124) py=mid(4,py,124) end function _draw() cls(0) circfill(px,py,4,12) tri(px,py-6,px-4,py+2, px+4,py+2,7) end

Fire Bullets
Press Z to shoot bullets upward
Locked
🎯
Goal for this step

Create a bullet system where pressing Z fires a bullet from the ship's position.

  • 1Create a bullets table. Each bullet: {x, y}.
  • 2When btnp(4) (Z pressed), add(bullets, {x=px, y=py-4}).
  • 3In _update(), move bullets up: b.y=b.y-4. Remove when off screen.
  • 4Draw bullets as small yellow circles.
📝 Shooter - Bullets
-- fire bullet if btnp(4) then add(bullets,{x=px,y=py-4}) sfx(0) end -- update bullets for b in all(bullets) do b.y=b.y-4 if b.y<-4 then del(bullets,b) end end

Bullet-Enemy Collision
Destroy enemies when bullets hit them
Locked
🎯
Goal for this step

Check if bullets overlap enemies, destroy both on hit, and add score.

  • 1Loop through bullets and enemies. Check if distance < 8 pixels.
  • 2On hit: del(bullets, b), del(enemies, e), score+=10.
  • 3Add explosion effect: spawn particles at hit location.
📝 Shooter - Hit Detection
for b in all(bullets) do for e in all(enemies) do if abs(b.x-e.x)<6 and abs(b.y-e.y)<6 then del(bullets,b) del(enemies,e) score=score+10 sfx(1) end end end
