Questions & Answers

Do I need to know C++ before starting?
No, but C++ is a stricter language, so some prior coding (Scratch, Python) helps. Episode 1 sets up everything and explains each line.
Is C++ and SFML really free?
Yes. Compilers like g++, editors like VS Code, and the SFML library are all completely free and open-source.
What will I build?
Pong with delta-time physics, Snake with a deque, Breakout with real classes, a platformer, and a two-part tower defence with waves, upgrades and a boss.
What age is it suitable for?
Ages 12+ works best. C++ manages more detail than Python or Java, so it suits learners ready for a stricter, more powerful language.
Why learn C++ if it is harder?
C++ powers Unreal Engine and most console and AAA games. Learning it in pure SFML makes engines like Unreal feel much easier later.
Is it really free?
All 7 episodes, forever. No ads, no paywall, no sign-up needed.
