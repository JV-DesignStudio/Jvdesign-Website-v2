How it works: write the code in each step, and the canvas on the right shows what your code does. It is a live preview that builds the game as you go. Type to see it update, or press Check my code to test it straight away.

Lumo says: every step adds one feature to the same game. Type a little, click Check my code, and test it straight away. There is no wrong answer you can't undo.

Scratch gravity: a forever loop reduces y_speed by 1 every frame (gravity), and change y by y_speed moves the sprite. Jumping sets y_speed to a large positive number all at once.
