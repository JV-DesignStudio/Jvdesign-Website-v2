Goal for this step

Understand item and block tags.

  • 1A tag is a named list of items or blocks, like mypack:shiny.
  • 2Tags live in data/<namespace>/tags/item/ (or tags/items/ in older versions).
  • 3Recipes and functions can refer to a whole tag at once.

Goal for this step

Create an item tag.

  • 1A tag file is JSON with a values list.
  • 2Each value is a full item id, or another tag with a # in front.
  • 3Give it a clear name so recipes read well.
{
  "values": [
    "minecraft:oak_planks",
    "minecraft:birch_planks",
    "minecraft:spruce_planks"
  ]
}

Make an Advancement
A custom goal
Locked
🎯
Goal for this step

Create an advancement with a reward.

  • 1advancement, display, and criteria are the main parts.
  • 2criteria describes what the player must do, using a trigger.
  • 3rewards can run a function when they earn it.
{
  "criteria": {
    "get_diamond": { "trigger": "minecraft:inventory_changed" }
  },
  "rewards": { "function": "mypack:reward" }
}
