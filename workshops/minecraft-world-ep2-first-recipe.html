Goal for this step

Put a recipe file in the right place.

  • 1Recipes go in data/<namespace>/recipe/ (singular recipe in 1.21 and newer).
  • 2The namespace is a name you choose for your pack, lowercase like mypack.
  • 3Each recipe is one .json file.

Shape and Key
The pattern of a recipe
Locked
🎯
Goal for this step

Write a shaped recipe.

  • 1pattern is the shape on the 3x3 grid, one string per row.
  • 2key says what each letter means.
  • 3A space in the pattern means an empty slot.
{
  "type": "minecraft:crafting_shaped",
  "pattern": ["PPP", " S ", " S "],
  "key": {
    "P": { "item": "minecraft:oak_planks" },
    "S": { "item": "minecraft:stick" }
  },
  "result": { "item": "minecraft:wooden_sword", "count": 1 }
}
