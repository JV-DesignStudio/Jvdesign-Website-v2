Set Up the Grid System
Create the grid that the snake moves on
Active
🎯
Goal for this step

Create a grid-based coordinate system that converts grid positions to screen positions.

Understanding grid movement

  • 1In Snake, the snake moves on a grid, not smoothly. Each cell is a fixed size.
  • 2Create a new Defold project called "snake-game".
  • 3Create a script called "grid.script" that manages the grid:
📜 grid.script — Grid Manager
function init(self) self.cell_size = 32 self.grid_w = 20 self.grid_h = 15 end -- Convert grid coords to screen position function grid_to_screen(self, gx, gy) local x = (gx - self.grid_w / 2) * self.cell_size local y = (gy - self.grid_h / 2) * self.cell_size return vmath.vector3(x, y, 0) end
💡
The grid is 20×15 cells, each 32 pixels wide. This gives us a 640×480 game area.

Create the Snake Body
Use a table to store the snake's segments
Locked
🎯
Goal for this step

Create a table to store the snake's body segments and render them on screen.

Build the snake body

  • 1In Lua, a table is like an array. We'll store each body segment's grid position in a table.
  • 2Create "snake.script" and attach it to a game object:
📜 snake.script — Body Table
function init(self) -- Body is a table of {x, y} positions self.body = { { x = 10, y = 7 }, { x = 9, y = 7 }, { x = 8, y = 7 }, } self.direction = { x = 1, y = 0 } self.move_timer = 0 self.move_interval = 0.15 end function update(self, dt) self.move_timer = self.move_timer + dt if self.move_timer >= self.move_interval then self.move_timer = 0 move_snake(self) end end function move_snake(self) -- Get head position local head = self.body[1] local new_head = { x = head.x + self.direction.x, y = head.y + self.direction.y } -- Add new head, remove tail table.insert(self.body, 1, new_head) table.remove(self.body) end
💡
table.insert() adds an item to a table. table.remove() removes the last item. This creates the "move forward" effect.

Direction Input
Control the snake with arrow keys
Locked
🎯
Goal for this step

Use on_input() to change the snake's direction with arrow keys, preventing 180-degree turns.

📜 snake.script — Input
function on_input(self, action_id, action) if action.pressed then if action_id == hash("up") and self.direction.y ~= -1 then self.direction = { x = 0, y = 1 } elseif action_id == hash("down") and self.direction.y ~= 1 then self.direction = { x = 0, y = -1 } elseif action_id == hash("left") and self.direction.x ~= 1 then self.direction = { x = -1, y = 0 } elseif action_id == hash("right") and self.direction.x ~= -1 then self.direction = { x = 1, y = 0 } end end end
💡
The check self.direction.y ~= -1 prevents the snake from turning 180 degrees into itself.

Spawn Food
Randomly place food on the grid
Locked
🎯
Goal for this step

Create a food spawning system that places food at random grid positions, avoiding the snake's body.

📜 food.script
function init(self) self.food_pos = { x = 5, y = 5 } end function spawn_food(self, snake_body) local valid = {} -- Check every grid cell for gx = 0, 19 do for gy = 0, 14 do local occupied = false for _, seg in ipairs(snake_body) do if seg.x == gx and seg.y == gy then occupied = true end end if not occupied then table.insert(valid, { x = gx, y = gy }) end end end -- Pick a random valid position local pick = valid[math.random(#valid)] self.food_pos = pick end

Grow the Snake
Increase body length when food is eaten
Locked
🎯
Goal for this step

Detect when the snake head reaches the food position and grow the snake by not removing the tail.

📜 snake.script — Grow on Eat
function move_snake(self) local head = self.body[1] local new_head = { x = head.x + self.direction.x, y = head.y + self.direction.y } table.insert(self.body, 1, new_head) -- Check if we ate the food if new_head.x == self.food_x and new_head.y == self.food_y then self.score = self.score + 1 -- Don't remove tail = snake grows! msg.post("/food", "spawn") else table.remove(self.body) end end
🎉
The key trick: when the snake eats food, we simply don't remove the tail. This makes the body one segment longer!

Wall & Self Collision
End the game when the snake hits a wall or itself
Locked
🎯
Goal for this step

Detect when the snake hits the walls or its own body and trigger game over.

📜 snake.script — Collision Check
function check_collision(self) local head = self.body[1] -- Wall collision if head.x < 0 or head.x >= 20 or head.y < 0 or head.y >= 15 then return true end -- Self collision (check if head overlaps any body segment) for i = 2, #self.body do if head.x == self.body[i].x and head.y == self.body[i].y then return true end end return false end

📜 snake.script — State Machine
function init(self) self.state = "menu" -- "menu", "playing", "gameover" self.score = 0 -- ... rest of init end function update(self, dt) if self.state == "menu" then -- Show title, wait for input elseif self.state == "playing" then -- Normal game logic self.move_timer = self.move_timer + dt if self.move_timer >= self.move_interval then self.move_timer = 0 move_snake(self) if check_collision(self) then self.state = "gameover" end end elseif self.state == "gameover" then -- Show game over, wait for restart end end

function init(self) self.high_score = sys.get_config_int("snake.high_score", 0) self.current_score = 0 end function on_message(self, message_id, message, sender) if message_id == hash("score") then self.current_score = message.value gui.set_text(gui.get_node("score_text"), "Score: " .. self.current_score) if self.current_score > self.high_score then self.high_score = self.current_score sys.set_config_int("snake.high_score", self.high_score) end gui.set_text(gui.get_node("high_text"), "Best: " .. self.high_score) end end
