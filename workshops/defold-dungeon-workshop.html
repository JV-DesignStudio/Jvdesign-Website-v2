Set Up a Tilemap
Create the dungeon floor and walls
Active
🎯
Goal for this step

Create a tilemap that defines the dungeon layout with floor tiles and walls.

Understanding tilemaps

  • 1A tilemap is a grid of tiles that forms your level. Each cell contains a tile index pointing to an image in an atlas.
  • 2Create a new project called "dungeon-crawler".
  • 3Create an atlas "tiles.atlas" with floor, wall, door and player tiles.
  • 4Create a Tilemap file: right-click → New → Tilemap. Name it "level1.tilemap".
  • 5Set the tile dimension to 32�-32 and paint your dungeon layout. Use tile index 1 for floor, 2 for walls.
📄 level1.tilemap — Tile Configuration
-- Tilemap uses a grid of tile indices -- 0 = empty (no tile) -- 1 = floor tile -- 2 = wall tile (solid) -- 3 = door tile -- Paint your dungeon in the tilemap editor -- Walls around the edges, floor in the middle

Player Movement with Collision
Move the player and stop at walls
Locked
🎯
Goal for this step

Move the player with arrow keys and use tilemap collision to stop at walls.

📜 player.script — Movement + Tilemap Collision
function init(self) self.speed = 200 self.dir = vmath.vector3(0, 0, 0) end function update(self, dt) local pos = go.get_position() local new_pos = pos + self.dir * self.speed * dt -- Check tilemap collision before moving if can_move_to(self, new_pos) then go.set_position(new_pos) end end function can_move_to(self, pos) -- Convert screen position to tile coords local tile_x = math.floor(pos.x / 32) local tile_y = math.floor(pos.y / 32) -- Get tile at that position local tile = tilemap.get_tile( hash("/level#tilemap"), hash("ground"), vmath.vector3(tile_x, tile_y, 0) ) -- Tile 2 is a wall, can't move there return tile ~= 2 end
💡
tilemap.get_tile() reads the tile index at a grid position. We check if it's a wall (index 2) before allowing movement.

Enemy AI
Create enemies that patrol and chase the player
Locked
🎯
Goal for this step

Create an enemy that patrols between two points and chases the player when close.

📜 enemy.script — Patrol + Chase AI
function init(self) self.speed = 120 self.chase_speed = 180 self.patrol_a = vmath.vector3(100, 0, 0) self.patrol_b = vmath.vector3(-100, 0, 0) self.target = self.patrol_b self.chase_range = 200 self.player_pos = vmath.vector3(0, 0, 0) end function update(self, dt) local pos = go.get_position() local dist_to_player = vmath.length(self.player_pos - pos) if dist_to_player < self.chase_range then -- Chase the player! local dir = vmath.normalize(self.player_pos - pos) pos = pos + dir * self.chase_speed * dt else -- Patrol between points local dir = vmath.normalize(self.target - pos) pos = pos + dir * self.speed * dt if vmath.length(self.target - pos) < 5 then self.target = (self.target == self.patrol_a) and self.patrol_b or self.patrol_a end end go.set_position(pos) end function on_message(self, message_id, message, sender) if message_id == hash("player_pos") then self.player_pos = message.pos end end

Health System
Add health to the player and damage from enemies
Locked
🎯
Goal for this step

Add a health variable, take damage when touching enemies, and display health in the GUI.

📜 player.script — Health
function init(self) self.health = 3 self.max_health = 3 self.invincible = false self.invincible_timer = 0 end function take_damage(self) if self.invincible then return end self.health = self.health - 1 self.invincible = true self.invincible_timer = 1.0 msg.post("/hud", "update_health", { health = self.health }) if self.health <= 0 then msg.post("/hud", "game_over") end end
💡
The invincibility timer prevents the player from taking damage every frame while touching an enemy. After 1 second, they can be hit again.

Collections & Prefabs
Reuse enemy and item templates
Locked
🎯
Goal for this step

Learn how collections and prefabs work to reuse game objects across your game.

  • 1A collection is a group of game objects. Your main.collection holds the level.
  • 2A prefab is a reusable game object template. Create "enemy.collection" with enemy components.
  • 3Place enemy prefabs directly in your tilemap or spawn them dynamically.
