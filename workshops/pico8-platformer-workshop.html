Build the Tile Map
Create a level layout using Pico-8's built-in map editor
Active
🎯
Goal for this step

Use Pico-8's MAP editor to draw a platformer level with solid tiles and open spaces.

👨‍👧
Parent note: Pico-8 has a built-in MAP editor (click the MAP tab in the editor). You draw tiles by clicking cells. We'll use sprite 1 for solid ground and leave empty spaces for air.
  • 1In the SPRITE editor, draw a simple 8x8 tile: grass/dirt for solid ground (sprite #1).
  • 2Open the MAP editor and draw a level layout: ground at the bottom, platforms in the air, gaps to jump over.
  • 3In code, use mget(x,y) to read map tiles. Tile 0 = empty (air), tile 1 = solid ground.
📝 Platformer - Reading the Map
function _init() px=16 py=96 pvx=0 pvy=0 end function is_solid(x,y) local tx=flr(x/8) local ty=flr(y/8) return mget(tx,ty)==1 end

Add Gravity
Make the player fall when not standing on ground
Locked
🎯
Goal for this step

Apply gravity to the player and stop falling when they land on a solid tile.

  • 1Create pvy=0 (vertical velocity). Each frame: pvy = pvy + 0.5 (gravity).
  • 2Move player: py = py + pvy.
  • 3Check if feet are on solid tile. If yes, set pvy=0 and snap to tile top.
📝 Platformer - Gravity
function _update() -- gravity pvy=pvy+0.5 -- apply velocity py=py+pvy -- ground collision if is_solid(px,py+7) then py=flr((py+7)/8)*8-7 pvy=0 grounded=true else grounded=false end end

Jumping
Press Z to jump when grounded
Locked
🎯
Goal for this step

Allow the player to jump by pressing Z when standing on the ground.

  • 1When btnp(4) (Z) and grounded is true: pvy = -3.
  • 2The negative value launches the player upward. Gravity brings them back down.
  • 3Add left/right movement: if btn(0) then px=px-1.5 end.
📝 Platformer - Jump
-- in _update: if btnp(4) and grounded then pvy=-3 sfx(0) end -- horizontal movement if btn(0) then px=px-1.5 end if btn(1) then px=px+1.5 end

Wall & Ceiling Collision
Prevent walking through walls and bumping through ceilings
Locked
🎯
Goal for this step

Add collision checks for horizontal walls and ceilings so the player can't phase through them.

  • 1Horizontal: before moving px, check if the new position hits a wall. If so, don't move.
  • 2Vertical: if moving up into a ceiling, set pvy=0 and push down.
  • 3Check both left/right edges of the player sprite for wall collision.

Collectible Coins
Add spinning coins that the player can collect
Locked
🎯
Goal for this step

Add coin objects that the player collects by touching them, with a score counter.

  • 1Create a coins table. Place coins at specific map positions or use map tile 2 as coin marker.
  • 2Draw coins as small yellow circles with a spin animation using circ() or ovalfill().

Patrol Enemies
Add walking enemies that patrol back and forth
Locked
🎯
Goal for this step

Add enemies that walk back and forth on platforms. Player can stomp them from above.

  • 1Create enemies table. Each: {x, y, dx} where dx is movement direction.
  • 2Move enemies: e.x = e.x + e.dx. Reverse direction at edges or walls.
  • 3Stomp: if player falls on enemy from above (pvy > 0 and player above enemy), enemy dies. Otherwise, player takes damage.

Camera Scrolling
Make the camera follow the player through the level
Locked
🎯
Goal for this step

Scroll the camera so the view follows the player as they move through a wider level.

  • 1Create cam_x=0, cam_y=0. Set camera: camera(cam_x, cam_y).
  • 2Center camera on player: cam_x = px - 64, cam_y = py - 64.
  • 3Clamp camera to level bounds so it doesn't show outside the map.
