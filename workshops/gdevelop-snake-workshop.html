Set Up the Snake Scene
Create the game grid and add the snake head
Active
🎯
Goal for this step

Create a new scene with a grid background and add the snake head object.

👨‍👧
Parent note: Snake uses a grid-based movement system. The snake moves in steps, one grid square at a time. This is different from Pong where movement was smooth.

Create the scene

  • 1In GDevelop, open your project. Right-click "Main Scene" in the Project Manager and rename it to "Menu".
  • 2Click "Add a new scene". Name it "Game".
  • 3Add a "Sprite" object called "SnakeHead". Paint a 20x20 green square.
  • 4Place it near the centre of the scene.

Add Direction Controls
Use arrow keys to change the snake's direction
Locked
🎯
Goal for this step

Create a direction variable and change it when arrow keys are pressed.

Create a direction variable

  • 1Open the Events Sheet. Create a scene variable called "Direction" with value "right" (text).
  • 2Add an event: Condition "Key pressed: Up". Action: "Change variable Direction to "up".
  • 3Repeat for Down → "down", Left → "left", Right → "right".
  • 4Important: add a condition to prevent reversing. For the Up key event, add an extra condition: "Variable Direction is NOT "down". This stops the snake from going backwards!

Condition: Key pressed: Up Condition: Direction ≠ "down" Action: Change Direction to "up" Condition: Key pressed: Down Condition: Direction ≠ "up" Action: Change Direction to "down"

Grid-Based Movement
Move the snake one grid square at a time
Locked
🎯
Goal for this step

Use a timer to move the snake one grid square at regular intervals based on the Direction variable.

Move on a timer

  • 1Add a scene variable "GridSize" = 20 (matches our square size).
  • 2Add a "Repeat every X seconds" condition (under Timers). Set to 0.15 seconds.
  • 3Inside that, add an event: Condition "Variable Direction = "right". Action: "Change X position of SnakeHead: Add GridSize".
  • 4Repeat for all four directions: left (subtract X), up (subtract Y), down (add Y).
💡
Using a timer means the snake moves in discrete steps, not smoothly. This gives it the classic grid-based Snake feel!

Add Food & Eating
Spawn food and make the snake grow when it eats
Locked
🎯
Goal for this step

Add a food object that appears at random positions, and detect when the snake eats it.

Add the food

  • 1Add a Sprite object called "Food". Paint a 20x20 red square.
  • 2Place it somewhere on the scene.
  • 3Add an event: Condition "At the beginning of the scene". Action: "Change the position of Food" to random X (0 to 780) and random Y (0 to 580). Use the "round to nearest" operator to snap to the grid.
  • 4Add event: Condition "SnakeHead is colliding with Food". Actions: 1) "Change variable Score: Add 1". 2) "Change position of Food" to new random grid position.
💡
To snap to the grid, use: round(Random(0, 39)) �- 20 for X and round(Random(0, 29)) �- 20 for Y. This gives positions like 0, 20, 40, 60...

Snake Body Growth
Add body segments that follow the head
Locked
🎯
Goal for this step

Create body segments that trail behind the snake head as it moves.

Track segment positions

  • 1Create two scene arrays: "SegmentX" and "SegmentY" to store positions of each body segment.
  • 2At the start of each move timer, add the head's current position to the front of both arrays.
  • 3Add a Sprite object "SnakeBody" (20x20 green, slightly darker than head).
  • 4Each frame, for each index in the arrays, create or position a SnakeBody instance at the stored X and Y.
  • 5When the snake eats food, don't remove the last position from the arrays. This makes the snake grow!

Game Over: Wall & Self Collision
End the game when the snake hits walls or itself
Locked
🎯
Goal for this step

Detect when the snake hits the edge of the screen or its own body and end the game.

Wall collision

  • 1Add event: Condition "SnakeHead X position < 0" OR "X position > 780" OR "Y position < 0" OR "Y position > 580".
  • 2Action: "Change scene to Game Over" (create a "GameOver" scene with a "Game Over" text object).

Self collision

  • 3Add event: For each segment in the arrays, check if SnakeHead position equals any segment position.
  • 4If it matches, change to Game Over scene.
🧠
Knowledge Check
+15 XP

AIt checks all four walls in a single event, which is more efficient
BGDevelop only allows one event per game

Score Display & Game Over Scene
Show the score and create the game over screen
Locked
🎯
Goal for this step

Display the score on screen and create a game over screen with restart option.

Show the score

  • 1Add a "Text" object called "ScoreText". Set it to display "Score: 0". Place it in the top-left corner.
  • 2Add event: Condition "Always". Action: "Change the text of ScoreText: Score".
  • 3Create the "GameOver" scene. Add a Text object saying "Game Over!" and another saying "Press R to restart".
  • 4In GameOver events, add: Condition "Key pressed: R". Action: "Change scene to Game".
