Goal for this step

Write a quarter-circle motion.

  • 1Directions use symbols: F forward, B back, D down, U up.
  • 2A quarter circle forward is down, down-forward, forward: D, DF, F, then a button.
  • 3Holding is written with a slash, like /$D for holding down.
[Command]
name = "QCF_x"
command = D, DF, F, x
time = 15

Goal for this step

Understand command buffering.

  • 1command.time is how long the engine waits for the full motion.
  • 2command.buffer.time lets a press just before you land still count.
  • 3Too tight is frustrating, too loose makes moves fire by accident.
