Step 1
GameManager, The Brain!
One script to rule all the nights...
🔒 Locked
🎯
Goal

Create a GameManager autoload singleton that tracks which night the player is on.

🧒 For the Child

When you go from the main menu to the game, Godot forgets everything! We need a "Singleton", a special script that's ALWAYS loaded, no matter which scene you're in. Think of it as the game's memory!

👨‍👩‍👧 For the Grown-Up

An autoload singleton is registered under Project → Project Settings → Autoload. Create game_manager.gd at the project root. It stores current_night and any global state. Any script can access it via GameManager.current_night.

💡
An autoload is loaded before any scene and lives for the entire game session. It sits above everything in the scene tree.

What to do:

  • 1In the Godot FileSystem, right-click and choose New Script. Name it game_manager.gd.
  • 2Paste the script below into game_manager.gd.
  • 3Go to Project → Project Settings → Autoload.
  • 4Click the folder icon, find game_manager.gd, and add it. Name: GameManager.
  • 5Click Add. You should see it with a green tick.
# game_manager.gd
extends Node

var current_night: int = 1
var highest_night: int = 1

const NIGHT_AI = [
    [0, 0, 0, 0],   # unused (nights start at 1)
    [3, 3, 1, 1],   # Night 1
    [5, 5, 3, 3],   # Night 2
    [8, 8, 6, 5],   # Night 3
    [12, 12, 10, 8], # Night 4
    [20, 18, 18, 16], # Night 5
]

func get_ai_for_night(animatronic_index: int) -> int:
    var night = clamp(current_night, 1, 5)
    return NIGHT_AI[night][animatronic_index]

# menu.gd, attach to MainMenu root
extends Control

var selected_night = 1

func _select_night(n: int):
    selected_night = n
    _highlight_night(n)

func _start_game():
    GameManager.current_night = selected_night
    get_tree().change_scene_to_file("res://main.tscn")

@export var animatronic_name: String = "Freddy"
@export var target_side: String = "right"
@export var ai_level: int = 3

func _move_closer():
    match room:
        0:  room = 1 if target_side == "left" else 2
        1:  room = 3
        2:  room = 4
        3, 4:
            reached_door.emit("left" if room == 3 else "right")

Step 5
Foxy & Pirate Cove!
The rules are different for this one...
🔒 Locked
🎯
Goal

Add Foxy with a unique mechanic, he gets angrier the LESS you check Camera 5 (Pirate Cove).

🧒 For the Child

Foxy works differently! The more you IGNORE his camera, the faster he gets. If you never check Pirate Cove, he SPRINTS at your left door. You have to peek every now and then to keep him calm!

👨‍👩‍👧 For the Grown-Up

Foxy uses a "check counter" approach. A timer decays the check count: if foxy_check_count is low, increment foxy.ai_level. When Foxy reaches the door, a closed left door sends him back but costs extra power.

💡
Foxy's mechanic creates a pacing challenge on top of the spatial challenge. Players must divide attention between watching for other animatronics AND maintaining a minimum check rate on Pirate Cove.

What to do:

  • 1Create camera panel Cam5_PirateCove and add a camera button for it.
  • 2Instance freddy.tscn, rename to Foxy, colour: red/orange.
  • 3In main.gd, add the Foxy check system.
  • 4Add Foxy to the "animatronics" group.
  • 5Set Foxy's Timer to 4.0 seconds, he moves fast once active.
# Add to main.gd:
var foxy_neglect_timer = 0.0
const FOXY_NEGLECT_INTERVAL = 20.0
var cam5_peeks = 0

func _update_foxy(delta):
    foxy_neglect_timer += delta
    if foxy_neglect_timer >= FOXY_NEGLECT_INTERVAL:
        foxy_neglect_timer = 0.0
        if cam5_peeks < 3:
            foxy.ai_level = min(foxy.ai_level + 3, 20)
        cam5_peeks = 0

👨‍👩‍👧 For the Grown-Up

A CanvasLayer with a RichTextLabel. In _ready(), start a typewriter coroutine using await get_tree().create_timer(0.03).timeout per character. Define messages per night in a dictionary. Great intro to async-style await in GDScript.

What to do:

  • 1Add a CanvasLayer named PhoneLayer (layer 5) with a dark Panel, a RichTextLabel, and an "OK" Button.
  • 2Add the night messages dictionary and typewriter function to main.gd.
  • 3Call _show_phone_message() at the end of _ready(), before setting game_active = true.
func _show_phone_message() -> void:
    var night = GameManager.current_night
    var msg = PHONE_MESSAGES.get(night, "")
    if msg == "":
        game_active = true
        return
    phone_layer.visible = true
    phone_label.text = ""
    game_active = false
    for ch in msg:
        phone_label.text += ch
        await get_tree().create_timer(0.03).timeout
    phone_ok_btn.visible = true
    await phone_ok_btn.pressed
    phone_layer.visible = false
    game_active = true

🎮 What We're Adding

Part 1 gave you a working FNAF-style horror game with one animatronic, a power meter, and a jump scare. Part 2 makes it a real game, three new animatronics with unique AI patterns, a main menu that lets you pick your night, five nights of increasing difficulty, hallway peek lights, and ambient audio that actually makes you nervous.

🧒 For the Child

Remember how Freddy could creep up on you? Now Bonnie does it too, but from a DIFFERENT direction! And Chica sneaks through the kitchen. And Foxy... well, Foxy is special. If you don't check Pirate Cove often enough, he SPRINTS at your office and there's nothing you can do. You'll also build a proper Start Screen so your game looks like a real game! 🏴‍☠️

👨‍👩‍👧 For the Grown-Up

This episode introduces: scene switching (main menu → game → game over), a GameManager autoload singleton for passing night data between scenes, multiple animatronic instances with different exported AI values, Foxy's unique "check counter" mechanic, an AudioStreamPlayer-based ambient sound system, and a death screen showing which animatronic caught you. More GDScript patterns introduced here than in any previous episode.

✨ What You'll Add

  • Bonnie the Bunny, attacks from the left
  • Chica the Chicken, approaches through the kitchen
  • Foxy the Pirate, rushes if you ignore Pirate Cove
  • A proper main menu with Night Select
  • 5 nights with scaling AI difficulty
  • Hallway peek lights at each door
  • Ambient audio & door creak sounds
  • A death screen naming who got you
  • A GameManager singleton keeping it all together
