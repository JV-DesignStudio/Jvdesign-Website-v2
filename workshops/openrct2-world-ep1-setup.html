Install OpenRCT2
Get the free park builder running
Active
🎯
Goal for this step

Have OpenRCT2 open and reading your RollerCoaster Tycoon 2 game files.

  • 1Go to the official OpenRCT2 website and download the installer for your computer.
  • 2Run it, then open OpenRCT2. On first run it asks where your RollerCoaster Tycoon 2 game is installed. Point it at that folder.
  • 3Open any park and make sure it loads and runs.
  • 4That is the hard part done. OpenRCT2 is a free remake, but it still uses the original game art, so keep the game installed.

Find the Plugin Folder
The one folder where your mods live
Locked
🎯
Goal for this step

Find the folder OpenRCT2 watches for plugins, and know how to open it from the game.

  • 1In OpenRCT2, turn on the developer tools (usually a helpful shortcut like Ctrl+D, or from the options menu).
  • 2Choose Open custom content folder, then Open plugin folder.
  • 3On Windows it lives in Documents / OpenRCT2 / plugin.
  • 4Every mod you write goes here as its own .js file. That is the whole install: drop a file in a folder.
