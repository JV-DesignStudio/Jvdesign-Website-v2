Active

Goal for this step

Print the park cash to the console.

  • 1The park object holds the money as park.cash.
  • 2Money is stored in the smallest unit, so you divide to show pounds or dollars.
  • 3Print it with console.log so you can see it.
context.subscribe("interval.day", function () {
  console.log("Cash now: " + Math.round(park.cash / 10) / 100);
});

Count the Guests
Everyone in the park
Locked
🎯
Goal for this step

Count the guests using the map API.

  • 1map.getAllEntities("guest") returns every guest.
  • 2Its length is the guest count.
  • 3You can loop over them to look at each one.
var guests = map.getAllEntities("guest");
console.log("Guests in park: " + guests.length);
