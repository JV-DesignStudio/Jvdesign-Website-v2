The Usual Suspects
Fast fixes
Locked

Goal for this step

Recognise the five common mistakes.

  • 1Missing or extra bracket or quote.
  • 2A file ending in .js.txt instead of .js.
  • 3A plugin name that clashes with another plugin.
  • 4Calling something that does not exist (like a typo in park.postMsg).
  • 5Code running too often and slowing the game.

Guard Your Code
Never crash the game
Locked
🎯
Goal for this step

Add a check so your code only acts when it is safe.

  • 1Before using something, check it exists: if (guest) { ... }.
  • 2Wrap risky sections in try/catch so one bad guest cannot break the whole plugin.
  • 3Fail quietly, never crash the park.
try {
  // risky work
} catch (e) {
  console.log("Skipped one: " + e.message);
}
