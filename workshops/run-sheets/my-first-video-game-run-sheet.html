My First Video Game

Nine game workshops in Godot 4. Free engine, no paid software, no account.

Ages 5+ 9 episodes About 14 hours total

Before you start

  • Kit: laptop or desktop with 4 GB RAM. The free Godot 4 editor runs from one folder.
  • Setup: if installs are blocked, unzip the portable Godot build into the learner's Documents folder. No admin rights needed.
  • Accounts: none. Projects save to the local drive.
  • Pairing: one device between two learners. The grown-up drives Blender-free tasks like input maps while the child designs the game.

What they finish with

Nine playable Godot games, from a top-down racer to a three-part horror game.

Skills: scenes and nodes, scripts, signals, collision, animation, cameras and game state.

One 90-minute session

10 min: open Episode 1 and play the finished racer.
55 min: build the scene and script one step at a time.
15 min: change the speed or colour and test.
10 min: share the game with the group.

Nine sessions

One episode per session. Start each session by replaying the last game for five minutes, then open the next episode. Episodes 7 to 9 continue one story, so run them in order.

When a learner is stuck

  • Scene runs but nothing moves: check the node has a script attached and the script extends the matching node type (for example CharacterBody2D).
  • Null instance error: a node path is wrong. Check the name in the Scene tree matches the $NodeName in the script.
  • Player falls through the floor: add a CollisionShape2D to the floor and make sure the collision layers and masks match.
  • Input does nothing: add the action in Project Settings, then Input Map, and use Input.is_action_pressed with the same name.
