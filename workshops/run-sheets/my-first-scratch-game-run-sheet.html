My First Scratch Game

Six drag-and-drop game workshops. Free, browser based, suitable for younger learners.

Ages 6+ 6 episodes About 8.5 hours total

Before you start

  • Kit: any laptop, desktop or Chromebook with a modern browser. No install.
  • Scratch: the editor runs at scratch.mit.edu. A free Scratch account saves projects; learners can also build without saving.
  • Reading: the workshops read the screen aloud to a grown-up. Pair a confident reader with each learner if needed.
  • Pairing: one device between two learners works. Swap who drags the blocks each episode.

What they finish with

Six playable Scratch games, ending with a branching story adventure they can share.

Skills: sprites, events, motion, variables, loops, collision, lists and simple dialogue.

One 60-minute session

5 min: open Episode 1 and play the finished example.
35 min: build the step together, one block at a time.
10 min: change one thing (speed, colour, sound).
10 min: show the game to the group.

Six sessions

One episode per session. Start each session by playing the last game, then open the next episode. Episode 5 and 6 are longer; split them across two shorter sessions if attention wanders.

When a learner is stuck

  • Sprite will not move: click the sprite so its scripts are selected, then check the script starts with when green flag clicked and the motion block sits inside a forever loop.
  • Score always shows zero: put the change score block inside the if touching block, and make sure the variable belongs to the sprite doing the check.
  • Game starts before the green flag: put every script under when green flag clicked and remove loose blocks from the workspace.

Still stuck? open the Scratch cheat sheet, reread the step, or ask an adult to sit with you.
