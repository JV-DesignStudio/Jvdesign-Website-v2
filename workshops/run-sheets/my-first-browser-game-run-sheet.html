My First Browser Game

Six browser game workshops. No install, no account, no paid software.

Ages 10+ 6 episodes About 9 hours total

Before you start

  • Kit: any laptop or Chromebook with a modern browser. Nothing to install.
  • Editor: every episode has its own code box on the page. A separate code editor is optional.
  • Accounts: none. Progress saves in the browser on that device.
  • Pairing: one device between two learners works. Swap who types each episode.

What they finish with

Six working games, ending with a full platformer they can play, download and share.

Skills: canvas drawing, game loop, gravity, input and touch, collision, scoring and a text level format.

One 90-minute session

10 min: open Episode 1 and read the goal together.
50 min: build the step, preview, and fix one bug.
20 min: answer the quiz and download the game.
10 min: one learner shows the game to the group.

Six 90-minute sessions

One episode per session. Start each session by replaying the last game for five minutes, then open the next episode. Episode 5 is a shorter builder session and pairs well with a share-and-tell.

When a learner is stuck

  • Blank page: check the script tag and read the first red console error. One typo stops the whole script.
  • Keys do nothing: click the page once so it has focus, then check the key names in the listener.
  • Runs once then freezes: the animation loop must call itself again at the end of each frame.
  • Works on laptop, not phone: add the viewport meta tag and a touch control that calls the same move function.

Still stuck? the JavaScript cheat sheet and the Debug It task on the engine hub cover the same fixes.
