Set Up Variables
Create all the number trackers the game needs before building anything
Active
🎯
Goal for this step

Create all variables first so they're ready to use when building each feature.

👨‍👧
Parent note: Clicker games are all about numbers changing over time. Every feature, coins, upgrades, auto-earn, is just a variable being increased or decreased at the right moment. Setting them all up first makes the rest much easier to follow.
  • 1Open scratch.mit.edu, start a new project, name it "Click Frenzy". Delete the cat.
  • 2Go to Variables → Make a Variable. Create these one by one: Coins, CoinsPerClick, AutoEarner1, AutoEarner2, Multiplier.
  • 3Keep Coins visible (ticked). Uncheck all others, we'll display them differently.
  • 4Also create Upgrade1Cost, Upgrade2Cost, Upgrade3Cost, these will be the prices of upgrades.
💡
Drag the Coins counter to the top-centre of the stage so it's the most prominent number on screen.
✏️Concept Fill+15 XP

In Scratch, a is a named container that stores a number or text. We keep visible on stage because it's the main score the player watches.

Create the Click Button
Draw a big clickable button in the centre of the stage
Locked
🎯
Goal for this step

Add a large, satisfying button in the middle of the stage. Clicking it is the core mechanic!

  • 1Click Paint to draw a new sprite. Draw a big circle in gold/yellow, about half the stage width. Add a coin symbol or star inside.
  • 2Name the sprite CoinButton. Set its size to 150 and centre it on stage.
  • 3In the Code tab, add: "when 🏳 clicked → set Coins to 0 → set CoinsPerClick to 1 → set Multiplier to 1 → set Upgrade1Cost to 10 → set Upgrade2Cost to 50 → set Upgrade3Cost to 200".
  • 4Add a second event block: "when this sprite clicked → change Coins by (CoinsPerClick × Multiplier)".
  • 5Also add a bounce effect: "when this sprite clicked → change size by (-10) → wait 0.05 seconds → change size by (10)".
🪙 CoinButton, Click to earn
when this sprite clicked change [Coins] by ((CoinsPerClick) * (Multiplier)) change size by (-10) wait (0.05) seconds change size by (10)
💡
Test it! Press Green Flag, then click the button rapidly. The coins should go up with every click.

Add Upgrade 1, More Per Click
Buy this to earn more coins with each click
Locked
🎯
Goal for this step

Add the first upgrade button. Costs 10 coins. Doubles CoinsPerClick.

  • 1Paint a new sprite, a rounded rectangle button. Add text: "Better Click 🖱️" and "Cost: 10". Name it Upgrade1.
  • 2Position it in the top section of the shop panel: x: 170, y: 100.
  • 3In the Code tab: "when 🏳 clicked → go to x: 170 y: 100 → forever → if Coins ≥ Upgrade1Cost then set colour effect to 0 else set colour effect to 25", this dims the button when you can't afford it.
  • 4Add: "when this sprite clicked → if Coins ≥ Upgrade1Cost then change Coins by (-Upgrade1Cost) → change CoinsPerClick by 1 → change Upgrade1Cost by 10".
⬆️ Upgrade1, Click to buy
when this sprite clicked if (Coins) >= (Upgrade1Cost) then change [Coins] by (-(Upgrade1Cost)) change [CoinsPerClick] by (1) change [Upgrade1Cost] by (10) end
📖
Each time you buy it, the cost goes up by 10, that's the classic idle game loop! You have to keep clicking to afford the next one.

Add Upgrade 2, Auto Clicker
Earns 1 coin per second automatically, forever!
Locked
🎯
Goal for this step

Add an auto-clicker upgrade that passively earns coins every second without clicking.

  • 1Paint Upgrade2 button. Text: "Auto Clicker 🤖", "Cost: 50". Position at x: 170, y: 30.
  • 2Same affordability dimming script as Upgrade1 (copy and adjust).
  • 3Buy script: "if Coins ≥ Upgrade2Cost then change Coins by (-50) → change AutoEarner1 by 1 → change Upgrade2Cost by 50".
  • 4Now create the auto-earn loop. Add a NEW script stack in Upgrade2: "when 🏳 clicked → forever → wait 1 second → change Coins by (AutoEarner1)".
🤖 Upgrade2, Auto earn loop
when 🏳 clicked forever wait (1) seconds change [Coins] by (AutoEarner1) end
🎉
Buy one auto clicker and watch your coins tick up on their own, the satisfying heart of every idle game!

Add a Milestone & Prestige
Celebrate reaching 1000 coins with a special reward
Locked
🎯
Goal for this step

When coins hit 1000, show a celebration and grant a prestige bonus.

  • 1In the CoinButton sprite, add a new script: "when 🏳 clicked → forever → if Coins ≥ 1000 and Milestone1 = 0 then say [🌟 1000 Coins! You unlocked a bonus!] for 3 seconds → set Milestone1 to 1 → change CoinsPerClick by 5".
  • 2Create a variable Milestone1 (hidden) so this only triggers once.
  • 3Add more milestones at 5000 and 10000 for extra rewards, copy the same pattern.
🎉
Milestones give players a goal to work towards and reward them with a surprise. It's one of the best feelings in idle games!

Add Floating Coin Particles
A +1 floats up from the button when you click, satisfying!
Locked
🎯
Goal for this step

Create a small coin sprite that clones itself on each click and floats upward before disappearing.

  • 1Paint a tiny sprite, a small gold circle with "+1" text. Name it CoinParticle. Hide it in the sprite panel (tick "hide" in properties).
  • 2In CoinButton's click script, add: "create clone of [CoinParticle]".
  • 3In CoinParticle's code: "when I start as a clone → go to [CoinButton] → show → repeat 20 → change y by 5 → change ghost effect by 5 → end → delete this clone".
💥 CoinParticle, Float and fade
when I start as a clone go to [CoinButton v] show repeat (20) change y by (5) change [ghost v] effect by (5) end delete this clone
💻

Add Click Sound & Background Music
A coin clink on every click and upbeat background music
Locked
🎯
Goal for this step

Add a satisfying coin sound on each click and looping background music.

  • 1Select CoinButton → Sounds tab → Choose a Sound. Add "Coin" or "Ding".
  • 2In the click script, add "start sound [Coin]" (not "play until done", that would pause clicking!).
  • 3Click the Stage → Sounds → add a fun upbeat loop like "Dance Around" or "Bossa Nova".
  • 4Stage code: "when 🏳 clicked → forever → play sound [Dance Around] until done".
⚡True or False?+15 XP
"start sound" lets the script keep running immediately while the sound plays in the background.
Background music should use "start sound" inside a forever loop.
You add sounds to a sprite through the Sounds tab, not the Code tab.
