🛠️ Defold Project Structure

How Defold Projects Work

Every Defold game follows the same file structure. Understanding these files is the first step to building real games.

📄
.project
The main project settings file. Tells Defold your game's name, screen size and build settings.
📦
.collection
Containers for game objects. Your main collection holds all the game objects in a scene.
🧩
.component
Component files attach scripts, sprites and other resources to game objects.
📜
.script
Lua scripts that define game logic. Each script has init(), update() and on_message() functions.
🎨
.sprite
Sprite components that render images and animations in the game world.
🌍
.tilemap
Tilemaps for building level layouts with repeating tiles, used in platformers and dungeons.

Questions from Parents

Do I need any coding experience?
None at all. Defold uses Lua scripting which is beginner-friendly, and each workshop is written for a parent and child reading together, with every step explained clearly. You'll learn as you build.
What age is it suitable for?
These workshops are designed for ages 10+ and work best with a parent helping. Younger kids (8-9) can do it with more parental involvement. The code is written step by step so you learn together.
Do I need to download anything?
Yes, Defold is a free game engine you download from defold.com. It's about 200MB and works on Windows, Mac and Linux. No account needed to use it.
Do I need to do episodes in order?
We recommend starting with Episode 1 (Pong Clone) since it teaches the basics. After that, you can jump to any episode that interests you.
Is it really free?
Yes, all 6 episodes and every step are completely free. Defold itself is also free to use, even for commercial games.
What is Lua scripting?
Lua is the programming language used by Defold. It's one of the easiest languages to learn , the syntax is simple and forgiving. You'll write real code that runs in a real game engine.
