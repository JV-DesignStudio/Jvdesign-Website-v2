Colour Your Fighter
Episode 3: Sprites and Palette

Now the art. MUGEN sprites are indexed pictures: every pixel points at a colour in a palette. Change the palette and the whole fighter changes colour, with no redrawing.

How Indexed Colour Works
Colour by number
Active
🎯
Goal for this step

Understand that each pixel is a palette number, not a colour.

  • 1A classic MUGEN sprite uses a 256 colour palette.
  • 2Each pixel stores a number from 0 to 255, not a colour.
  • 3The palette file decides what colour each number actually is.

The Palette File (.act)
One file, all the colour
Locked
🎯
Goal for this step

Know that .act holds the palette.

  • 1.act is a palette file: 256 colours in order.
  • 2The def lists palettes as pal1, pal2 and so on, giving a colour choice on the select screen.
  • 3Editing an .act is the easiest way to make a character your own.
