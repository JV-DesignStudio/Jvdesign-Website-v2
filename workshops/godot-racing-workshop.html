Stardust's five moves

Don't just copy it. Own it.

Copying the finished code proves it runs. Explaining and changing it proves you understand it. Work through these five moves.

  1. 1. See it Pip Watch the finished build work before you type anything. Notice one thing it does that you want to keep. Open it
  2. 2. Understand it Lumo Read why the important lines are there before you copy them. If you can say what a line does in your own words, you understand it. Open it
  3. 3. Build it Ember Type or assemble the guided version yourself. Keep the reference solution closed unless a step stops you. Open it
  4. 4. Fix it Echo Try Echo's Debug It challenge. Find the bug from the clues before you open the answer. Open it
  5. 5. Own it Stardust Change one thing the guide never asked for: adding one feature or level of your own. If your version runs, it is yours. Open it

Before We Start What is Godot?
A quick hello for grown-ups and little coders alike!

👶 For the child

Godot is like a magical toybox where you can build your own video games! We'll use it to make a racing car that you can actually drive. How cool is that?!

👨‍👩‍👧 For the grown-up

Godot 4 is a free, open-source game engine. This workshop uses GDScript (Python-like). Download from godotengine.org it's about 40 MB and needs no installer.

👨‍👩‍👧⭐
Grown-up note: Throughout this workshop, purple boxes like this one have tips just for you. The child can do most of the typing just be there to read the instructions together and help when they get stuck!
✅
Make sure you have Godot 4 installed before you start! Go to godotengine.org, click Download, and grab the Standard version. It's free!
🛠️
Build it in our Godot Studio too: lay out your scene on a grid, add real GDScript and download a real project.godot plus a scene you can open in Godot, right in the browser with no install. Open the Godot Mod Studio →
🌐
How it works: write the code in each step, and the canvas on the right shows what your code does. It is a live preview that builds the game as you go, so you can play every step along the way. Type to see it update, or press Apply to Canvas to test it straight away.
🦊
Lumo says: every step adds one feature to the same game. Type a little, click Apply to Canvas, and play it straight away. There is no wrong answer you can't undo.
