Create the Gem Grid
Set up an 8x8 grid of random coloured gems
Active
🎯
Goal for this step

Create an 8x8 grid where each cell holds a gem type (1-5) and draw them as coloured squares.

  • 1Create grid={} as an 8x8 2D table. Fill with random values 1-5 using flr(rnd(5))+1.
  • 2Each gem type maps to a colour: 1=red(8), 2=blue(12), 3=green(11), 4=yellow(10), 5=pink(14).
  • 3Draw each gem as a filled rectangle with a darker border for a polished look.
📝 Match-3 - Grid Setup
function _init() g=14 -- gem size cols={8,12,11,10,14} grid={} for y=1,8 do grid[y]={} for x=1,8 do grid[y][x]=flr(rnd(5))+1 end end end function draw_gem(x,y,t) local c=cols[t] local px=x*g+20 local py=y*g+20 rectfill(px,py,px+g-2,py+g-2,c) end

Goal for this step

Match Detection
Find horizontal and vertical matches of 3+
Locked
🎯
Goal for this step

Scan the grid for horizontal and vertical lines of 3 or more matching gems.

  • 1Horizontal: for each row, check if grid[y][x]==grid[y][x+1]==grid[y][x+2].
  • 2Vertical: for each column, check grid[y][x]==grid[y+1][x]==grid[y+2][x].
  • 3Store matched positions in a table and return the count.
