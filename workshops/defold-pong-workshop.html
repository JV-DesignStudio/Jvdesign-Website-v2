Download & Install Defold
Get Defold running on your computer
Active

Goal for this step

Download and install Defold on your computer, then create a new empty project.

Parent note: Defold is a free, professional game engine. Download it from defold.com. It works on Windows, Mac and Linux and requires no account to use.

Get started with Defold

Understand game objects and components

🎯
Goal for this step

Learn what game objects and components are, and create your first game object in the collection.

Understanding Defold's structure

  • 1In Defold, everything in your game is a Game Object. Players, enemies, UI are all game objects.
  • 2Each game object has Components that give it behaviour. A sprite component renders an image, a script component runs Lua code.
  • 3Open main/main.collection in the file browser. This is your game's main scene.
  • 4Right-click in the collection editor and choose "Add Game Object". Name it "paddle".
  • 5The game object appears in the collection but has no components yet. It's an empty container.

Write Your First Script
Learn the component lifecycle: init and update
Locked
🎯
Goal for this step

Create a Lua script with init() and update() functions that run when the game starts.

👨‍👧
Parent note: Every Defold script has special functions that run at specific times. init() runs once when the game object is created. update(dt) runs every frame (60 times per second).

Create the paddle script

  • 1In the file browser, right-click and create a new Script. Name it "paddle.script".
  • 2Defold creates a template with init(), final(), update(), on_message() and on_input().
  • 3This is the component lifecycle. Every script goes through these phases.
  • 4Add a print statement in init() to confirm it runs:
📜 paddle.script
function init(self) -- This runs once when the game object is created print("Paddle created!") self.speed = 400 end function final(self) -- Runs when the game object is deleted end function update(self, dt) -- Runs every frame. dt is the time since last frame end function on_message(self, message_id, message, sender) -- Handles messages from other game objects end function on_input(self, action_id, action) -- Handles keyboard/touch input end
  • 5Attach the script to the paddle: right-click the paddle game object → "Add Component File" → select "paddle.script".
  • 6Press Ctrl+B (or Cmd+B) to build and run. Check the Console tab for "Paddle created!"
💡
The dt parameter in update() is "delta time" — the time in seconds since the last frame. Multiply movement by dt to make it smooth and frame-rate independent.

Move the Paddle with Input
Use on_input() to read keyboard controls
Locked
🎯
Goal for this step

Make the paddle move up and down when the player presses arrow keys.

Add input handling

  • 1Defold needs an Input Bindings file to know which keys to listen for. Open main/input_bindings.input_binding.
  • 2Add two bindings: "up" mapped to Key W and "down" mapped to Key S.
  • 3Also add "up" mapped to Key Up and "down" mapped to Key Down for arrow key support.
  • 4Now update the paddle script to read these inputs and move:
📜 paddle.script — Input Handling
function init(self) self.speed = 400 self.velocity = 0 end function update(self, dt) -- Move paddle based on velocity local pos = go.get_position() pos.y = pos.y + self.velocity * dt go.set_position(pos) end function on_input(self, action_id, action) if action_id == hash("up") then if action.pressed then self.velocity = self.speed elseif action.released then self.velocity = 0 end elseif action_id == hash("down") then if action.pressed then self.velocity = -self.speed elseif action.released then self.velocity = 0 end end end
  • 5Build and run. Use W/Up and S/Down keys to move the paddle!
💡
We use go.get_position() to get the current position and go.set_position() to set the new one. These are core Defold API functions you'll use constantly.

Create the Ball
Add a ball game object that bounces around
Locked
🎯
Goal for this step

Create a ball game object with a script that moves it across the screen and bounces off the walls.

Build the ball

  • 1Create a new game object called "ball" in main.collection.
  • 2Add a sprite component with a small square image from your atlas.
  • 3Create a new script called "ball.script" and attach it.
  • 4The ball needs a direction and speed. We'll set these in init():
📜 ball.script
function init(self) self.speed = 300 self.dir = vmath.vector3(1, 1, 0) end function update(self, dt) local pos = go.get_position() -- Move the ball pos.x = pos.x + self.dir.x * self.speed * dt pos.y = pos.y + self.dir.y * self.speed * dt -- Bounce off top and bottom walls if pos.y > 340 then pos.y = 340 self.dir.y = -self.dir.y elseif pos.y < -340 then pos.y = -340 self.dir.y = -self.dir.y end -- Reset if ball goes off left or right edge if pos.x > 560 or pos.x < -560 then go.set_position(vmath.vector3(0, 0, 0)) end go.set_position(pos) end
💡
vmath.vector3() creates a vector with x, y and z components. We use it for position and direction. The z is always 0 in 2D games.

Add Paddle-Ball Collision
Make the ball bounce off the paddle
Locked
🎯
Goal for this step

Detect when the ball hits the paddle and make it bounce off in the opposite direction.

Collision detection

  • 1Defold has built-in collision detection using collision objects. We'll use a simple approach first.
  • 2In the ball script, add a helper function to check overlap:
  • 3We need the paddle's position. Use msg.post() to ask the paddle where it is.
  • 4This is how game objects communicate in Defold — through messages!
📜 ball.script — Collision + Messaging
function init(self) self.speed = 300 self.dir = vmath.vector3(1, 1, 0) self.paddle_y = 0 end function update(self, dt) local pos = go.get_position() pos.x = pos.x + self.dir.x * self.speed * dt pos.y = pos.y + self.dir.y * self.speed * dt -- Simple paddle collision check if pos.x < -440 then local diff = pos.y - self.paddle_y if math.abs(diff) < 60 then self.dir.x = 1 self.dir.y = math.sign(diff) end end -- Wall bounces if pos.y > 340 or pos.y < -340 then self.dir.y = -self.dir.y end go.set_position(pos) end function on_message(self, message_id, message, sender) if message_id == hash("paddle_pos") then self.paddle_y = message.y end end
📜 paddle.script — Send Position
function update(self, dt) -- Move paddle (existing code) local pos = go.get_position() pos.y = pos.y + self.velocity * dt go.set_position(pos) -- Tell the ball where we are msg.post("/ball", "paddle_pos", { y = pos.y }) end
💡
msg.post() sends a message to another game object. The ball listens with on_message(). This is how Defold game objects talk to each other!

Add an AI Opponent
Create a second paddle that follows the ball
Locked
🎯
Goal for this step

Create an AI-controlled paddle on the right side that automatically tracks the ball.

Build the AI paddle

  • 1Create a new game object called "paddle2". Add a sprite and script component.
  • 2Position it at x=450 (right side of screen).
  • 3The AI simply follows the ball's y position with some speed limit:
📜 paddle2.script — Simple AI
function init(self) self.speed = 250 self.ball_y = 0 end function update(self, dt) local pos = go.get_position() -- Move towards the ball's y position if pos.y < self.ball_y then pos.y = pos.y + self.speed * dt elseif pos.y > self.ball_y then pos.y = pos.y - self.speed * dt end go.set_position(pos) end function on_message(self, message_id, message, sender) if message_id == hash("ball_pos") then self.ball_y = message.y end end
📜 ball.script — Send position to AI
-- Add this line in update(), after moving the ball: msg.post("/paddle2", "ball_pos", { y = pos.y })

Score & Win Condition
Add scoring and detect when someone wins
Locked
🎯
Goal for this step

Add a score display, track points when the ball passes a paddle, and detect when a player reaches 5 points.

Add scoring with GUI

  • 1Create a new GUI scene: main/main.gui. This is Defold's GUI system.
  • 2Add two Text nodes for Player 1 and Player 2 scores. Position them top-left and top-right.
  • 3Create a gui.script that listens for score messages and updates the text:
📜 main/gui.script
function init(self) self.score1 = 0 self.score2 = 0 end function on_message(self, message_id, message, sender) if message_id == hash("score1") then self.score1 = self.score1 + 1 gui.set_text( gui.get_node("score1"), tostring(self.score1) ) elseif message_id == hash("score2") then self.score2 = self.score2 + 1 gui.set_text( gui.get_node("score2"), tostring(self.score2) ) end end
📜 ball.script — Score detection
-- In update(), when ball goes off left edge: if pos.x < -560 then msg.post("/gui", "score2") go.set_position(vmath.vector3(0, 0, 0)) end -- When ball goes off right edge: if pos.x > 560 then msg.post("/gui", "score1") go.set_position(vmath.vector3(0, 0, 0)) end
