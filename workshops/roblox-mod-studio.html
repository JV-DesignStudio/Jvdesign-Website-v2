Roblox Mod Studio
Build a game model in your browser

A little model maker for the Roblox Studio series. Lay out an obby level on a grid, tick the Lua scripts you want, read a broken Output log and choose the fix, then download a real model you can insert into Roblox Studio. It runs on a locked-down school computer with no install and no account.

🛠️ Open the Studio ← Back to the Roblox series
🔥
Ember says: Roblox Studio is a free app, but you can plan and build a whole level right here first. This studio turns your grid into a real .rbxmx model file and writes the Lua scripts for you. Your work saves automatically.

Lay out your obby

Pick a block below, then click squares on the grid to place it. Put a Spawn Pad where you start and a Finish Pad at the end. Click a square again, or use the eraser, to remove it.

Blocks

Your level so far

Each block becomes a Part in your model. The grid below is a bird's eye view of where they will sit in Roblox Studio.

What is in the level

    Add scripts

    A script is code Roblox Studio runs for you. Tick the ones you want and the Studio writes the Lua for you. Start with Kill brick if your level has lava, and Win pad so the finish does something.

    Your scripts

    Each ticked script becomes a .lua file. Drop them into ServerScriptService in Roblox Studio.

      How this maps to real Roblox
      
        
      
          
      .rbxmx is a Roblox model file written as text. In Studio, right-click Workspace then choose Insert from File and pick this file.
      
          
      Parts are the building blocks. A SpawnLocation sets where players start.
      
          
      .lua scripts go in ServerScriptService. They run on the server, so they affect everyone.
      
          
      Test it with the green Play button, then publish for free at create.roblox.com.
