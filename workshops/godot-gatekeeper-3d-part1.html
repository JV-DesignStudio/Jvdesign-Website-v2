Turn your preview into a game you can export

The canvas is a live preview. To keep the game and play it on another computer, open the same project in Godot 4 and export it.

  1. Download the starter project: the Part 1 reference project.
  2. Unzip it, open Godot 4 from godotengine.org, choose Import and pick project.godot.
  3. Copy each step's GDScript from the canvas into the script named in that step, then press F5 to play.
  4. Check the start, the win and the game over before you export.
  5. Open Project > Export, click Download Export Templates if asked, add a Windows Desktop or Web preset, then choose Export Project.
  6. Keep the whole export folder, not just the .exe, so the game still runs when you copy it.
