Know It All! Build a Quiz Game in Scratch

Try it: Show final results with a message based on score, press R to retry.

Tap an answer or press 1, 2 or 3.

What makes it work

These are the Scratch blocks behind the game. Open Scratch Studio to build your own version, or drag the same blocks on scratch.mit.edu.

Step 1: The Question Display
// Set up quiz variables
set [qIndex] to [0]
set [score] to [0]
set [total] to [5]
Step 2: Click or Press to Answer
// Press 1, 2, or 3 to answer
if <key [1] pressed?> then
  say [Picked answer 1]
end
if <key [2] pressed?> then
  say [Picked answer 2]
end
if <key [3] pressed?> then
  say [Picked answer 3]
end
Step 3: Right or Wrong Feedback
// Check if answer is correct
change [score] by [1]
set [feedback] to [Correct!]

// If wrong, show the right answer
set [feedback] to [Wrong!]
Step 4: Question Timer
// Timer for each question
set [timeLeft] to [10]

// Each second
change [timeLeft] by [-1]
Step 5: Score Tracking
// Display score
set [score] to [0]
set [total] to [5]
Step 6: Results and Restart
// Show result message based on score
// 4-5 correct:
set [message] to [Amazing!]
// 2-3 correct:
set [message] to [Good try!]
// 0-1 correct:
set [message] to [Keep practising!]
