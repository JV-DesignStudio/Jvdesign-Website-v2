Find the Exit! Build a Maze Game in Scratch

Try it: Show a win message with the move count when you reach the goal.

Or use the arrow keys. Press R to restart.

What makes it work

These are the Scratch blocks behind the game. Open Scratch Studio to build your own version, or drag the same blocks on scratch.mit.edu.

Step 1: The Player Sprite
// Place the player sprite
go to x: [30] y: [30]
set [ps] to [16]
set [pSpeed] to [3]
Step 2: Four-Way Movement
// Move with arrow keys
if <key [up arrow] pressed?> then
  change y by [-3]
end
if <key [down arrow] pressed?> then
  change y by [3]
end
if <key [left arrow] pressed?> then
  change x by [-3]
end
if <key [right arrow] pressed?> then
  change x by [3]
end
Step 3: Maze Walls
// If touching a wall, undo the move
if <touching color [grey]?> then
  set x to [oldX]
  set y to [oldY]
end
Step 4: The Goal
// Place the goal sprite
set [gx] to [432]
set [gy] to [312]
set [gs] to [24]
Step 5: Move Counter
// Count each movement
change [moves] by [1]

// Reset on new game
set [moves] to [0]
Step 6: Win Screen and Restart
// Check if player reached the goal
set [gameState] to [win]

// Reset for new attempt
go to x: [30] y: [30]
set [moves] to [0]
