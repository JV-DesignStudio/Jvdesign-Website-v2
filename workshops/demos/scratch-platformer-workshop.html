Jump &amp; Run! Build a Platformer in Scratch

Try it: Collect all 5 coins to win. Press R to reset and play again.

Or use the arrow keys. Press R to restart.

What makes it work

These are the Scratch blocks behind the game. Open Scratch Studio to build your own version, or drag the same blocks on scratch.mit.edu.

Step 1: The Player Sprite
// Place the player on the ground
go to x: [40] y: [280]
set [pw] to [24]
set [ph] to [24]
Step 2: Left and Right Running
// Move left and right
if <key [left arrow] pressed?> then
  change x by [-4]
end
if <key [right arrow] pressed?> then
  change x by [4]
end
Step 3: Gravity and Platforms
// Apply gravity each frame
change [pvy] by [0.5]

// When landing on a platform
set [pvy] to [0]
set [onGround] to [true]
Step 4: Jumping
// Jump when on ground
if <key [space] pressed?> then
  set [pvy] to [-9]
end
Step 5: Collectible Coins
// When touching a coin
change [score] by [1]

// Total coins to collect
set [totalCoins] to [5]
Step 6: Win Screen and Restart
// Check if all coins collected
if <score = 5> then
  set [gameState] to [win]
end

// Reset on R
set [score] to [0]
go to x: [40] y: [280]
