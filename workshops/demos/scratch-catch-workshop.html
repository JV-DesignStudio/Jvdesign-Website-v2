Don't Drop It! Build a Fruit Catch Game in Scratch

Try it: Make fruit fall faster as score grows, let R restart the game.

Or use the arrow keys. Press R to restart.

What makes it work

These are the Scratch blocks behind the game. Open Scratch Studio to build your own version, or drag the same blocks on scratch.mit.edu.

Step 1: The Basket Sprite
// Set the basket starting position
set [bx] to [200]
set [by] to [320]
set [bw] to [80]
set [bh] to [20]
Step 2: Arrow Key Movement
// Move basket with arrow keys
if <key [left arrow] pressed?> then
  change x by [-6]
end
if <key [right arrow] pressed?> then
  change x by [6]
end
Step 3: Falling Fruit
// Move fruit downward
change [fy] by [fallSpeed]

// Reset when off stage
set [fx] to pick random [20] to [440]
set [fy] to [-20]
Step 4: Catching Fruit
// Check if fruit touches basket
change [score] by [1]
set [fx] to pick random [20] to [440]
set [fy] to [-20]
Step 5: Lives and Missing
// Fruit missed!
change [lives] by [-1]

// Check for game over
set [gameState] to [over]
Step 6: Speed Ramp and Restart
// Speed up as score grows
set [fallSpeed] to [3 + score / 5]

// Cap the speed
set [maxSpeed] to [8]
