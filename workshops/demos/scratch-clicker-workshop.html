Click Frenzy! Build an Idle Clicker Game in Scratch

Try it: Show the final score when time runs out, press R to play again.

What makes it work

These are the Scratch blocks behind the game. Open Scratch Studio to build your own version, or drag the same blocks on scratch.mit.edu.

Step 1: The Target Sprite
// Place the target sprite
set [tx] to [200]
set [ty] to [140]
set [tr] to [35]
Step 2: Click to Move
// When target clicked, move to random spot
set [tx] to pick random [50] to [430]
set [ty] to pick random [50] to [310]
Step 3: Score Counter
// When green flag clicked
set [score] to [0]

// When target clicked
change [score] by [1]
Step 4: Countdown Timer
// When green flag clicked
set [timeLeft] to [30]

// Each second
change [timeLeft] by [-1]
Step 5: Shrinking Target
// Shrink target as score grows
set [tr] to [35 - score]

// But never smaller than
set [minSize] to [15]
Step 6: Game Over and Restart
// Reset everything for a new game
set [score] to [0]
set [timeLeft] to [30]
set [tr] to [35]
set [gameState] to [play]
