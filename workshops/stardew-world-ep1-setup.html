What modding needs, and what it costs

Goal for this step

Understand exactly what you need before you touch anything.

  • 1Stardew Valley is a paid game for PC, Mac and Linux. You need to own it before you can play or mod it.
  • 2The mods and tools are free: the mod loader (SMAPI), Content Patcher and Tiled cost nothing.
  • 3Every change you make lives inside one folder: Stardew Valley / Mods. That is the whole idea.
  • 4Modding never touches your save file, so you can always undo it by removing a folder.

Install SMAPI
The free mod loader that runs your mods
Locked
🎯
Goal for this step

Install the mod loader that lets Stardew read the Mods folder.

👨‍👧
Grown-up note: download SMAPI only from the official site, smapi.io. The installer will look for Stardew Valley on its own. If it cannot find it, it asks you to point at the game folder.
  • 1Open a browser and go to smapi.io.
  • 2Download the installer for your system (Windows, Mac or Linux) and run it.
  • 3Follow the prompts. When it finishes, Stardew gains a new launcher called StardewModdingAPI.
  • 4From now on, always start the game with that launcher so your mods load.

Install Content Patcher
The mod that lets your pack change maps
Locked
🎯
Goal for this step

Add Content Patcher so your own content pack can change the world.

  • 1Content Patcher is a free mod. It lets a content pack change maps, images and data without editing the game itself.
  • 2Download it from Nexus Mods (or CurseForge) and unzip it.
  • 3Move the unzipped folder into Stardew Valley / Mods. The folder must be named ContentPatcher and hold a manifest.json at the top.
  • 4Watch out: do not unzip a folder inside a folder. If you see ContentPatcher/ContentPatcher, move the inner one up.
Mods folder
Stardew Valley/
└── Mods/
    └── ContentPatcher/
        ├── manifest.json   ← every mod needs this
        └── ContentPatcher.dll

Install the free editor you will use to shape your world.

Find the Mods Folder & Launch
Point at the right folder, then start through SMAPI
Locked
🎯
Goal for this step

Locate the Mods folder and run Stardew through SMAPI once.

  • 1Find your Mods folder using the paths below. It sits inside your Stardew Valley folder.
  • 2Inside, you should see the ContentPatcher folder you added in Step 3.
  • 3Now launch the game with StardewModdingAPI. A black console window opens with the load log.
  • 4You are not building a world yet. You are proving mods load at all.
Where the Mods folder lives
Windows:  C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley\Mods
Mac:      ~/Library/Application Support/Steam/steamapps/common/Stardew Valley/Mods
Linux:    ~/.steam/steam/steamapps/common/Stardew Valley/Mods

Read the SMAPI Console
Spot a healthy load versus an error
Locked
🎯
Goal for this step

Learn to read the log, so every future fix is quick.

  • 1The console lists every mod it loaded. Normal lines are white or green. That is a healthy load.
  • 2A red line or the word Error means a mod failed. Nine times out of ten the folder is nested or named wrong.
  • 3Look for the line that says how many mods loaded and names them.
  • 4If you see ContentPatcher in that list, your setup is ready. That is the whole goal of Episode 1.
What a healthy log looks like
[SMAPI] Loading mod manifest for ContentPatcher 2.9.x
[SMAPI] Loaded 1 mod:
[SMAPI]    Content Patcher 2.9.x by Pathoschild
