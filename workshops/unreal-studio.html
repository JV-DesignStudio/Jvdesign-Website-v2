🔺 Unreal Engine 5 🖱️ No install to start 🧩 Blueprint logic Ages 10+

Unreal Studio

Pick a game, arrange the Blueprint nodes that make it work, set the variables, then play a live sketch right here. When you are ready, download a real Blueprint recipe and follow it in Unreal Engine 5 for real.

Companion to the My First Unreal Game series. Nothing to install here, so it works on a school computer.

🦊
Lumo says: a Blueprint is just a chain of nodes. Add one, press Play, and watch what changes. If it breaks, take the node out again. There is no wrong answer, only experiments.
Make your own art and sounds: draw sprites in Pixel Studio and make music or sound effects in Sound Studio, then bring them into your game.

Build the Blueprint graph

Click a node to add it to the graph or take it out. The nodes that are in the graph are what your game does when it runs.

Tip: start with the required nodes, then add one action at a time and press Play to feel the difference.

How Blueprints read variables

Every node in the graph can read these variables. In Unreal you add them in the My Blueprint panel, then drag them into the graph. Here they change the live sketch straight away.

Play your Blueprint

Nothing happening? Go back to the Blueprint Graph, add the missing node, then play again.

Take it into Unreal Engine 5

This downloads a real Blueprint recipe: the node chain, the variables and the values, plus a README that walks you through building it in Unreal. Unreal itself is a free install on a decent PC, with a grown-up the first time.

How to build it in Unreal

  1. Install the Epic Games Launcher and Unreal Engine 5 (both free), with a grown-up the first time.
  2. New Project, Games, Blank, Blueprint.
  3. Open the Blueprint graph and wire the nodes in the order the recipe lists.
  4. Add the variables and set the values, then press Play in the editor.
