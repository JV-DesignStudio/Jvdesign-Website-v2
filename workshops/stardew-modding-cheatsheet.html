Stardew Modding
Cheat Sheet

Everything from the Stardew World Workshop on one page: paths, templates, layers, rules and the common fixes. Print it and keep it next to your keyboard.

🌱 Back to the Workshop 🖨️ Print This Page
🐯
Ember says: the copy, open, change, save, load, test loop is the whole job. This page is the answer key for when something does not match.

📁 Where the Mods folder lives

Paths
Windows:  C:\Program Files (x86)\Steam\steamapps\common\Stardew Valley\Mods
Mac:      ~/Library/Application Support/Steam/steamapps/common/Stardew Valley/Mods
Linux:    ~/.steam/steam/steamapps/common/Stardew Valley/Mods

🗂️ A tidy mod layout

Folder structure
MyFirstFarm/
├── manifest.json
├── content.json
├── icon.png            (optional)
└── assets/
    ├── maps/
    │   └── Farm.tmx
    └── images/
        └── CustomBed.png

🏷️ manifest.json template

manifest.json
{
  "Name": "My First Farm",
  "Author": "You",
  "Version": "1.0.0",
  "Description": "A custom farm and a secret garden.",
  "UniqueID": "You.MyFirstFarm",
  "ContentPackFor": { "UniqueID": "Pathoschild.ContentPatcher" }
}

📝 content.json template

content.json (load two maps)
{
  "Format": "2.0.0",
  "LogName": "My First Farm",
  "Changes": [
    { "Action": "Load", "Target": "Maps/Farm",
      "FromFile": "assets/maps/Farm.tmx" },
    { "Action": "Load", "Target": "Maps/SecretGarden",
      "FromFile": "assets/maps/SecretGarden.tmx" }
  ]
}

🗂️ Layer draw order (bottom to top)

Layers
Back         the ground: grass, dirt, water, floors
Buildings    houses, objects, tree trunks
Paths        walkable flooring
Front        draws OVER the player: tree tops, roofs
AlwaysFront  the very top: weather and effects

🚶 Tile properties

Common tile rules
Passable   (bool)   true = walk on it, false = wall
Water      (bool)   true = water (can refill/fish)
Diggable   (bool)   true = hoe and plant here
Type       (string) "Grass", "Dirt", "Stone", "Water"

🚪 Warps

Doorway tile
Warp    (string) = "Farm 64 15"
// On the doorway tile. Step here, arrive on the "Farm" map at X 64, Y 15.
// Always add a matching warp back, or the player is stranded.

🔎 The five common mistakes

Fix list
1 Nested folder (ContentPatcher/ContentPatcher)  -> move inner folder up
2 Wrong FromFile path                            -> match the real file name
3 Broken JSON (missing comma or quote)           -> check with a JSON tool
4 Map name mismatch                              -> warp name = Load Target
5 Duplicate UniqueID                             -> make yours one of a kind

🗜️ Sharing check

Before you share
Zip the MOD FOLDER, so unzipping gives MyFirstFarm/manifest.json
Name it with the version, e.g. MyFirstFarm-1.0.0.zip
Unzip into a fresh Mods folder and launch through SMAPI to test
