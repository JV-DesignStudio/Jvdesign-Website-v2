Meet the Events
The park broadcasts, you listen
Active
🎯
Goal for this step

Know three useful events and when they fire.

  • 1interval.tick fires many times a second. Good for smooth checks, easy to overload.
  • 2interval.day fires once per in-game day. Good for slow, gentle logic.
  • 3ride.ratings.calculate fires when the game rates a ride. Good for reacting to builds.

Pick the Right Speed
Do not run too often
Locked
🎯
Goal for this step

Choose events that match how often your code needs to run.

  • 1Anything on interval.tick runs constantly. Keep it tiny.
  • 2Anything on interval.day runs rarely. It can do a bit more.
  • 3Rule of thumb: use the slowest event that still does the job.

Different Messages
Make the park talk
Locked
🎯
Goal for this step

Send a different message each time the event fires.

  • 1Keep a counter in your plugin that grows each time the event runs.
  • 2Pick a message based on the counter.
  • 3Use park.postMessage to show it.
var days = 0;
function main() {
  context.subscribe("interval.day", function () {
    days++;
    park.postMessage("Day " + days + " in the park!");
  });
}
registerPlugin({ name: "Day Counter", version: "1.0", authors: ["You"], type: "local", main: main });
