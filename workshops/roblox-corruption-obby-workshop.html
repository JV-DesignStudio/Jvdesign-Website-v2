Design the Failing Simulation
Plan the rule: if corruption catches you, you are reset
Current
🎯
Goal for this step

Create the project structure and the shared settings that control the whole chase.

ThemeNeon digital world, black glass, cyan paths, magenta danger.
PressureThe Corruption Zone moves forward after a short delay.
FailureIf it touches the player, the screen glitches and they respawn.
SkillJumps get harder while the world deletes behind them.
  • 1Open Roblox Studio and create a Baseplate project.
  • 2In Workspace, create folders named NeonMap, DestroyablePlatforms, Checkpoints and Finish.
  • 3In ReplicatedStorage, create a Folder named Remotes. Inside it create a RemoteEvent named CorruptionFX.
  • 4In ReplicatedStorage, create a ModuleScript named CorruptionConfig.
ModuleScript - CorruptionConfig (ReplicatedStorage)
local Config = { CORRUPTION_SPEED = 14, START_DELAY = 4, PLATFORM_BREAK_DELAY = 0.35, PLATFORM_DELETE_DELAY = 1.2, FINISH_Z = 520, } return Config

Build the Neon World
Make a readable third-person path with glowing safe and danger colours
Locked
🎯
Goal for this step

Build a long course that looks like a broken simulation, but still reads clearly while running and jumping.

  • 1Create a Start platform at position 0, 2, 0, size 28, 2, 28, Material Neon, Color cyan.
  • 2Create 30-40 platforms moving forward on the Z axis. Leave gaps, angle a few, and make some thin beams.
  • 3Put every jump platform inside Workspace > DestroyablePlatforms. Keep the Start and Finish platforms outside this folder.
  • 4Add black or very dark purple walls as floating background shapes. Do not make them collide with the player.
  • 5Add small neon magenta cracks: thin Parts placed through platforms like broken code lines.
💡
Readability tip: Safe jumps should glow cyan or green. Danger should glow magenta or red. Do not make everything the same colour.

LocalScript - RunnerFeel (StarterPlayerScripts)
local Players = game:GetService("Players") local player = Players.LocalPlayer local function tune(character) local humanoid = character:WaitForChild("Humanoid") humanoid.WalkSpeed = 22 humanoid.JumpPower = 58 end if player.Character then tune(player.Character) end player.CharacterAdded:Connect(tune)

Make the Corruption Zone
A glowing wall that chases forward and catches slow players
Locked
🎯
Goal for this step

Create the red neon zone that starts behind the player and moves through the course.

  • 1In Workspace, create a Part named CorruptionZone. Size 80, 40, 4, Anchored true, CanCollide false, CanTouch true.
  • 2Set Material to Neon, Color magenta/red, Transparency 0.25.
  • 3Place it at 0, 18, -45, behind the start platform.
  • 4Add this Script to ServerScriptService named CorruptionChase.
Script - CorruptionChase (ServerScriptService)
local RunService = game:GetService("RunService") local ReplicatedStorage = game:GetService("ReplicatedStorage") local Config = require(ReplicatedStorage:WaitForChild("CorruptionConfig")) local fxEvent = ReplicatedStorage.Remotes:WaitForChild("CorruptionFX") local zone = workspace:WaitForChild("CorruptionZone") task.wait(Config.START_DELAY) RunService.Heartbeat:Connect(function(dt) zone.CFrame = zone.CFrame + Vector3.new(0, 0, Config.CORRUPTION_SPEED * dt) end) zone.Touched:Connect(function(hit) local character = hit.Parent local humanoid = character and character:FindFirstChild("Humanoid") if not humanoid or humanoid.Health <= 0 then return end local player = game.Players:GetPlayerFromCharacter(character) if player then fxEvent:FireClient(player) end humanoid.Health = 0 end)

Destroy the World Behind You
Platforms flicker, fall and vanish when the corruption passes them
Locked
🎯
Goal for this step

Make the level genuinely delete itself so players cannot wait forever.

  • 1Make sure all vanishing platforms are inside the DestroyablePlatforms folder.
  • 2Create this Script in ServerScriptService named WorldBreakdown.
Script - WorldBreakdown (ServerScriptService)
local TweenService = game:GetService("TweenService") local ReplicatedStorage = game:GetService("ReplicatedStorage") local Config = require(ReplicatedStorage:WaitForChild("CorruptionConfig")) local zone = workspace:WaitForChild("CorruptionZone") local folder = workspace:WaitForChild("DestroyablePlatforms") local broken = {} local function breakPlatform(part) if broken[part] then return end broken[part] = true local flicker = TweenService:Create(part, TweenInfo.new(Config.PLATFORM_BREAK_DELAY), { Color = Color3.fromRGB(255, 0, 120), Transparency = 0.6 }) flicker:Play() flicker.Completed:Wait() part.Anchored = false part.CanCollide = false task.wait(Config.PLATFORM_DELETE_DELAY) part:Destroy() end while task.wait(0.1) do for _, part in folder:GetChildren() do if part:IsA("BasePart") and part.Position.Z < zone.Position.Z then task.spawn(breakPlatform, part) end end end

Add Corruption Screen FX
Use a RemoteEvent to warn and glitch the caught player
Locked
🎯
Goal for this step

When the player gets caught, show a short local screen effect before they respawn.

  • 1In StarterGui, create a ScreenGui named CorruptionGui.
  • 2Inside it, create a TextLabel named Warning. Text: SIMULATION CORRUPTED. Background red/pink, TextScaled true, Visible false.
  • 3Put this LocalScript inside CorruptionGui.
LocalScript - CorruptionGui script
local ReplicatedStorage = game:GetService("ReplicatedStorage") local Lighting = game:GetService("Lighting") local fxEvent = ReplicatedStorage.Remotes:WaitForChild("CorruptionFX") local warning = script.Parent:WaitForChild("Warning") local blur = Instance.new("BlurEffect") blur.Size = 0 blur.Parent = Lighting fxEvent.OnClientEvent:Connect(function() warning.Visible = true warning.TextTransparency = 0 blur.Size = 18 for i = 1, 8 do warning.Rotation = math.random(-4, 4) warning.TextColor3 = Color3.fromRGB(255, math.random(0, 120), 255) task.wait(0.05) end warning.Visible = false warning.Rotation = 0 blur.Size = 0 end)

Finish Core and Checkpoints
Give the player a goal: shut down the broken simulation

Goal for this step

Add a glowing finish core that announces victory and stops the chase feeling like an endless run.

  • 1Create a Ball Part named SimulationCore near the end of the course. Material Neon, Color white/cyan, Anchored true.
  • 2Create a large Finish platform under it. Put both inside Workspace > Finish.
  • 3Create this Script inside the SimulationCore Part.
Script - inside SimulationCore
local core = script.Parent local won = {} core.Touched:Connect(function(hit) local player = game.Players:GetPlayerFromCharacter(hit.Parent) if not player or won[player] then return end won[player] = true core.Color = Color3.fromRGB(0, 255, 170) core.PointLight.Enabled = true local message = Instance.new("Message") message.Text = player.Name .. " repaired the simulation!" message.Parent = workspace task.wait(4) message:Destroy() end)

Test, Balance and Publish
Tune the speed so the corruption is scary but fair
Locked
🎯
Goal for this step

Run the full course, tune the speed, then publish your neon corruption obby.

  • 1Play from the start. If the corruption catches you before jump 5, lower CORRUPTION_SPEED.
  • 2If the player can wait safely for too long, raise CORRUPTION_SPEED or shorten START_DELAY.
  • 3Test every disappearing platform. The Start and Finish areas should not delete.
  • 4Go to File > Publish to Roblox. Name it something like Corrupted Neon Obby.
