Create the Game Grid
Build an 8×8 grid with random piece types
Active
🎯
Goal for this step

Create a 2D table representing an 8×8 grid filled with random piece types.

📜 board.script — Grid Creation
function init(self) self.cols = 8 self.rows = 8 self.cell_size = 64 self.piece_types = {"red", "blue", "green", "yellow", "purple"} self.grid = {} create_board(self) end function create_board(self) for row = 1, self.rows do self.grid[row] = {} for col = 1, self.cols do self.grid[row][col] = { type = self.piece_types[ math.random(#self.piece_types)], x = col, y = row } end end end
💡
A 2D table is a table of tables. self.grid[row][col] gives you the piece at that position. Row 1 is the top.

Handle mouse/touch input to select a piece and swap it with an adjacent piece.

📜 board.script — Selection & Swap
function on_input(self, action_id, action) if action_id == hash("touch") and action.pressed then local col = math.ceil(action.x / self.cell_size) local row = math.ceil(action.y / self.cell_size) if self.selected then -- Check if adjacent to first selection local dx = math.abs(col - self.selected.x) local dy = math.abs(row - self.selected.y) if (dx == 1 and dy == 0) or (dx == 0 and dy == 1) then swap_pieces(self, self.selected.x, self.selected.y, col, row) end self.selected = nil else self.selected = { x = col, y = row } end end end

📜 Tween Animation System
-- Defold doesn't have built-in tweens -- We create our own simple tween system function tween_position(self, node, target, duration, callback) local start = gui.get_position(node) local elapsed = 0 self.tween_update = function(self, dt) elapsed = elapsed + dt local t = math.min(elapsed / duration, 1) -- Ease-out curve t = 1 - (1 - t) * (1 - t) local pos = start + (target - start) * t gui.set_position(node, pos) if t >= 1 then self.tween_update = nil if callback then callback() end end end end

Goal for this step

Scan the grid to find horizontal and vertical matches of 3 or more identical pieces.

📜 Match Detection Algorithm
function find_matches(self) local matches = {} -- Check horizontal matches for row = 1, self.rows do local count = 1 for col = 2, self.cols do if self.grid[row][col].type == self.grid[row][col-1].type then count = count + 1 else if count >= 3 then for i = col-count, col-1 do table.insert(matches, {x=i, y=row}) end end count = 1 end end if count >= 3 then for i = self.cols-count+1, self.cols do table.insert(matches, {x=i, y=row}) end end end -- Check vertical matches (same logic, different axis) -- ... similar code for columns return matches end

Remove Matches & Drop

Locked
🎯
Goal for this step

Remove matched pieces, make pieces above fall down, and fill empty spaces with new random pieces.

📜 Drop & Fill
function remove_and_drop(self, matches) -- Remove matched pieces for _, pos in ipairs(matches) do self.grid[pos.y][pos.x] = nil end -- Drop pieces down into empty spaces for col = 1, self.cols do local empty = 0 for row = self.rows, 1, -1 do if self.grid[row][col] == nil then empty = empty + 1 elseif empty > 0 then self.grid[row + empty][col] = self.grid[row][col] self.grid[row][col] = nil end end -- Fill top empty spaces with new pieces for row = 1, empty do self.grid[row][col] = { type = self.piece_types[ math.random(#self.piece_types)] } end end end

Chain Reactions

Locked
🎯
Goal for this step

After pieces drop, check for new matches and repeat until no more matches exist.

📜 Chain Reaction Loop
function process_matches(self) local matches = find_matches(self) if #matches > 0 then -- Award points for this match self.combo = self.combo + 1 local points = #matches * 10 * self.combo msg.post("/hud", "add_score", { value = points }) -- Remove, drop, then check again remove_and_drop(self, matches) -- Use timer to wait for drop animation self.chain_timer = 0.3 self.waiting_for_chain = true else self.combo = 0 self.processing = false end end
💡
The combo multiplier increases with each chain reaction. A 3-piece match gives 30 points, but a chain of 2 gives 60!

Goal for this step

📜 Scoring System
-- Scoring formula: -- Base: 10 points per piece in match -- Combo: multiplied by chain number -- Bonus: +50 for matches of 4, +100 for 5+ function calculate_score(self, match_count) local base = match_count * 10 local combo_mult = self.combo local bonus = 0 if match_count == 4 then bonus = 50 elseif match_count >= 5 then bonus = 100 end return base * combo_mult + bonus end

function init(self) self.time_left = 60 self.running = true end function update(self, dt) if self.running then self.time_left = self.time_left - dt if self.time_left <= 0 then self.time_left = 0 self.running = false msg.post("/board", "time_up") end gui.set_text(gui.get_node("timer_text"), tostring(math.ceil(self.time_left))) end end
