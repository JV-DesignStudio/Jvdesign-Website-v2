Questions from Parents

Do I need any coding experience?
None at all. Pico-8 uses simple Lua code that reads almost like English. Each workshop is written for a grown-up and child reading together, with every step explained clearly.
What age is it suitable for?
Episode 1 works well from age 8 with a parent. Later episodes involve more code and logic and suit ages 9-10+ better. Confident readers can do more independently from around age 10.
Do I need to download anything?
Pico-8 is a small download from lexaloffle.com. The free trial lets you do everything in these workshops. The full version costs around £11 and gives you unlimited saving and exporting.
What is Pico-8?
Pico-8 is a "fantasy console" a tiny game engine that looks like retro computers from the 80s. It has a built-in editor, sprite editor, sound editor and runs games at 128x128 pixels with 16 colours. It's perfect for learning.
Do I need to do episodes in order?
No each episode stands alone. But if it's your first time with Pico-8, Episode 1 (Pong) is the gentlest start and teaches the core concepts you'll use in every other game.
Is it really free?
Yes all 6 episodes, forever. No ads, no paywall, no sign-up required. Pico-8 has a free trial version that works perfectly for these workshops.
