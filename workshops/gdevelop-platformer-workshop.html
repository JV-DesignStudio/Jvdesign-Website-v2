Create the Scene & Player
Set up a scene and add the player character
Active
🎯
Goal for this step

Create a new scene and add a player character with the Platformer Character behavior.

  • 1Create a new scene called "Level1".
  • 2Add a Sprite object called "Player". Paint a simple character (about 30x40 pixels).
  • 3Click "Edit object behaviors" and add "Platformer character".
  • 4Place the Player near the bottom-left of the scene.
💡
The Platformer Character behavior gives you jump, gravity and horizontal movement automatically. You don't need to code movement events!

Add Platforms
Create the ground and platforms for the player to jump on
Locked
🎯
Goal for this step

Add platform objects that the player can stand on and jump between.

  • 1Add a Sprite object called "Platform". Paint a brown/green rectangle (at least 100 pixels wide, 20 pixels tall).
  • 2Add the "Platform" behavior to it (different from Platformer Character!).
  • 3Place several instances to create a level: ground at the bottom, floating platforms at various heights.
  • 4Add a "FinishFlag" sprite at the top-right of the level.
👨‍👧
Parent note: There are TWO platform-related behaviors. "Platformer Character" goes on the player. "Platform" goes on the objects the player stands on. Don't mix them up!

Add Player Controls
Map keyboard keys to player movement
Locked
🎯
Goal for this step

Create events so arrow keys move the player and space makes it jump.

  • 1Open the Events Sheet. Add event: Condition "Key pressed: Right". Action: "Simulate a press of the Right key" on Player (Platformer Character).
  • 2Repeat for Left key.
  • 3Add event: Condition "Key pressed: Space". Action: "Simulate a jump" on Player.
🎮 Events — Player Controls
Condition: Key pressed: Right Action: Simulate Right key press on Player (Platformer Character) Condition: Key pressed: Left Action: Simulate Left key press on Player (Platformer Character) Condition: Key pressed: Space Action: Simulate a jump on Player (Platformer Character)

Add Collectible Coins
Place coins for the player to collect
Locked
🎯
Goal for this step

Add coin objects that disappear when the player touches them and add to a score.

  • 1Add a Sprite object "Coin". Paint a yellow circle (about 16x16).
  • 2Place several coins around the level on top of platforms.
  • 3Create scene variable "Score" = 0.
  • 4Add event: Condition "Player is in collision with Coin". Actions: "Delete the Coin", "Change Score: Add 1".

Add Enemies
Create patrolling enemies the player must avoid
Locked
🎯
Goal for this step

Add an enemy that walks back and forth on a platform.

  • 1Add a Sprite object "Enemy". Paint a red enemy (about 24x24).
  • 2Add the "Platformer character" behavior to it too.
  • 3Add a scene variable "EnemyDirection" = 1.
  • 4Event: Condition "Repeat every 0.5 seconds". Action: "Simulate Right key" on Enemy (if direction is 1) or Left (if -1).
  • 5Event: Condition "Enemy is in collision with Platform" AND "Enemy is falling". Action: "Change EnemyDirection: Multiply by -1" (reverses direction).

Player-Enemy Collision
Handle what happens when the player touches an enemy
Locked
🎯
Goal for this step

If the player lands on top of an enemy, destroy it. If hit from the side, restart the level.

  • 1Add event: Condition "Player is in collision with Enemy" AND "Player is falling". Action: "Delete Enemy". This lets you stomp on enemies from above!
  • 2Add event: Condition "Player is in collision with Enemy" AND "Player is NOT falling". Action: "Change scene to Level1" (restart).
💡
"Is falling" checks if the player is moving downward. If you're falling onto an enemy, you stomp it. If you're walking into it from the side, you lose!

Win Condition & Finish Flag
End the level when the player reaches the flag
Locked
🎯
Goal for this step

Detect when the player touches the finish flag and show a win screen.

  • 1Create a "Win" scene with a "You Win!" text and "Press R to play again".
  • 2Add event: Condition "Player is in collision with FinishFlag". Action: "Change scene to Win".
  • 3In the Win scene events: Condition "Key pressed: R". Action: "Change scene to Level1".

Camera Following
Make the camera follow the player through a longer level
Locked
🎯
Goal for this step

Make the camera follow the player so you can build longer levels.

  • 1Make your level wider by adding more platforms to the right.
  • 2Add event: Condition "At the beginning of the scene". Action: "Camera: Follow Player".
  • 3Add event: Condition "At the beginning of the scene". Action: "Camera: Set zoom to 1".
💡
You can also lock the camera's Y position so it only scrolls horizontally. This is great for classic side-scrolling platformers!
🧠
