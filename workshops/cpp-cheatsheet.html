C++ & SFML Cheat Sheet

A one-page printable reference for variables, SFML window setup, drawing shapes, event handling and collision the most-used C++ snippets for 2D games. Pin it next to your monitor!

📦 Variables & Types

int health = 100;
float speed = 4.5f;
std::string playerName = "Pip";
bool isAlive = true;
const int MAX_HP = 100;
auto score = 0; // type inferred as int

Use auto to let the compiler infer the type. const values cannot be changed after declaration.

🪟 SFML Window Setup

#include <SFML/Graphics.hpp>

int main() {
    sf::RenderWindow window(sf::VideoMode({800, 600}), "My Game");
    window.setFramerateLimit(60);

    while (window.isOpen()) {
        // 1. handle events
        // 2. update game logic
        // 3. draw
        window.clear();
        window.display();
    }
    return 0;
}

🎮 Event Handling

#include <optional>

while (const std::optional event = window.pollEvent()) {
    if (event->is<sf::Event::Closed>())
        window.close();

    if (const auto* kp = event->getIf<sf::Event::KeyPressed>()) {
        if (kp->code == sf::Keyboard::Key::Space)
            Jump();
    }
}

Always drain pollEvent() every frame, even if you don't act on every event, otherwise the window appears frozen. SFML 3 renamed the loop, see below.

📐 Vectors & Collision

sf::Vector2f position(100.f, 200.f);
sf::Vector2f velocity(2.f, 0.f);
position += velocity;

if (playerSprite.getGlobalBounds()
        .findIntersection(enemySprite.getGlobalBounds())) {
    // collision happened! (SFML 3 renamed intersects → findIntersection)
    TakeDamage();
}

🛠️ Common Patterns: Minimal SFML Game Loop

#include <SFML/Graphics.hpp>

int main() {
    sf::RenderWindow window(sf::VideoMode({800, 600}), "Mini Game");
    window.setFramerateLimit(60);

    sf::RectangleShape player({40.f, 40.f});
    player.setFillColor(sf::Color::Cyan);
    player.setPosition({380.f, 280.f});

    float speed = 3.f;

    while (window.isOpen()) {
        while (const std::optional event = window.pollEvent()) {
            if (event->is<sf::Event::Closed>())
                window.close();
        }

        if (sf::Keyboard::isKeyPressed(sf::Keyboard::Key::Right))
            player.move({speed, 0.f});
        if (sf::Keyboard::isKeyPressed(sf::Keyboard::Key::Left))
            player.move({-speed, 0.f});

        window.clear(sf::Color::Black);
        window.draw(player);
        window.display();
    }
    return 0;
}
