Find the Right Guest
Loop and filter
Active

Goal for this step

Loop over guests and pick out the unhappy ones.

  • 1Get all guests with map.getAllEntities("guest").
  • 2Each guest has a happiness value.
  • 3Collect the ones below a threshold into a shortlist.
var guests = map.getAllEntities("guest");
var sad = guests.filter(function (g) { return g.happiness < 100; });
