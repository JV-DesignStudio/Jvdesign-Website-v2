# Traffic Dash

Dodge the traffic for 45 seconds, then bank the finish bonus.

- Left and Right arrow keys or A and D steer.
- R or Enter restarts after a crash or the finish.
- Press Play in the Godot Lab. No download needed.

Ideas to make it yours:

1. Change `RUN_TIME` in `game.gd` to make the run longer or shorter.
2. Add a fourth lane by adding an x value to `LANES`.
3. Change `BASE_SPEED` to make the traffic faster.
4. Draw new cars in `main.tscn` and `traffic.tscn`.

Lumo says: change one number, press Play, and see what happens.
