The Name Tag: manifest.json
The fields every manifest needs
Locked
🎯
Goal for this step

Read a manifest and know what each field is for.

  • 1Name: what shows in the SMAPI list. Author: you.
  • 2Version: like 1.0.0. Bump it when you change the mod.
  • 3UniqueID: a one-of-a-kind id, usually YourName.ModName. No two mods may share it.
  • 4ContentPackFor: tells SMAPI that Content Patcher should read your content file.
manifest.json
{
  "Name": "My First Farm",
  "Author": "You",
  "Version": "1.0.0",
  "UniqueID": "You.MyFirstFarm",
  "ContentPackFor": { "UniqueID": "Pathoschild.ContentPatcher" }
}
✏️

The Change List: content.json
A list of edits the game applies in order
Locked
🎯
Goal for this step

Understand that content.json is a list of actions.

  • 1content.json holds a Format version and a list of Changes.
  • 2Each change has an Action (what to do, e.g. Load or EditMap) and a Target (which game file to touch).
  • 3FromFile points at your own file in the assets folder to load in place of the game's.
  • 4Content Patcher reads this list and applies it without ever damaging the real game files.
content.json (a Load change)
{
  "Format": "2.9.0",
  "Changes": [
    {
      "Action": "Load",
      "Target": "Maps/Farm",
      "FromFile": "assets/maps/Farm.tmx"
    }
  ]
}

The assets Folder
Where your maps and images live
Locked
🎯
Goal for this step

Know where your world files sit inside the mod.

  • 1The assets folder holds the files you made: maps, tilesheets, images.
  • 2Keeping maps in assets/maps and images in assets/images keeps a mod tidy.
  • 3A map file ends in .tmx. That is the Tiled map you will edit from Episode 3.
  • 4FromFile in content.json points here, so the paths must match exactly.
A tidy content pack
MyFirstFarm/
├── manifest.json
├── content.json
└── assets/
    ├── maps/
    │   └── Farm.tmx
    └── images/
        └── CustomBed.png

How SMAPI Loads It
Follow the chain from folder to game
Locked
🎯
Goal for this step

Picture the load chain so you can debug it later.

  • 1SMAPI scans the Mods folder and reads each manifest.json.
  • 2Because your manifest says ContentPackFor Content Patcher, SMAPI hands your folder to Content Patcher.
  • 3Content Patcher reads your content.json and applies each change at the right moment.
  • 4The game then loads the edited content. Your mod never overwrote the real files.

Spot Your Mod in the Log
Use LogName to find it fast
Locked
🎯
Goal for this step

Add a LogName so your mod is easy to find in the console.

  • 1Add a LogName to content.json. It is the friendly label that appears in the console.
  • 2Launch the game and look for that label in the SMAPI window.
  • 3If it is there, your mod is loading. If it is missing, the folder or manifest has a problem.
  • 4This one label turns every future error into a five-second check.
content.json (top of file)
{
  "Format": "2.9.0",
  "LogName": "My First Farm",
  "Changes": [ /* ... */ ]
}
✏️
