Echo's Debug It

Debug It: The score that never wins

Collecting all ten coins should show the win message, but the build fails with an error instead.

if score = 10 then
    msg.post("#", "win")
end
  1. What did you expect? The win message appears at ten coins.
  2. What happened instead? The project will not build, and the error points at this line.
  3. What evidence tells you where the problem is? Read the build error: it names the line and says it found an unexpected symbol near '='.
Hint 1: a nudge

Lua uses a different symbol for comparing two values than for storing one.

Hint 2: what to look for

In Lua a single = assigns a value. Comparing needs ==. The compiler reads score = 10 as an assignment inside a condition and rejects it.

Full answer

Use a comparison: if score == 10 then. If the win screen already appeared you can also guard it with if score >= 10 and not won then.

Try the hints before the answer. Finding the bug is the skill, the fix is the easy part.
