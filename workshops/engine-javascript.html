Your JavaScript pathway

Five steps from your first game to a finished project you can keep. Start at step 1, or jump to the step that matches you.

  1. 1 Make your first game Flappy Bird, Episode 1 Simple controls and instant results. Build a game that runs in your browser. Open stage 1 →

    Next: Learn the code

  2. 2 Learn the code Memory Match, Episode 2 Variables, conditions, functions and loops, learned by building a real game. Open stage 2 →

    Next: Build a complete game

  3. 3 Build a complete game Breakout, Episode 3 Paddle, ball, bricks, lives and scoring. A full game loop you can play. Open stage 3 →

    Next: Make it yours

  4. 4 Make it yours Snake, Episode 4 Change the colours, speed and rules, then test your own version. Open stage 4 → Pixel Studio SFX Studio Colour Palette Logo Maker

    Next: Play, test and export

  5. 5 Play, test and export Platformer, Episode 5 Add gravity and jumping, playtest it, then download your game to keep. Open stage 5 →

    Keep going: add coins and enemies

Finished? Check your game:

  • It starts and you can play it.
  • The core mechanics work: movement, collisions and scoring.
  • At least one choice is yours: colours, speed, character or sound.
  • You playtested it and fixed one bug.
  • You saved or downloaded the project so you can come back to it.

Then keep building with Episode 6: add coins and enemies, or pick another engine from the full workshop hub.
