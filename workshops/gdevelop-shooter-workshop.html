Goal for this step

Create a new scene with a spaceship the player can move left, right, up and down.

Add Shooting
Create bullets that fire when the player presses Space
Locked
🎯
Goal for this step

Create a bullet object that spawns at the player's position and moves upward.

  • 1Add a Sprite object "Bullet". Paint a small yellow/white projectile.
  • 2Add event: Condition "Key pressed: Space". Actions: "Create object Bullet at position of Player", then "Add force to Bullet: X=0, Y=-400".
  • 3Add event: Condition "Bullet Y position < -20". Action: "Delete Bullet" (remove off-screen bullets).
💡
To prevent holding Space and firing hundreds of bullets, add a timer. Create event: Condition "Timer "ShootCooldown" > 0.2". Put the shoot action inside it, then reset the timer.

Add Enemy Spawning
Create enemies that appear at the top and drift downward
Locked
🎯
Goal for this step

Use a timer to spawn enemy objects at random positions at the top of the screen.

  • 1Add Sprite object "Enemy". Paint a red alien shape.
  • 2Add event: Condition "Repeat every 1.5 seconds". Action: "Create Enemy at position (Random(0 to 800), -30)".
  • 3Add event: Condition "Always". Action: "Change Enemy Y position: Add 100" (makes them drift down).
  • 4Add event: Condition "Enemy Y position > 620". Action: "Delete Enemy".
⚡

Bullet-Enemy Collision
Destroy enemies when bullets hit them
Locked
🎯
Goal for this step

Detect when a bullet hits an enemy, delete both and add to score.

  • 1Create variable "Score" = 0.
  • 2Add event: Condition "Bullet is in collision with Enemy". Actions: "Delete Bullet", "Delete Enemy", "Change Score: Add 1".
💡
Want explosions? Before deleting the enemy, create a "Explosion" sprite at the enemy's position and delete it after 0.3 seconds using a timer!

Wave System & Difficulty
Make the game harder over time with enemy waves
Locked
🎯
Goal for this step

Track waves and increase enemy speed and spawn rate as waves progress.

  • 1Create variables: "Wave" = 1, "EnemySpeed" = 100, "SpawnRate" = 1.5.
  • 2Event: Condition "Score = Wave ✨ 5". Actions: "Change Wave: Add 1", "Change EnemySpeed: Add 20", "Change SpawnRate: Subtract 0.1" (min 0.3).
  • 3Use EnemySpeed in the "Always" event that moves enemies downward.
  • 4Use SpawnRate in the "Repeat every" timer event.

Power-Ups
Add collectible power-ups that help the player
Locked
🎯
Goal for this step

Create a power-up that temporarily makes the player shoot faster or wider.

  • 1Add Sprite object "PowerUp". Paint a blue/green gem.
  • 2Event: Condition "Repeat every 10 seconds". Action: "Create PowerUp at random position at top".
  • 3Event: Condition "Player collides with PowerUp". Actions: "Delete PowerUp", "Change variable ShootSpeed: Set to 0.1" (faster shooting).
  • 4Add a timer event that resets ShootSpeed after 5 seconds.

Lives & Game Over
Add lives and detect when the player is hit
Locked
🎯
Goal for this step

Give the player 3 lives. Lose a life when an enemy reaches the bottom. Game over at zero.

  • 1Create variable "Lives" = 3. Add a Text object "LivesText" to display it.
  • 2Event: Condition "Enemy Y position > 620" (before deleting). Action: "Change Lives: Subtract 1".
  • 3Event: Condition "Lives < 1". Action: "Change scene to GameOver".
🧠
