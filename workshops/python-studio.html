How to run your project

  1. Install Python 3 from python.org (free).
  2. In a terminal, install Pygame: pip install pygame.
  3. Unzip the download and run python main.py.
  4. To change the game, edit main.py and run it again. That is the same code you tuned here.
🦊
Lumo says: every Pygame game is the same four steps repeating forever. Once you know the loop, you can read almost any game.

The Pygame game loop

  1. Get the events. Check what the player did (closed the window, pressed a key, clicked).
  2. Update the world. Move the player, the ball, the enemies, and check for collisions.
  3. Draw the screen. Fill the background, then draw everything in its new place.
  4. Flip and wait. pygame.display.flip() shows the frame, and clock.tick(60) keeps it at 60 frames a second.

The loop runs in a while True: block, so it repeats until the player quits. Every game on the series uses this exact shape.
