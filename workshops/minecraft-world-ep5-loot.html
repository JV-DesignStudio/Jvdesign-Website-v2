Pools and Rolls

Goal for this step

Write a simple pool.

  • 1pools is a list. Each pool has rolls and entries.
  • 2rolls is how many times it draws from the entries.
  • 3An entry can be an item, and can have a weight to make it rare.
{
  "type": "minecraft:block",
  "pools": [{
    "rolls": 1,
    "entries": [
      { "type": "minecraft:item", "name": "minecraft:diamond", "weight": 1 },
      { "type": "minecraft:item", "name": "minecraft:coal", "weight": 5 }
    ]
  }]
}

Goal for this step

Understand chance and stacking.

  • 1A lower weight means a lower chance.
  • 2You can give a drop a range of counts, like 1 to 3.
  • 3Test by breaking the block many times and counting the drops.
