Open Pico-8 & Start a New Cartridge
Launch Pico-8 and create a blank Lua file
Active
🎯
Goal for this step

Get Pico-8 open with a blank cartridge ready to write code in.

👨‍👧
Parent note: Pico-8 is a small program you download from lexaloffle.com/pico-8.php. The free trial works perfectly for all these workshops. It costs around £11 for the full version but you don't need it yet.

Get started

  • 1Open Pico-8 from your Start Menu or Applications folder. A black console window appears.
  • 2Type folder and press Enter. This opens the Pico-8 cart data folder where your games are saved.
  • 3In the Pico-8 console, type code and press Enter. This opens the code editor.
  • 4You'll see an empty code editor. The editor has tabs: CODE, SPRITE, MAP, SFX, and MUSIC.
  • 5Pico-8 games use three special functions: _init() (runs once), _update() (runs 30 times per second), and _draw() (draws the screen).
📝 Basic Pico-8 Structure
-- pong.p8 function _init() -- runs once at start end function _update() -- runs 30x per second end function _draw() -- draws the screen end
💡
Type this basic structure into your code editor. Press Ctrl+S to save, then Esc to return to the console and type run to test. You should see a black screen!

Draw the Paddles
Create two paddles on screen using rect()
Locked
🎯
Goal for this step

Draw a white paddle on each side of the screen that the player can move up and down.

Set up paddle variables and draw them

  • 1In _init(), create variables for the paddle positions. We'll use py1 for the left paddle's Y position and py2 for the right paddle.
  • 2Set both to 54 so they start in the middle of the 128-pixel screen.
  • 3In _draw(), use cls(0) to clear the screen black, then rectfill() to draw each paddle as a white rectangle.
  • 4The paddles are 3 pixels wide and 20 pixels tall. Left paddle at x=2, right paddle at x=123.
📝 Pong - Draw Paddles
function _init() -- paddle y positions py1=54 -- left paddle py2=54 -- right paddle end function _draw() cls(0) -- clear screen black -- left paddle (white) rectfill(2,py1,4,py1+19,7) -- right paddle (white) rectfill(123,py2,125,py2+19,7) end
💡
Pico-8 screen is 128x128 pixels. Colours are numbered 0-15. Colour 7 is white. rectfill(x1,y1,x2,y2,col) draws a filled rectangle.

Move the Paddles
Use btn() to detect arrow key input
Locked
🎯
Goal for this step

Make the left paddle move with arrow keys and the right paddle with X and Z buttons.

Add input handling

  • 1In _update(), use btn(2) and btn(3) to check if UP or DOWN is pressed.
  • 2btn(0)=left, btn(1)=right, btn(2)=up, btn(3)=down, btn(4)=Z/C, btn(5)=X
  • 3Move py1 up/down by 2 pixels. Use if py1<0 then py1=0 end to keep it on screen.
  • 4For the right paddle, use btn(4) and btn(5) or add a second set of keys.
📝 Pong - Paddle Movement
function _update() -- left paddle: arrow keys if btn(2) then py1=py1-2 end if btn(3) then py1=py1+2 end -- keep paddle on screen if py1<0 then py1=0 end if py1>108 then py1=108 end -- right paddle: z/x keys if btn(4) then py2=py2-2 end if btn(5) then py2=py2+2 end if py2<0 then py2=0 end if py2>108 then py2=108 end end
💡
108 is 128 minus 20 (paddle height). This keeps the paddle from going off the bottom of the screen!

Add the Ball
Create a ball that moves and bounces off walls
Locked
🎯
Goal for this step

Add a ball with position, speed and direction that bounces off the top and bottom walls.

Create the ball

  • 1In _init(), add ball variables: bx (x position), by (y position), bdx (x speed), bdy (y speed).
  • 2Set bx=63, by=63 (centre), bdx=2, bdy=1.
  • 3In _draw(), add circfill(bx,by,2,7) to draw a white filled circle.
  • 4In _update(), move the ball: bx=bx+bdx and by=by+bdy.
  • 5Add wall bounce: if by<1 or by>126 then bdy=-bdy end
📝 Pong - Ball Movement
function _init() py1=54 py2=54 bx=63 by=63 bdx=2 bdy=1 end function _update() -- move ball bx=bx+bdx by=by+bdy -- bounce off top/bottom if by<1 or by>126 then bdy=-bdy end end function _draw() cls(0) rectfill(2,py1,4,py1+19,7) rectfill(123,py2,125,py2+19,7) circfill(bx,by,2,7) end

Paddle Collision & Bounce
Make the ball bounce off the paddles
Locked
🎯
Goal for this step

Detect when the ball hits a paddle and reverse its direction.

Add collision detection

  • 1We need to check: is the ball overlapping the left paddle? Use bx<6 and by>=py1 and by<=py1+19.
  • 2When it hits, set bx=5 (push it back) and bdx=-bdx (reverse direction).
  • 3Do the same for the right paddle with bx>121 and by>=py2.
  • 4Add a score variable: sc1 and sc2. When the ball goes past a paddle, add a point and reset the ball.
📝 Pong - Collision & Score
function _init() py1=54 py2=54 bx=63 by=63 bdx=2 bdy=1 sc1=0 sc2=0 end function _update() bx=bx+bdx by=by+bdy -- bounce top/bottom if by<1 or by>126 then bdy=-bdy end -- left paddle bounce if bx<6 and by>=py1 and by<=py1+19 then bdx=-bdx bx=5 end -- right paddle bounce if bx>121 and by>=py2 and by<=py2+19 then bdx=-bdx bx=122 end -- scoring if bx<0 then sc2=sc2+1 bx=63 by=63 bdx=2 bdy=1 end if bx>128 then sc1=sc1+1 bx=63 by=63 bdx=-2 bdy=1 end end

Draw the Score
Display the score on screen for both players
Locked
🎯
Goal for this step

Show the score at the top of the screen so both players can see who's winning.

Add score display

  • 1In _draw(), use print(sc1, 54, 6, 7) to draw player 1's score near the left.
  • 2Use print(sc2, 70, 6, 7) for player 2's score near the right.
  • 3Add a centre line using a loop: for i=0,128,8 do pset(64,i,5) end
  • 4Colour 5 is grey, which makes a nice dashed centre line.
📝 Pong - Score Display
function _draw() cls(0) -- dashed centre line for i=0,128,8 do pset(64,i,5) end -- draw score print(sc1,54,6,7) print(sc2,70,6,7) -- draw paddles and ball rectfill(2,py1,4,py1+19,7) rectfill(123,py2,125,py2+19,7) circfill(bx,by,2,7) end

Add a Computer Opponent
Make the right paddle follow the ball automatically
Locked
🎯
Goal for this step

Add simple AI so the right paddle automatically follows the ball, making it a single-player game.

Simple AI movement

  • 1Remove the btn(4)/btn(5) controls for the right paddle.
  • 2Replace them with: if py2+10<by then py2=py2+1.5 end
  • 3And: if py2+10>by then py2=py2-1.5 end
  • 4This makes the AI paddle slowly follow the ball's Y position. The 1.5 speed makes it beatable!
📝 Pong - AI Paddle
function _update() -- left paddle: arrow keys if btn(2) then py1=py1-2 end if btn(3) then py1=py1+2 end if py1<0 then py1=0 end if py1>108 then py1=108 end -- right paddle: simple ai if py2+10<by then py2=py2+1.5 end if py2+10>by then py2=py2-1.5 end if py2<0 then py2=0 end if py2>108 then py2=108 end end
💡
Try changing the AI speed! Use 1 for easy, 2 for hard. The AI is always slightly slower than the player's paddle (which moves at 2).

Add Sound & Polish!
Add sound effects and a title screen
Locked
🎯
Goal for this step

Add sound effects when the ball bounces and scores, plus a simple title screen to make the game feel complete.

Add sound effects

  • 1In the Pico-8 editor, click the SFX tab. Create a short "blip" sound effect.
  • 2In your code, add sfx(0) when the ball bounces off a paddle (sfx number 0).
  • 3Create a different sound for scoring and play it with sfx(1).
  • 4Add a title screen variable: title=true in _init(). When title is true, show "PONG" text and wait for Z button press.
📝 Pong - Title Screen
function _init() title=true py1=54 py2=54 bx=63 by=63 bdx=2 bdy=1 sc1=0 sc2=0 end function _update() if title then if btnp(4) then title=false end return end -- rest of game code here end function _draw() if title then cls(0) print("🏓 pong",42,40,7) print("press z to start",26,70,6) return end -- rest of draw code here end
