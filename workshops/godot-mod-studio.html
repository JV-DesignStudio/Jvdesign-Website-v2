Echo's recovery check

Stuck? Try this

These are the three things that most often stop a first Godot Studio session. Check the symptom first, then try the fix.

The editor will not load

What you'll see: the loading bar stops, or a warning says service workers are blocked.

Fix: the real editor needs internet and about 96 MB the first time. Try again on a home connection, or use the offline Godot hub.

My project will not open

What you'll see: Godot asks for a project and nothing appears in the list.

Fix: press Import and pick project.godot, not the folder. In the browser editor, choose Load starter project instead.

The game runs but the scene is empty

What you'll see: the game window opens with nothing in it.

Fix: check the main scene in Project > Project Settings > Run. Press F5, then read the first red line in the Output panel.

Still stuck? Reread the step, open the engine cheat sheet, or ask an adult to sit with you.

🛠️ Open the Godot editor ⬇ Download the starter project

Needs internet and about 96 MB the first time. If your school blocks it, use the offline Godot hub.

What you get

The starter project has everything you need to see a game run:

  • A player that moves with the arrow keys
  • A coin that is picked up when you touch it
  • Ground to stand on
  • Two GDScript files you can read and change

Open it in the editor, or download it and import project.godot in Godot on a computer.

Your first 10 minutes

  1. Open the editor and choose Load starter project.
  2. Press Play, move with the arrow keys and collect the coin.
  3. Open player.gd, change the speed number, then press Play again.
  4. Download your project so you can keep it or open it in Godot at home.

Read the Output panel

When something breaks, Godot prints the reason at the bottom of the editor. Read the first red line. These are the ones you will meet first.

Identifier "speed" not declared: the script uses a name before it exists. Add var speed = 200.0 near the top.

Cannot call method "move_and_slide" on a null instance: the node is not ready yet. Call it inside _physics_process(delta).

Cannot open file res://player.gd: the file name and the path in the scene must match exactly, including case.

What is inside a Godot project

project.godot tells Godot this folder is a project and which scene to run.

main.tscn is the scene: the player, coin and ground with their positions.

player.gd and coin.gd are the scripts that make things happen.

To open it yourself: Godot > Import > pick project.godot, then press F5.
