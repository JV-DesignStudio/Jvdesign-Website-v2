C++ Mod Studio
Build an SFML game in your browser

A little project maker for the C++ World Workshop. Lay out a game level on a grid, tick the SFML features you want, read a broken compiler error and choose the fix, then download a real C++ project you can build on any computer with a compiler.

🛠️ Open the Studio ← Back to the C++ World Workshop
Make your own art and sounds: draw sprites in Pixel Studio and make music or sound effects in Sound Studio, then bring them into your project.
Ember says: a C++ game is a window, an event loop and some shapes you draw again and again. This studio writes the whole main.cpp for you, using the level you build, so your first build is not an empty screen. Your work saves automatically.

Lay out your level

Pick an object below, then click squares on the grid to place it. Put the Player where you start and the Goal at the end. Click a square again, or use the eraser, to remove it.

Objects

Your level so far

      How this maps to real C++
      
        
      
          
      main.cpp is your whole game: a window, an event loop and drawing.
      
          
      sf::RectangleShape is a rectangle. Each object you placed is one.
      
          
      sf::RenderWindow is the game window. window.draw puts a shape on it.
      
          
      Build it: install a compiler and SFML, then use the CMakeLists.txt in the zip.
