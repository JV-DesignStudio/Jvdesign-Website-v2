Download Python from python.org and tick "Add Python to PATH". It is the language all these games are written in.

🎮
Pygame (Free)

Questions & Answers

Do I need to know Python before starting?
No. Episode 1 starts with installing Python and Pygame and writing your first game window. We explain everything as we go.
Is Python really free?
Yes. Python and the Pygame library are both completely free and open-source.
What will I build?
A fruit-catch game, a platformer, a dodge-and-collect game, a maze with a chasing ghost, a Breakout clone with power-ups, and a scrolling platformer with enemies and checkpoints.
What age is it suitable for?
Ages 10+ works well. Python reads almost like English, which makes it one of the friendliest first text languages.
Do the workshops save my progress?
Yes. Each workshop tracks XP, streaks and completed steps, and reports to the My Progress page for badges and certificates.
Is it really free?
All 7 episodes, forever. No ads, no paywall, no sign-up needed.
