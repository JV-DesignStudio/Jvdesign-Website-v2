Questions & Answers

Do I need to know Java before starting?
No. Episode 1 starts with installing Java and writing your very first program. We explain every keyword and line as we go.
Is Java really free?
Yes. The JDK (from Adoptium/Eclipse Temurin) and editors like VS Code and IntelliJ Community are all completely free.
What will I build?
A platformer, a brick breaker, a space shooter, Pong with an AI opponent, and a full three-part RPG with a map, monsters, combat and a dragon boss.
What age is it suitable for?
Ages 11+ works well. Java is more text-heavy than Scratch or GameMaker, so it suits learners comfortable typing and reading code carefully.
Do the workshops save my progress?
Yes. Each workshop tracks your XP, streaks and completed steps, and reports to the My Progress page where you can earn badges and certificates.
Is it really free?
All 7 episodes, forever. No ads, no paywall, no sign-up needed.
