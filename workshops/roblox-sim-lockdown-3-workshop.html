Hand Out the Gauntlet
A Tool every player holds, with a glowing Handle
Active
🎯
Goal for this step

A tool called the Glitch Gauntlet, given to every player when a round begins.

  • 1A Tool is a held item in Roblox. It needs a child part called exactly Handle.
  • 2When the player clicks or taps the tool, the Activated event fires. That is our shove.
  • 3We build the tool in code on the server and put it in the player's Backpack.
ObbyServer (Script)
local function giveGauntlet(player) local backpack = player:FindFirstChildOfClass("Backpack") if not backpack then return end local tool = Instance.new("Tool") tool.Name = "Glitch Gauntlet" local handle = Instance.new("Part") handle.Name = "Handle" handle.Size = Vector3.new(1.2, 1.2, 1.6) handle.Color = Color3.fromRGB(255, 60, 90) handle.Material = Enum.Material.Neon handle.Parent = tool tool.Parent = backpack tool.Activated:Connect(function() shove(player) -- step 2 fills this in end) end
💡
Run giveGauntlet(player) for every player at the start of a round. On a phone the player taps the tool icon in their hotbar, on a computer they click, and on a controller they press the button. One tool, every device.

The Shove
Push everyone in front of you away, hard enough to send them off the edge
Locked
🎯
Goal for this step

Find nearby players in a cone in front of you and launch them away.

  • 1Loop over every other player and measure the distance to them.
  • 2Check they are in front of you using the dot product of your facing direction.
  • 3Add a burst of speed to their character, away from you and slightly upward.
ObbyServer (Script)
local Players = game:GetService("Players") local RANGE, POWER, UP = 14, 65, 16 local function shove(player) local root = player.Character.HumanoidRootPart local origin = root.Position local look = root.CFrame.LookVector for _, other in ipairs(Players:GetPlayers()) do if other ~= player then local otherRoot = other.Character and other.Character:FindFirstChild("HumanoidRootPart") if otherRoot then local away = otherRoot.Position - origin if away.Magnitude <= RANGE and look:Dot(away.Unit) >= 0.35 then otherRoot.AssemblyLinearVelocity = away.Unit * POWER + Vector3.new(0, UP, 0) end end end end end
💡
The dot product is a maths trick that tells you the angle between two directions. A value near 1 means "right in front of me", near 0 means "to the side", negative means "behind me". We accept anything above 0.35, so a wide cone in front.
🎨
Keep the map readable while people shove. Red parts are lethal, yellow parts move or are about to fire, green is safe. A warning beacon glows before a timed trap fires, so being pushed into a red bar is a mistake, not a coin flip. Show the same legend in the lobby so nobody has to guess.

Rank and Eliminate
Keep the fastest players, remove the rest, send them to spectate
Locked
🎯
Goal for this step

At the end of a round, put the players in order and cut the bottom of the list.

  • 1Collect every player with how far along the course they got.
  • 2Sort them, best first, with table.sort.
  • 3Keep the top slice and mark everyone else as eliminated.
ObbyServer (Script)
local function rankAndCut(field, keep) table.sort(field, function(a, b) return a.progress > b.progress -- further along = better end) local survivors = {} for i, entry in ipairs(field) do if i <= keep then survivors[#survivors + 1] = entry.player else eliminate(entry.player) -- out of the match end end return survivors end
💡
How big is keep? Make it a percentage that scales with the crowd. With 8 players keep about 5, with 40 keep about 20. Never let it drop below the number you need for the final. Our Config says FINAL_SIZE = 5.
🎲
One twist per match. Before round one, roll a single mutator and announce it: SPEED RUSH (everyone walks faster), LOW GRAVITY (higher, floatier jumps), or RISING DELETION (the kill plane climbs after 12 seconds, capped 10 studs below the lowest deck). One at a time, never stacked, and always shown in the HUD. A twist players cannot see is just a bug.

Build the Final Arena
A grid of tiles with a ring number, ready to be eaten away
Locked
🎯
Goal for this step

A circular-looking platform built from square tiles, each tagged with a ring number.

  • 1Make a grid from -6 to 6 in both directions. That is a 13 by 13 floor.
  • 2For each tile work out its ring, how far it is from the centre.
  • 3Store the ring on the tile with SetAttribute, so we can find and remove the outer ring later.
MapGen (ModuleScript)
function mapgen.buildArena(parent) local rings = 6 for gx = -rings, rings do for gz = -rings, rings do local ring = math.max(math.abs(gx), math.abs(gz)) local tile = newPart(parent, Vector3.new(12, 2, 12), Vector3.new(gx * 12, 0, gz * 12), palette[ring + 1]) tile:SetAttribute("Ring", ring) end end end
💡
The centre tile is ring 0. Everything around it is ring 1, then ring 2, and so on out to ring 6 at the edge. Deleting a whole ring at once gives you that shrinking battle-royale feel.

The Arena Shrinks
Every few seconds the outer ring falls away, until one player is left
Locked
🎯
Goal for this step

Delete the outermost ring on a timer and crown the last player standing.

  • 1Count down, and when the timer hits zero remove the highest ring left.
  • 2Anyone standing on the fallen ring drops into the void and is out.
  • 3Stop when one player remains. They are the champion.
ObbyServer (Script)
local ring = 6 while #alive > 1 do task.wait(11) -- SHRINK_EVERY seconds shrinkRing(ring) ring = ring - 1 end local function shrinkRing(n) for _, tile in ipairs(arenaFolder:GetChildren()) do if tile:GetAttribute("Ring") == n then tile:Destroy() -- the edge falls away end end end
🔧
Players who fall below the arena should be knocked out. Check root.Position.Y each frame; if it drops below the arena, that player is out. Do not respawn them, this is the final.
👨‍👧
Tip for a fair final: give the gauntlet a small damage value in the final too, so a well-timed shove can knock someone out. Around 34 damage, so three hits finishes them. That keeps it a real deathmatch, not just a pushing contest.

Champion and Publish
Show the winner, then publish your game for friends to play
Locked
🎯
Goal for this step

Celebrate the winner and put your game online.

  • 1Set a Won attribute on the champion and fire a RemoteEvent so their screen shows a big banner.
  • 2Click File then Publish to Roblox, give the game a name and a description.
  • 3Set it to Public in Game Settings so anyone can join, then test it from the Roblox website.
ObbyServer (Script)
local function crown(champion) champion:SetAttribute("Won", true) event:FireAllClients("Champion", champion.Name) end
