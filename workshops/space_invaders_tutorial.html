Stuck? Try these fixes first

Red error in the Output panel

What you'll see: a red line naming a file and line number.

Fix: Open that exact file, go to that line, and read what it says. The error message tells you what went wrong. Fix the typo or missing piece it points to.

Aliens not moving

What you'll see: aliens appear but stay frozen.

Fix: Check that AlienGrid.gd is attached to the AlienGrid node (not just saved as a file). Click the AlienGrid node in the Scene tree and look for the script icon.

Player can't shoot

What you'll see: pressing Space does nothing.

Fix: Open Main.gd and check that $Player.player_shot.connect(_on_player_shoot) is in _ready(). Also check Player.gd has a signal player_shot line at the top.

Score not updating

What you'll see: you shoot aliens but the score stays at 0.

Fix: Go to Project → Project Settings → Autoload and make sure GameState.gd is listed and enabled. The checkbox must be ticked.

Game won't run at all

What you'll see: pressing F5 does nothing or shows "No main scene set".

Fix: Go to Project → Project Settings → Application → Run and set Main Scene to Main.tscn.

Still stuck? Reread the step, check the checkpoint list, or ask an adult to sit with you.

Setting Up Godot
Download and configure Godot 4 for your Space Invaders project
Active
🎯
Goal: Godot installed and project created

We'll download Godot 4, create a new project, and set the window size for a classic arcade game.

Godot is a free program that turns your code into a real game. It handles the window, graphics, sounds all the boring stuff. You focus on the fun part: telling the game what to DO.
  1. 1Go to godotengine.org → Download Godot 4 for your computer → Open it
  2. 2In the Project Manager, click New Project → name it "Space Invaders" → Click Create & Edit
  3. 3Click Project → Project Settings → Display → Window → Set width to 480, height to 600, Stretch Mode to canvas_items

The Game State Script
Create a persistent script for score, lives and wave number
Locked
🎯
Goal: A GameState Autoload script

Before building anything visible, create a script that remembers the score, lives, and wave number.

A normal script only works while its scene is open. An Autoload script runs all the time, forever. Perfect for score and lives, because they need to survive scene changes.
GameState.gd
# GameState.gd, type this exactly
extends Node

# var creates a variable, a box that holds a number
var score: int = 0
var lives: int = 3
var wave:  int = 1
var hi_score: int = 0
  1. 1FileSystem panel → right-click res:// → New Script → name it GameState.gd → type the code above
  2. 2Press Ctrl+S to save
  3. 3Project → Project Settings → Autoload tab → add GameState.gd → click Add
GameState.gd saved · Appears in Autoload list · No red error lines

The Player Ship
Build a ship that moves and shoots with keyboard controls
Locked
🎯
Goal: A controllable player ship

The player ship moves left/right and fires bullets. It's built from three nodes stacked together.

Three nodes needed: Area2D (the container, detects when things touch it), Sprite2D (shows the ship picture), CollisionShape2D (invisible hit shape).
  1. 1Scene → New Scene → add Area2D root → rename it "Player"
  2. 2Add Sprite2D child → add CollisionShape2D child → set shape to RectangleShape2D
  3. 3Save as Player.tscn → attach a new script Player.gd
Player.gd
# Player.gd
extends Area2D
const SPEED = 180.0
const SCREEN_W = 480.0
var can_shoot = true

func _process(delta):
    var dir = int(Input.is_action_pressed("ui_right")) - int(Input.is_action_pressed("ui_left"))
    position.x = clamp(position.x + dir * SPEED * delta, 20, SCREEN_W - 20)
    if Input.is_action_just_pressed("ui_accept") and can_shoot:
        shoot()
Player.tscn and Player.gd saved · No red error lines

The Bullet Scene
One bullet scene reused for both player and enemy fire
Locked
🎯
Goal: A reusable bullet

Both the player and the aliens fire bullets. Build one bullet scene and reuse it for both, just change the direction.

Bullet.gd
# Bullet.gd
extends Area2D
# -1.0 = flies UP (player)  +1.0 = flies DOWN (enemy)
@export var direction: float = -1.0
@export var speed: float = 400.0
@export var is_enemy: bool = false

func _process(delta):
    position.y += speed * direction * delta
    # Delete bullet when it leaves the screen
    if position.y < -20 or position.y > 650:
        queue_free()
💡
queue_free() tells Godot to delete this node safely at the end of the current frame, not immediately while the game is still using it.

The Alien Scene
Build a single alien that the grid will duplicate 55 times
Locked
🎯
Goal: One alien scene

Build a single alien scene. Later, the AlienGrid script will create 55 copies of it automatically.

Use AnimatedSprite2D (not Sprite2D), this one plays frame animations like a cartoon. You need 3 animations: 'a' (squid), 'b' (crab), 'c' (ufo). Each has 2 frames for walking.
Alien.gd
# Alien.gd
extends Area2D
signal alien_killed(points, pos)
# 0=squid(10pts)  1=crab(20pts)  2=ufo-row(30pts)
@export var alien_type: int = 0
@export var points: int = 10

func _ready():
    add_to_group("aliens")
    match alien_type:
        0: $AnimatedSprite2D.play("a")
        1: $AnimatedSprite2D.play("b")
        2: $AnimatedSprite2D.play("c")

func die():
    alien_killed.emit(points, global_position)
    queue_free()
Alien.tscn and Alien.gd saved · No errors · Images set up in Chapter 8

The Alien Grid
The most complex script: 55 aliens marching in formation
Locked
🎯
Goal: A marching alien army

The most complex script in the game. Take your time, read each section before typing it. AlienGrid does three jobs.

  1. 1Fills the screen with 55 aliens (11 columns × 5 rows)
  2. 2Marches them sideways, drops them down when they hit an edge
  3. 3Picks a random alien at the bottom of each column to shoot at the player
AlienGrid.gd — variables section
# AlienGrid.gd, variables section
extends Node2D
signal all_dead
signal reached_bottom
signal enemy_bullet_fired(pos)

const COLS = 11
const ROWS = 5
const SPACING_X = 36
const SPACING_Y = 32
const ROW_POINTS = [30, 20, 20, 10, 10]
var _dir: float = 1.0
var _step_interval: float = 0.8
const AlienScene = preload("res://Alien.tscn")
⚠️
This script has 5 parts. Type them in order, each part uses variables or functions from the part above it. Check for errors after each part.
💡
preload() loads a scene when the game starts. Then AlienScene.instantiate() creates a new copy. Like a cookie cutter, load it once, stamp out as many as you need.

Barriers & Explosions
Destructible shields and animated explosion effects
Locked
🎯
Goal: Four shields and explosions

Four destructible shields the player can hide behind. Both player and alien bullets chip chunks out of them.

  1. 1Create a new scene → StaticBody2D root → rename "Barrier"
  2. 2Add a Sprite2D child (your shield image) and a CollisionShape2D
  3. 3Attach Barrier.gd, the script tracks health and destroys the node when it hits zero
  4. 4Save as Barrier.tscn

Also create an Explosion scene, an AnimatedSprite2D that plays a short animation then deletes itself with queue_free().

Barrier.gd
# Barrier.gd, simplified
extends StaticBody2D
var health = 4

func take_hit():
    health -= 1
    # Update sprite to show damage
    $Sprite2D.frame = 4 - health
    if health <= 0:
        queue_free()

Drawing the Sprites
Create pixel art for every game object
Locked
🎯
Goal: All sprites drawn and assigned

Every game needs pictures. This chapter covers drawing your pixel art sprites and wiring them into the scenes.

Use any pixel art tool: Aseprite (paid, excellent), Piskel (free, browser-based), or LibreSprite (free desktop). Export each sprite as PNG with a transparent background.

Sprites you need to draw:

  1. 🚀Player ship, facing up, roughly 32×24px
  2. 👾3 alien types · 2 walk frames each, squid, crab, ufo-row
  3. 💥Explosion, 3-4 frames of pixel burst
  4. 🛡️Barrier, 5 damage states (full → destroyed)
  5. 🔵Player bullet, thin vertical sprite
  6. 🔴Enemy bullet, 2 frames for zigzag animation
💡
Keep a consistent colour palette, 4 to 6 colours maximum. Classic Space Invaders uses white aliens on a black background. Simple is fine for a first game.
All PNG sprites saved into res://assets/ · Assigned to correct scenes

The Main Scene
Wire everything together with signals
Locked
🎯
Goal: All scenes connected

The Main scene brings everything together, it creates the player, alien grid, and barriers, and connects all the signals.

  1. 1Scene → New Scene → Node2D root → rename "Main"
  2. 2Add AlienGrid as a child node (attach AlienGrid.gd to it)
  3. 3Add Player (instance Player.tscn) → position at bottom centre
  4. 4Add 4 Barrier instances → spread evenly across the screen
  5. 5Add a CanvasLayer → add Labels for score, hi-score, and lives HUD
Main.gd — signal connections
# Main.gd, signal connections in _ready()
func _ready():
    $AlienGrid.all_dead.connect(_on_wave_clear)
    $AlienGrid.reached_bottom.connect(_on_game_over)
    $AlienGrid.enemy_bullet_fired.connect(_on_enemy_shoot)
    $Player.player_shot.connect(_on_player_shoot)
💡
Signals are Godot's way of sending a message from one node to another without them needing to know about each other. When an alien dies, it emits a signal. Main listens and updates the score.

AlienGrid.gd Marching Logic 
func _march():
    if _drop_next:
        _drop_next = false
        _dir = -_dir
        position.y += 12
        if position.y > 420:
            reached_bottom.emit()
        return
    position.x += _dir * 12
AlienGrid.gd Speed Up on Kill 
func _on_alien_killed(pts, pos):
    _alive_count -= 1
    # Speed up as fewer aliens remain
    _step_interval = max(
        0.08,
        0.8 * (_alive_count / float(COLS * ROWS))
    )
    if _alive_count <= 0:
        all_dead.emit()
AlienGrid.gd Random Shooting 
func _random_shoot():
    # Find bottom alien in each column
    var shooters = []
    for c in range(COLS):
        for r in range(ROWS-1, -1, -1):
            if is_instance_valid(aliens[r][c]):
                shooters.append(aliens[r][c])
                break
Bullet.gd Enemy Zigzag 
var _anim_t: float = 0.0

func _process(delta):
    position.y += speed * direction * delta
    # Enemy bullets zigzag between 2 frames
    if is_enemy:
        _anim_t += delta * 8
        $Sprite2D.frame = int(_anim_t) % 2
