Stuck?
• Basket will not move → Make sure you are editing the BASKET sprite, not the Stage
• Score does not show → Right-click the Score variable and choose "show stage monitor"
• Blocks do not snap → Drag blocks close together until you see the white highlight

How it works: write the code in each step, and the canvas on the right shows what your code does. It is a live preview that builds the game as you go. Type to see it update, or press Apply to Canvas to test it straight away.
