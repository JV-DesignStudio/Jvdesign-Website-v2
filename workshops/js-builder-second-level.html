Goal for this step

Write one sentence that says what is different in level 2.

A second level is not a new game. It is the same game with one thing changed and a higher target. Pick one change you can see and test.

  • 1Open your finished Flappy game in your editor.
  • 2Write this sentence: In level 2, the player must ______ and the target is ______.
  • 3Pick one obstacle change: a moving pipe, a smaller gap or a faster speed.
  • 4Pick a target score that is higher than level 1.
💡
Choose the change you can explain in one sentence. A small change you understand beats a big change you copied.

Goal for this step

Add level and targetScore and show the level on screen.

A variable is a labelled box. level holds the current level number, and targetScore holds the score needed to finish it.

In your game.js, near the other variables at the top, add:

let level = 1;
let targetScore = 10;
  • 1Add the two lines at the top of your game code.
  • 2Find the place where you draw the score.
  • 3Draw the level too: drawText("Level " + level, 16, 24);
  • 4Run the game and check that it says Level 1.
💡
If the text does not show, check that your draw function runs every frame. The level number should be drawn next to the score.

Goal for this step

Add one obstacle that only moves when level is 2.

You do not need a new game. Reuse the pipe code and add a second pipe that moves up and down. The level variable decides whether it moves.

In your game.js, add a second pipe:

let bonusPipe = { x: 420, y: 120, gap: 120, speed: 2 };

function updateBonusPipe() {
  if (level < 2) return;
  bonusPipe.x -= bonusPipe.speed;
  bonusPipe.y = 120 + Math.sin(Date.now() / 500) * 60;
  if (bonusPipe.x < -60) bonusPipe.x = 420;
}
  • 1Add the bonusPipe object near your other game objects.
  • 2Add the updateBonusPipe function below your other update code.
  • 3Call updateBonusPipe() inside your game loop.
  • 4Draw the pipe with the same draw code you use for the first pipe.
  • 5Set level = 2 by hand for one run and watch it move.
💡
Test the obstacle on its own before you add the win rule. One change at a time is easier to fix.

Goal for this step

Reach targetScore and the game moves to level 2 and shows a win screen.

Now connect the score to the level. When the score reaches the target, change level, raise the target and show a short message.

In your game.js, inside the place where you add a point, add:

if (score >= targetScore) {
  level = 2;
  targetScore = 20;
  bonusPipe.speed = 3;
  showWin = true;
}
  • 1Add the check where the score goes up.
  • 2Declare let showWin = false; near your other variables.
  • 3Draw a win message when showWin is true.
  • 4Press R or add a restart that sets level = 1, score = 0 and showWin = false.
  • 5Play until the win message, then restart and play again.
💡
If the win message never shows, log the score and target to the console. They should meet when you expect.

Echo's recovery check

Stuck? Try this

These are the three things that most often stop this project. Check the symptom first, then try the fix.

The level number never changes

What you'll see: You reach the target but the game still says Level 1.

Fix: Check that the line that changes level runs when the score goes up, not only once at the start. Put the check right after score = score + 1.

The new pipe does not move

What you'll see: The second pipe sits still or never appears.

Fix: Make sure updateBonusPipe() is called inside the game loop, and that you set level = 2 before testing it. Also check the pipe starts inside the screen.

The win message shows at the start

What you'll see: The win screen appears before you score anything.

Fix: Set showWin = false when the game starts and when you restart. Only set it to true inside the score check.

Still stuck? Reread the step, open the JavaScript cheat sheet, or ask an adult to sit with you.
