🔗 How the two work together

You use our browser studio and real Python as one workflow, so you can start building with nothing installed and run it when you are ready:

  1. Lay out a level in our studio. Open the Python Mod Studio and place a player, platforms, coins and a goal. No install.
  2. Download the project. The studio writes a whole main.py, a requirements.txt and a README.
  3. Install Python once. Get Python free from python.org, then run pip install pygame and python main.py.
  4. Follow the episodes. Use each episode to learn a new idea, from catching and dodging all the way to a platformer.

Follow them in order. Each episode adds one new idea and ends with a game you can play.

🧰 What you need

A computer and the free Python app (from python.org). Pygame installs with one command. Python runs on modest computers, and the Mod Studio above works in any browser.
