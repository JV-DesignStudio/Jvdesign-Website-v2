Write hello.js

Goal for this step

Save a working plugin in your plugin folder.

  • 1Open your text editor and create a new file.
  • 2Type the code below exactly.
  • 3Save it inside your plugin folder as hello.js. Make sure it is not hello.js.txt.
function main() {
  console.log("Hello park! My first plugin is running.");
}

registerPlugin({
  name: "Hello Park",
  version: "1.0",
  authors: ["Your Name"],
  type: "local",
  main: main
});

React to the Park
Run code when something happens
Locked
🎯
Goal for this step

Make your plugin do something when a new day starts.

  • 1OpenRCT2 gives you events you can listen to, like interval.day.
  • 2context.subscribe attaches your code to an event.
  • 3park.postMessage shows a message in the game, like a park announcement.
function main() {
  context.subscribe("interval.day", function () {
    park.postMessage("A new day dawns in your park!");
  });
}

registerPlugin({
  name: "Daily Greeting",
  version: "1.0",
  authors: ["Your Name"],
  type: "local",
  main: main
});

Goal for this step

Prove the game loaded your file and ran your code.

  • 1Open the Plugin Manager from the developer tools. Your plugin should be listed.
  • 2Open the game console and find your printed message.
  • 3If it is missing: check the file is in the plugin folder and ends in .js (not .txt).
  • 4Fix any missing bracket or quote and save again.
