Read the Load Log
Find the red line that names the problem
Active
🎯
Goal for this step

Read the log and name the problem before you touch anything.

  • 1When tModLoader starts, it writes a load log. Normal lines are grey or white and mean everything loaded.
  • 2A red line or the word Exception means something failed. That is the line you care about.
  • 3Read the red line slowly. It usually names the file, the mod or the version that went wrong.
  • 4Say the problem out loud in your own words. "The mod is for a newer game" is a fix you can act on.
A log with a problem in it
[tModLoader] Loading world MyWorld.wld
[tModLoader] Exception: world is version 270, game is 279
[tModLoader] World failed to load

Fix a Version Mismatch
Make the world and game versions match
Locked
🎯
Goal for this step

Fix the most common error by matching the versions.

  • 1A version mismatch means the world or mod was made for a different game version than the one you are running.
  • 2The log tells you both numbers. In our example the world is 270 and the game is 279.
  • 3The fix is to make them the same. Update the world or mod so both numbers match.
  • 4If it is a mod, update that mod. If the world is too old, open it in the matching editor version and save it again.

Fix a Nested Folder
Move the inner folder up one level
Locked
🎯
Goal for this step

Fix the folder mistake that stops a mod loading.

  • 1Mods must sit at the top of the Mods folder. A nested folder is when the mod is inside another folder inside that.
  • 2Open the Mods folder. If you open one folder and find another folder with the same name, the mod is nested.
  • 3Drag the inner folder up one level so the mod sits at the top.
  • 4A duplicate is two copies of the same mod. Keep one and remove the extra.
Nested folder, then the fix
wrong:  Mods/ExampleMod/ExampleMod/...
right:  Mods/ExampleMod/...

Restore a Backup World
Bring back the copy that still works
Locked
🎯
Goal for this step

Get back to a working world when your edit breaks.

  • 1Terraria keeps a .wld.bak copy beside every world. That is your safety net.
  • 2If a world will not load, you can restore that copy and start again.
  • 3Close the game first, then copy the backup and give it a clear name.
  • 4You always keep the original. Restoring never costs you the last good version.

When TEdit Will Not Open
Check the copy and the version
Locked
🎯
Goal for this step

Fix the two things that stop TEdit opening a world.

  • 1If TEdit will not open a world, first check you picked a copy and not the live file the game is using.
  • 2Next check the version. TEdit must match the game version the world was made in.
  • 3If the world is newer than your TEdit, update TEdit to the latest release.
  • 4Still stuck? Try opening a fresh copy. A file the game has locked half-open often refuses to load.

Ask for Help Well
Share the log line and what you tried
Locked
🎯
Goal for this step

Write a help request that gets a fast, useful answer.

  • 1When you ask for help, copy the exact log line. Do not summarise it. The exact words matter.
  • 2Say what you already tried. That stops people suggesting things that did not work.
  • 3Add one clear sentence about what you expected and what happened instead.
  • 4Good help requests get good answers. Vague ones get guesses.
