Questions & Answers

Do I need to know C# before starting?
No. Episode 1 introduces C# from scratch we explain every line of code as we write it. By the end of the series you'll understand classes, variables, methods, events and physics in Unity.
Which version of Unity should I use?
Download the latest LTS (Long Term Support) version from Unity Hub it's labelled clearly. LTS versions are stable and recommended for beginners. The workshops will note if anything differs between versions.
Is Unity really free?
Unity Personal is completely free for individuals and small teams earning under $200k per year. For learning and hobby projects you will never pay a thing.
What age is it suitable for?
Ages 12+ across the whole series, with some parental support helpful during the Unity install in Episode 1. Later episodes (Action RPG, Multiplayer) involve more moving parts and suit kids comfortable following longer, multi-step instructions.
Can I publish my Unity game?
Yes! Unity can export games for Windows, Mac, WebGL (browser), iOS and Android. WebGL builds can be uploaded to itch.io for free so friends can play in their browser.
Is it really free?
All 8 episodes, forever. No ads, no paywall, no sign-up required. Unity Hub, the Unity Editor and Visual Studio Code are all free.
