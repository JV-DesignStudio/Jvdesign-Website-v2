Stardust's five moves

Don't just copy it. Own it.

Copying the finished code proves it runs. Changing and explaining it proves you understand it. Keep the reference solution closed until you need it.

  1. 1. See it Pip Play the finished bakery before you type anything. Watch the counter climb and find one thing you want to keep. Open it
  2. 2. Understand it Lumo Read why each line is there before you copy it. If you can say what it does in your own words, you understand it. Open the cheat sheet
  3. 3. Build it Ember Type the guided version yourself. The live canvas shows what each step adds. Open it
  4. 4. Fix it Echo Try Echo's recovery check when a shop button does nothing or the counter stops. Find the clue before the answer. Open the Godot hub
  5. 5. Own it Stardust Change one thing the guide never asked for: a new biscuit, a third upgrade, or a bakery name. If your version runs, it is yours. Open it

Echo's recovery check

Stuck? Try this

These are the three things that most often stop a first clicker. Check the symptom, then try the fix.

The biscuit counter never moves

What you'll see: you click the tin and the number stays at zero.

Fix: Check the function is named exactly on_tap and that it adds click_power. A misspelled name is never called.

Auto tappers do nothing

What you'll see: the shop says you own tappers, but the counter does not climb.

Fix: Check auto_tick(delta) multiplies by delta. Without it, the function adds a tiny fraction and the display stays still.

The shop button never works

What you'll see: you have enough biscuits but the button does nothing.

Fix: Check the cost test uses biscuits >= auto_cost and that the cost is taken away before the tapper is added.

Still stuck? Reread the step, open the GDScript cheat sheet, or ask an adult to sit with you.

Finish in Godot

Turn your preview into a real bakery

The canvas is a live preview. To keep the game and play it in Godot, build the same scene in the free editor.

  1. Download the Biscuit Tycoon starter project.
  2. Open Godot 4 from godotengine.org, choose Import and pick project.godot.
  3. Press F5. The tin, labels, shop buttons, golden timer and signals are already wired.
  4. Open bakery.gd and follow the In Godot panel under each step. The code is the same code you wrote in the canvas.
  5. Check the tap, the auto tapper, both shop buttons and the golden biscuit, then open Project > Export to keep your game.
