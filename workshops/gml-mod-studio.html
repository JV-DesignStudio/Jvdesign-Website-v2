GameMaker (GML) Mod Studio
Build a game project in your browser

A little project maker for the GameMaker series. Lay out a 2D game on a grid, tick the GML behaviours you want, read a broken GameMaker log and choose the fix, then download real GML event code you can paste straight into GameMaker.

🛠️ Open the Studio ← Back to all workshops
Make your own art and sounds: draw sprites in Pixel Studio and make music or sound effects in Sound Studio, then bring them into your project.
Ember says: GameMaker is free to start with, and GML is a friendly language built for games. This studio writes the event code for you: a Create, Step and Draw event you can paste into an object. Your work saves automatically.

Lay out your scene

Pick an object below, then click squares on the grid to place it. Put the Player where you start and a Goal at the end. Click a square again, or use the eraser, to remove it.

Objects

Your scene so far

Each object becomes a shape your GML draws in the Draw event. The mini map below is a bird's eye view of where they sit in the game.

What is in the scene

    Add scripts

    A behaviour is a little block of GML that runs every step. Tick the ones you want and the Studio writes them. Start with Player move so you can move, and Coin collect so collecting does something.

    Your scripts

    Each ticked behaviour is written into your project's Step_0.gml event.

      How this maps to real GameMaker
      
        
      
          
      Create event runs once when the object is made. Set your variables and arrays here.
      
          
      Step event runs every frame: movement, collisions and score.
      
          
      Draw event draws your objects with draw_rectangle and draw_text.
      
          
      Paste them in: make one object (obj_game), open Add Event, and paste each file into its event.
      
          
      Run it: GameMaker is free to download, press the green Run button.
