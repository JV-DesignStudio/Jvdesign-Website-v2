Questions & Answers

Do I need to install anything?
No. Every game is a single HTML file you open in your browser. A free editor like VS Code helps but even Notepad works.
Do I need to know JavaScript first?
No. Episode 1 starts with your first canvas and explains every line. JavaScript is a great first language because it runs instantly in the browser.
What will I build?
A Flappy Bird clone, a memory card game with CSS flips, Breakout with particles, Snake with touch controls, and a platformer with double jump and a scrolling camera.
Can I share my games?
Yes , that is the best part. Send the HTML file or upload it to a free host like itch.io and anyone with a browser can play instantly, even on a phone.
Do the workshops save my progress?
Yes. Each tracks XP, streaks and completed steps (using the same localStorage the games teach), and reports to the My Progress page.
Is it really free?
All 6 episodes, forever. No ads, no paywall, no sign-up needed.
