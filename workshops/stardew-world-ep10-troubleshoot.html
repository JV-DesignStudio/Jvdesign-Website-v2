Read the SMAPI Log
What each kind of line means
Active
🎯
Goal for this step

Tell healthy lines from problem lines at a glance.

  • 1White or normal lines are just SMAPI working. Nothing to do.
  • 2A red line, or the word ERROR, is a real problem.
  • 3The line usually names the mod and the file, so it tells you where to look.
  • 4Read from the bottom of the error block upward: the last line is the actual cause, the ones above are the trail.
A typical error block
[Content Patcher] Error loading content pack 'My First Farm'.
FromFile asset 'assets/maps/Farm.tmx' doesn't exist.
   at ContentPatcher.Framework...
Tip: the file path is usually the real clue.

The Five Common Mistakes
And their quick fixes
Locked
🎯
Goal for this step

Recognise the mistakes almost everyone makes first.

  • 1Nested folder: ContentPatcher/ContentPatcher. Move the inner folder up.
  • 2Wrong FromFile path: a typo or wrong case. Match the real file name exactly.
  • 3Broken JSON: a missing comma or quote in content.json or manifest.json.
  • 4Map name mismatch: the warp target and the Load Target do not match.
  • 5Duplicate UniqueID: another mod already uses it. Make yours unique.

Check Your JSON First
Catch the easy errors before launch
Locked
🎯
Goal for this step

Learn the three things that break JSON.

  • 1Every item in a list needs a comma between them, but not after the last one.
  • 2Names and text values need straight quotes, not curly ones.
  • 3Every open curly brace has a matching close curly brace.
  • 4Paste your content.json into an online JSON checker if you are unsure. It finds the exact line.
Common JSON slip
Bad (trailing comma):
  "Changes": [ { "Action": "Load" }, ]

Good:
  "Changes": [ { "Action": "Load" } ]

Back Up Your Mod
A copy saves your whole world
Locked
🎯
Goal for this step

Make a backup habit that protects your work.

  • 1Copy your whole mod folder somewhere safe, like a backups folder.
  • 2Do it before big changes, so you can always go back to a working version.
  • 3Name backups with the version, like MyFirstFarm-1.0.0.
  • 4This is the same file the game's own backup folder keeps, so it fits right in.
