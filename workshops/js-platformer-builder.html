Build a Platformer!
JavaScript Platformer

A Mario-style platformer you build one step at a time: gravity, arrow-key movement, platforms, collectible coins, patrolling enemies, health and a scrolling camera. See the finished game first, then build yours.

How this workshop works: every step is labelled with what you do. Configure means change a value, Modify code means complete the missing lines, and Write code means write the logic yourself. This workshop starts with Modify code and finishes with Write code, so you build up to writing JavaScript on your own.
