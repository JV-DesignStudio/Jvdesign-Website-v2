Echo's Debug It

Debug It: The jump that never comes back down

On some computers the character jumps once and then keeps flying upward, and on slower machines it barely jumps at all.

void Update() {
    if (Input.GetKeyDown(KeyCode.Space)) {
        rb.velocity = new Vector2(rb.velocity.x, 8f);
    }
}
  1. What did you expect? The character jumps to a fixed height and falls back down.
  2. What happened instead? The height changes from one computer to another, and holding space flaps the character upward.
  3. What evidence tells you where the problem is? Log rb.velocity.y in FixedUpdate and in Update. The value keeps being reset before gravity has a chance to pull it down.
Hint 1: a nudge

Physics work belongs in one specific update method, and a jump needs a check that you are on the ground.

Hint 2: what to look for

Setting velocity every frame in Update fights gravity and runs at the monitor's frame rate, so the jump height depends on the machine. A grounded check stops repeated jumps, and physics belongs in FixedUpdate.

Full answer

Move the physics into FixedUpdate, add a ground check, and apply the impulse once: 

if (Input.GetKeyDown(KeyCode.Space) && isGrounded) {
    rb.velocity = new Vector2(rb.velocity.x, jumpForce);
    isGrounded = false;
}

Try the hints before the answer. Finding the bug is the skill, the fix is the easy part.
