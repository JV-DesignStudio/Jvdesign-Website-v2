Your Blender path

  1. Stage 1: Learn BlenderStart hereThe nine-step beginners course. Finish with a simple rendered scene. Next: Episode 1, then build a character.
  2. Stage 2: Build a characterBeginnerEpisode 2 models a low-poly character. Start with Episode 1 if the viewport still feels new. You need to move, rotate and scale objects.
  3. Stage 3: Rig and animateImproverEpisode 3 adds bones and weights, then Episode 4 animates a walk cycle. You need a finished character mesh.
  4. Stage 4: Create a sceneAdvancedEpisodes 5 to 7 add materials, lighting and a complete rendered scene. You need a rigged, animated character.
  5. Stage 5: Independent projectCapstoneBuild your own scene from a brief. Use the episode skills and the browser Mod Studio to plan it. You need modelling, rigging, animation, materials and lighting.
