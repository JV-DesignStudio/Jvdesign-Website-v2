What Is a Warp?
An invisible doorway between maps
Active
🎯
Goal for this step

Understand how a warp moves the player to another map and tile.

  • 1A warp is a spot on the map that teleports the player somewhere else when stepped on.
  • 2Every warp entry has five values: the from tile (X and Y), the target map, and the target point (X and Y).
  • 3Doors, cave mouths and the edges of a map all use warps.
  • 4All the warps on a map live in one list called the map's Warp property.

Pick the Landing Spot
Where the player appears
Locked

Goal for this step

Choose a safe target point on the other map.

  • 1A target point is a tile coordinate on the destination map, like X 12, Y 8.
  • 2Pick a spot that is walkable, or the player lands somewhere they cannot move.
  • 3Leave a one-tile gap from the doorway so the player does not instantly trigger a warp back.
  • 4In Tiled you can read a tile's coordinates from the status bar as you hover.

Add the Warp Entry
Add a doorway to the map's Warp list
Locked
🎯
Goal for this step

Add a Warp entry that points somewhere.

  • 1Decide which tile is the doorway and which map it leads to.
  • 2Open the map's Warp property and add an entry for it.
  • 3The entry is five values: fromX fromY toArea toX toY.
  • 4When the player steps on the from tile, the game sends them to the target map and point.

Add the Way Back
Every warp needs a return
Locked
🎯
Goal for this step

Add the matching warp so the player is not trapped.

  • 1On the destination map, add a Warp entry near the landing spot.
  • 2Point it back to the first map and a safe tile.
  • 3Now the connection runs both ways. One-way warps strand the player.
  • 4If you know the destination, you know the return: it is just the two maps swapped.

Walk Through It
Test both directions
Locked
🎯
Goal for this step

Prove the doorway works both ways.

  • 1Save both maps, load your save and walk into the doorway.
  • 2You should appear at the target point on the other map.
  • 3Walk back through the return doorway and confirm you arrive home.
  • 4If you land inside a wall or fall through, the target point is wrong. Fix and reload.

Fix the Classic Falls
Why players drop through the world
Locked
🎯
Goal for this step

Learn the two most common warp mistakes.

  • 1Your map does not cover the whole playable area, so the player walks off the edge into empty space.
  • 2The fix: paint solid ground right to the map's border on the Back layer, or add warps at the border to send the player somewhere safe.
  • 3A warp points at a missing map or an out-of-bounds point, so the game cannot place the player.
  • 4The fix: retype the Warp value exactly, check the map name spelling and the X Y numbers.
