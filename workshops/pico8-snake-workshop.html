Set Up the Grid
Create a grid system for the snake to move on
Active
🎯
Goal for this step

Set up an 8x8 grid on the 128x128 Pico-8 screen and learn how grid coordinates work.

👨‍👧
Parent note: Snake works on a grid, not pixel coordinates. Each grid cell is 16x16 pixels (128 / 8 = 16). This makes movement and collision much simpler!

Create the grid

  • 1In _init(), set up the grid size: g=16 (each cell is 16 pixels).
  • 2Draw the grid lines in _draw() using a for loop to draw faint lines.
  • 3Use colour 1 (dark blue) for the grid lines so they're subtle.
📝 Snake - Grid Setup
function _init() g=16 -- grid cell size end function _draw() cls(0) -- draw grid lines for i=0,8 do line(i*g,0,i*g,128,1) line(0,i*g,128,i*g,1) end end

Create the Snake
Use a Lua table to store the snake body segments
Locked
🎯
Goal for this step

Use a Lua table to store the snake's body segments and draw them on screen.

Build the snake with a table

  • 1Create a table: snake={} in _init(). Each entry is {x, y}.
  • 2Add starting segments: add(snake,{4,4}) for the head, then {3,4} and {2,4} for the body.
  • 3In _draw(), loop through the table: for s in all(snake) do rectfill(s.x*g, s.y*g, ...)
📝 Snake - Body Table
function _init() g=16 snake={} add(snake,{x=4,y=4}) add(snake,{x=3,y=4}) add(snake,{x=2,y=4}) end function _draw() cls(0) for s in all(snake) do rectfill( s.x*g+1,s.y*g+1, s.x*g+14,s.y*g+14, 11) end end

Move the Snake
Add grid-based movement with arrow keys
Locked
🎯
Goal for this step

Make the snake move continuously in one direction, controlled by arrow keys.

Add direction and movement

  • 1Create direction variables: dx=1 (moving right), dy=0.
  • 2Use btnp() instead of btn() for direction changes (only triggers once per press).
  • 3In _update(), move the head: snake[1].x += dx and snake[1].y += dy.
  • 4Prevent reversing: only allow UP if currently going LEFT/RIGHT, etc.
📝 Snake - Movement
function _init() g=16 dx=1 dy=0 snake={} add(snake,{x=4,y=4}) add(snake,{x=3,y=4}) add(snake,{x=2,y=4}) end function _update() -- change direction if btnp(0) and dx==0 then dx=-1 dy=0 end if btnp(1) and dx==0 then dx=1 dy=0 end if btnp(2) and dy==0 then dx=0 dy=-1 end if btnp(3) and dy==0 then dx=0 dy=1 end -- move head snake[1].x=snake[1].x+dx snake[1].y=snake[1].y+dy end

True or False?
+15 XP
btnp() only returns true once per press, while btn() returns true every frame.
The snake can reverse direction (go left when going right).
snake[1] refers to the head of the snake.

Body Follows the Head
Make each segment follow the one in front of it
Locked
🎯
Goal for this step

Each body segment should move to where the segment in front of it was, creating the classic snake movement.

Body following logic

  • 1Loop backwards from the last segment to the second: for i=#snake,2,-1
  • 2Each segment copies the position of the one before it: snake[i].x = snake[i-1].x
  • 3The head (snake[1]) moves with dx/dy as before.
📝 Snake - Body Following
function _update() -- direction changes here... -- body follows head for i=#snake,2,-1 do snake[i].x=snake[i-1].x snake[i].y=snake[i-1].y end -- move head snake[1].x=snake[1].x+dx snake[1].y=snake[1].y+dy end
💡
The # operator gives you the length of a table. So #snake tells you how many segments the snake has!
🧠
Knowledge Check
+15 XP
Why do we loop backwards (from #snake to 2) instead of forwards?
AIt's faster
BIf we looped forwards, each segment would copy the already-updated position of the one in front, creating a diagonal line
CLua only supports backwards loops

Add Food
Spawn food at random positions for the snake to eat
Locked
🎯
Goal for this step

Create food that appears at random grid positions and draw it as a red square.

Spawn food

  • 1Create food variables: fx and fy in _init().
  • 2Use fx=flr(rnd(8)) to get a random grid position 0-7.
  • 3Draw food as a red filled rectangle in _draw().
  • 4Check if head overlaps food: if snake[1].x==fx and snake[1].y==fy
📝 Snake - Food
function _init() g=16 dx=1 dy=0 snake={} add(snake,{x=4,y=4}) add(snake,{x=3,y=4}) add(snake,{x=2,y=4}) spawn_food() end function spawn_food() fx=flr(rnd(8)) fy=flr(rnd(8)) end function _draw() cls(0) -- draw food rectfill( fx*g+2,fy*g+2, fx*g+13,fy*g+13,8) -- draw snake... end

Grow the Snake
Add a new segment when the snake eats food
Locked
🎯
Goal for this step

When the snake eats food, add a new body segment and spawn new food.

Eating and growing

  • 1After moving the snake, check if head overlaps food.
  • 2If yes, add a new segment at the tail's position: add(snake, {x=snake[#snake].x, y=snake[#snake].y})
  • 3Then call spawn_food() to place new food.
  • 4Also add a score variable: score=0 and increment it: score+=1.
📝 Snake - Eating Logic
-- in _update, after moving: if snake[1].x==fx and snake[1].y==fy then score=score+1 add(snake,{ x=snake[#snake].x, y=snake[#snake].y}) spawn_food() sfx(0) end

Game Over: Wall & Self Collision
End the game if the snake hits a wall or itself
Locked
🎯
Goal for this step

Detect when the snake hits the screen edges or its own body and show a game over screen.

Collision detection

  • 1Wall check: if snake[1].x<0 or snake[1].x>7 or snake[1].y<0 or snake[1].y>7
  • 2Self check: loop from segment 2 onwards, if any matches head position, game over.
  • 3Create a game_over variable. When true, show "GAME OVER" and press Z to restart.
📝 Snake - Game Over
-- wall collision if snake[1].x<0 or snake[1].x>7 or snake[1].y<0 or snake[1].y>7 then game_over=true end -- self collision for i=2,#snake do if snake[1].x==snake[i].x and snake[1].y==snake[i].y then game_over=true end end

Add Speed Increase
Make the snake move faster as the score goes up
Locked
🎯
Goal for this step

Use a timer so the snake only moves every N frames, and decrease that interval as the score increases.

Timer-based movement

  • 1Create move_timer=0 and move_speed=8 in _init().
  • 2In _update(), increment timer: move_timer+=1. Only move when move_timer>=move_speed.
  • 3After eating food, decrease move_speed: if move_speed>3 then move_speed-=0.5 end
📝 Snake - Speed
function _update() move_timer=move_timer+1 if move_timer<move_speed then return end move_timer=0 -- direction + movement here -- after eating food: if move_speed>3 then move_speed=move_speed-0.5 end end
