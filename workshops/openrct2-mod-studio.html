Echo's recovery check

Stuck? Try this

These are the three things that most often stop a first OpenRCT2 plugin build. Check the symptom first, then try the fix.

Copy plugin does nothing

What you'll see: no plugin text is copied.

Fix: Type a plugin name on the Your plugin tab, then press Copy my plugin.

The console shows the same error

What you'll see: Next problem does not clear it.

Fix: Read the error, choose the fix that matches it, then press Next problem.

The download will not open

What you'll see: the zip does not load in OpenRCT2.

Fix: Unzip the download into the OpenRCT2 plugin folder, then restart OpenRCT2.

Still stuck? Reread the step, open the OpenRCT2 cheat sheet, or ask an adult to sit with you.

Your plugin folder

        
An OpenRCT2 plugin is just this: a .js file in the plugin folder, plus an optional README. That is the whole install.

    The .js file goes in Documents/OpenRCT2/plugin/.
    
          
    registerPlugin tells the game the plugin exists.
    
          
    context.subscribe attaches your code to an event, and park.postMessage shows a message.
