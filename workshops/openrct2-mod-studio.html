OpenRCT2 Mod Studio
Build a park plugin in your browser

A little plugin maker for the OpenRCT2 World Workshop: name your plugin, choose when it runs and what it does with the park, read a broken console log and choose the fix, then download a real plugin folder as a zip. It runs on a locked-down school computer with no install and no account.

Your plugin folder

        
An OpenRCT2 plugin is just this: a .js file in the plugin folder, plus an optional README. That is the whole install.

        
    
        
    How this maps to the real game
    
        
    
          
    The .js file goes in Documents/OpenRCT2/plugin/.
    
          
    registerPlugin tells the game the plugin exists.
    
          
    context.subscribe attaches your code to an event, and park.postMessage shows a message.
