✦ Why JVDesignStudio

What makes this different

📚
Books that tackle real topics
The books address anxiety, fear, online safety, belonging and resilience — themes children carry into school every day. Written to spark conversations, not avoid them.
🎮
Games tied to the stories
Every major book has a free browser game built around its world. No downloads, no accounts — playable on any school device in seconds.
🔧
Coding courses for beginners
7 free courses — Godot, JavaScript, Python, MUGEN, Roblox. Each builds something real. Ages 8+, no prior experience needed.
💰
Completely free
Every game, every course, every PDF. No subscriptions, no sign-up, no paywalls. Accessible to every school regardless of budget.
💻
Works on any device
All games and courses run in a standard browser. Tested on Chromebooks, iPads, Windows laptops and mobile. No software installation required.
👨‍🏫
Discovery sessions available
A ready-made 15-minute interactive presentation covering books, games and coding — designed to run in front of a class with minimal teacher input needed.
