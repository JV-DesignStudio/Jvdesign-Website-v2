📋 Blender Cheat Sheet

🖱️ Viewport Navigation

Orbit (rotate view)Middle Mouse Button drag
Pan (move view)Shift + MMB drag
ZoomScroll Wheel
Focus on objectNumpad . (or View → Frame Selected)
Top viewNumpad 7
Front viewNumpad 1
Side viewNumpad 3
Camera viewNumpad 0
Toggle wireframeAlt + Z

🔲 Object Mode Shortcuts

Select objectLeft Click
Deselect all / Select allAlt + A / A
MoveG
RotateR
ScaleS
Constrain to axisG/R/S then X, Y, or Z
Delete selectedX or Delete
DuplicateShift + D
Add objectShift + A
Toggle Edit ModeTab
UndoCtrl + Z

✏️ Edit Mode Shortcuts

Vertex select mode1
Edge select mode2
Face select mode3
ExtrudeE
Inset faceI
Loop cutCtrl + R
BevelCtrl + B
Merge verticesM
Select edge loopAlt + Click edge

Save renderImage → Save As (in render window)
