if (RIGHT) player.rotate(+190)
if (UP)    player.thrust(200)

Thrust Power200

Shoot System
Fire bullets forward
LIVE
if (SPACE pressed) {
  bullet = spawn(player.x, player.y)
  bullet.speed = 540
  cooldown = 180ms
}
Bullet Speed540
Fire Cooldown (ms)180
Every SPACE press (after cooldown) spawns a bullet pointed in the ship's direction and launches it. Lower cooldown = rapid fire!

Enemy Spawner
Timer-based spawning
RESTART TO APPLY
every(1100ms, do:)
  enemy = spawn(randomX, top)
  enemy.fallSpeed = 150
Spawn Delay (ms)1100
Fall Speed150
A game timer fires every N ms and drops an enemy at a random X. Lower delay = harder! Restart after changing the delay.
