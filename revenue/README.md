# Studio Revenue Kits

Separated so site root stays clean. Each kit is zero-cost to launch, no new art needed.

```
revenue/
├── templates/       # itch.io PWYW Godot templates (11 zips from pages/downloads.html:101)
├── fund-the-books/  # BuyMeACoffee tiers + Lumo Art Fund £0/£900
└── ace-grant/       # Arts Council England DYCP £4.5k application
```

**Order:** `templates` (cash now) → `fund-the-books` (cash monthly) → `ace-grant` (big cash, 6-8wk decision).

All source zips stay on site at `pages/downloads.html:101` - these are just store listings/bonus PDFs, not duplicates.
