## 🎯 REDDIT POST (r/gamedev)

```
Title: We built an educational gaming ecosystem where workshops unlock games, 
games feed quests, and quests unlock cosmetics. It's free and launched today.

We just shipped something we've been working on for months. Here's what it does:

**The Core Loop:**
- Complete interactive workshops (Scratch, Godot, Python, etc.)
- Each workshop unlocks a matching game
- Playing the game feeds into a quest
- Complete the quest = unlock cosmetics + earn XP

**Social Features:**
- Global leaderboards (XP, achievements, streaks)
- Personal progress dashboard
- 5 curated learning paths (Scratch, Godot, Idle Games, Puzzles, Story Games)
- Share achievements and ranks

**Why We Built It:**
We wanted to prove that learning and gaming aren't opposites. A well-designed game 
can be the learning medium itself. Progress should be visible. Competition should 
motivate. Rewards should feel earned.

**The Result:**
A system where a 7-year-old can learn Scratch while a 16-year-old learns Godot, 
both see their progress, both compete on the same leaderboards, both unlock cosmetics 
that prove their achievement.

All browser-based. All free. All connected.

We'd love feedback from the community. What would you add?

https://jvdesignstudio.co.uk
```
