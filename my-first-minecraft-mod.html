Questions & Answers

Do I need to know Java before starting?
No. Episode 1 introduces Java gently we explain every line of code as we write it. By the end of the series you'll have a solid beginner understanding of Java classes, methods and events.
Why Fabric and not Forge?
Fabric is lighter, faster to set up and has cleaner beginner documentation. It's the best choice for learning. Once you understand the basics, moving to Forge (or NeoForge) is straightforward.
Which version of Minecraft do the workshops use?
The workshops target Minecraft Java Edition 1.21. We'll note if anything changes with newer versions. You need to own Minecraft Java Edition it's the only paid item in the whole series.
What age is it suitable for?
Episodes 1–4 work well from age 10 with some parental support for the setup. Episodes 5–6 involve more Java and suit ages 11–12+ who are comfortable copying and editing code.
Can I share my mod with friends?
Yes! Once built, your mod is a .jar file. Friends can drop it into their Fabric mods folder and play with it. You can also share it on sites like Modrinth or CurseForge for anyone to download.
Is it really free?
All 6 episodes, forever. No ads, no paywall, no sign-up. The only cost is a copy of Minecraft Java Edition Java JDK, IntelliJ IDEA and Fabric are all free.
