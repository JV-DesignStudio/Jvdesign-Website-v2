## New Arcade Ideas Worth Adding

- Daily Arcade Run: one featured game per day with a seed, leaderboard, and streak reward.
- Arcade Quests: cross-game objectives such as score 500 in any puzzle game, clear 3 waves, or win without taking damage.
- Remix Spotlight: feature one Game Maker creation each week with Play and Remix buttons.
- Boss Rush Cabinet: short 90-second action game made from existing shooter/wave tech.
- Tiny Roguelite Cabinet: one-screen dungeon rooms with three upgrade choices per floor.
- Skill Ladder: bronze/silver/gold goals for every keeper game.
- Arcade Cleanup Pass: every public card must have screenshot, controls, genre, expected session length, and mobile smoke result.
