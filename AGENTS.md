## 1) What JVDS Is For

**North Star , `JVDS_PRODUCT_VISION.md:1` + `pages/dev-board.html:112`:**
> JVDesignStudio exists so young people can learn, create and play without barriers. A new learner should arrive and make something they are proud of within 15 minutes on a locked-down school computer. **Creativity shouldn't need permission.**

**Core loop:** `Imagine(Stardust) → Learn(Lumo) → Create(Ember) → Play(Pip) → Improve(Echo) → Imagine again` (`JVDS_PRODUCT_VISION.md:24`).

**School-Computer Rule** (`JVDS_PRODUCT_VISION.md:38`): core experiences require **no install, no admin rights, no paid software, no powerful PC, no account to start**. Open the browser. Start creating. The toolbox is the solution to those restrictions, not clutter.

**Current mission** (`pages/dev-board.html:167`): make the *first successful creation* obvious/joyful , arrival → pick path → make something small/real → save/export → know what to improve next. The chosen first-path is **Pixel Character Studio** (merged Pixel Studio + Character Designer).

**Before you build anything ask** (`JVDS_PRODUCT_VISION.md:54`):
- Does it help a young person make/understand/play/improve something?
- Does it strengthen the loop? Can it work in a restricted browser?
- Can an existing tool be improved instead of adding a disconnected one?
- Does it respect the characters as identity, not decoration?
- Is it more important than the learner's first successful creation? If no → don't build yet.

Backlog is not a to-do list (`pages/dev-board.html:192`). Prioritise against the North Star + school rule + current mission.
