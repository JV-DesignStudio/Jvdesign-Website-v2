Game Engine Keyboard Shortcuts

A printable quick-reference for keyboard shortcuts in Godot 4, Unity, GDevelop, GameMaker, and Unreal Engine 5. Pick your engine and pin it next to your monitor!

🎮

Godot 4 Shortcuts

▶️ Run & Build

F5Run project
F6Run current scene
F7Build (incremental)
F8Stop running project
F9Toggle breakpoint
F11Run current scene as server

💾 File

Ctrl+SSave scene
Ctrl+Shift+SSave scene as…
Ctrl+Alt+SSave all scenes
Ctrl+OOpen scene
Ctrl+NNew scene
Ctrl+QQuit editor

↩️ Edit

Ctrl+ZUndo
Ctrl+YRedo
Ctrl+DDuplicate
Ctrl+XCut
Ctrl+CCopy
Ctrl+VPaste
Ctrl+ASelect all
DeleteDelete selected

🔍 Find & View

Ctrl+FFind
Ctrl+HFind and replace
Ctrl+GGo to line
SpaceToggle 2D/3D editor
Alt+GToggle grid
Alt+OToggle perspective/orthogonal

🧭 Navigation

Alt+QSwitch to 2D editor
Alt+ESwitch to 3D editor
Alt+XSwitch to Script editor
Alt+BSwitch to AssetLib
TabCycle between editors
Ctrl+TabCycle open scripts

🎮 3D Viewport

GGrab / Move
RRotate
SScale
FFocus selected
Ctrl+LSnap to grid
Alt+Left MouseOrbit camera
Alt+Right MouseZoom camera
Shift+Alt+Left MousePan camera

🧠 Scene & Node

Ctrl+Shift+AAdd child node
Ctrl+AAttach script
Ctrl+Shift+CAttach script to node
Ctrl+F5Toggle unique name
Ctrl+Shift+FSearch the online docs
Ctrl+KCollapse/expand node in tree
HomeGo to root node
EndGo to last node
