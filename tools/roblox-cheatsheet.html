Roblox Lua Cheat Sheet

A one-page printable reference for Roblox data types, instance methods, properties, events, remote events, services and the most-used Lua patterns. Pin it next to your monitor!

📦 Data Types

InstanceBase object for all game objects
Vector33D vector (x, y, z)
Vector22D vector (x, y)
CFramePosition + rotation combined
Color3RGB colour (0-1 range)
BrickColorNamed colour palette
EnumEnumerated constants
UDim2UI scale + offset (pixels + scale)
UDimSingle scale + offset
RayOrigin + direction for raycasting
Enum.EasingStyleLinear, Sine, Quad, Cubic, etc.

🔧 Instance Methods

Instance.new("ClassName")Create a new instance
:FindFirstChild("Name")Find child or nil
:GetFirstChild("Name")Find child or error
:GetChildren()Array of all children
:GetDescendants()All nested children
:Clone()Deep copy of instance
:Destroy()Remove from game
:WaitForChild("Name")Wait then find child
:GetService("Name")Get/create a service
:IsA("ClassName")Check class type
:GetAttribute("Key")Read custom attribute
:SetAttribute("Key", val)Write custom attribute

🏷️ Properties

.NameInstance name
.ParentParent in hierarchy
.PositionWorld position (Vector3)
.SizeDimensions (Vector3)
.ColorBrickColor value
.Transparency0 (opaque) to 1 (invisible)
.AnchoredStatic in world (no physics)
.CanCollideCan other parts collide with it
.CFramePosition + orientation
.MasslessZero mass in assembly
.MaterialPlastic, Wood, Neon, etc.

🔔 Events

TouchedPart collision begin

Triggered (ProximityPrompt)Player interacted

HeartbeatEvery frame (RunService)

🌐 Remote Events

── SERVER SCRIPT ──
local remote = Instance.new("RemoteEvent")
remote.Name = "DamageEvent"
remote.Parent = ReplicatedStorage

remote.OnServerEvent:Connect(
    function(player, amount)
        -- player = who fired it
    end
)

── LOCAL SCRIPT ──
remote.FireServer(10)

── SERVER BROADCAST ──
remote.FireClient(targetPlayer, data)
remote.FireAllClients(data)

── REMOTE FUNCTION (request/response) ──
-- Server:
func.OnServerInvoke = function(player)
    return {gold = 50}
end
-- Client:
local data = func.InvokeServer()

🛠️ Common Patterns

── PLAYER MOVEMENT ──
local UIS = game:GetService("UserInputService")
local speed = 16

game.RunService.Heartbeat:Connect(function()
    local char = player.Character
    if not char then return end
    local hrp = char:FindFirstChild("HumanoidRootPart")
    local hum = char:FindFirstChild("Humanoid")
    if hum then hum.WalkSpeed = speed end
end)

── LEADERSTATS ──
game.Players.PlayerAdded:Connect(function(player)
    local ls = Instance.new("Folder")
    ls.Name = "leaderstats"
    ls.Parent = player

    local coins = Instance.new("IntValue")
    coins.Name = "Coins"
    coins.Value = 0
    coins.Parent = ls
end)

── DATA STORE ──
local DS = game:GetService("DataStoreService")
local store = DS:GetDataStore("SaveData")

game.Players.PlayerAdded:Connect(function(player)
    local key = "player_" .. player.UserId
    local data = store:GetAsync(key)
end)

game.Players.PlayerRemoving:Connect(function(player)
    local key = "player_" .. player.UserId
    store:SetAsync(key, {coins = 100})
end)

── SHOP SYSTEM ──
local deb = false
part.Touched:Connect(function(hit)
    if deb then return end
    local plr = game.Players:GetPlayerFromCharacter(hit.Parent)
    if plr and plr.leaderstats.Coins.Value >= 50 then
        plr.leaderstats.Coins.Value -= 50
        -- give item
        deb = true
        task.wait(1)
        deb = false
    end
end)

── TWEEN SERVICE ──
local ts = game:GetService("TweenService")
local info = TweenInfo.new(1, Enum.EasingStyle.Quad)
local tween = ts:Create(part, info, {
    Position = part.Position + Vector3.new(0, 10, 0)
})
tween:Play()
