GDevelop Visual Events Cheat Sheet

A one-page printable reference for conditions, actions, behaviors, variables, expressions and the most-used GDevelop event patterns. Pin it next to your monitor!

✅ Common Conditions

At the beginning of the sceneRuns once when scene starts
Timer "name" exceeded X secondsRepeat after delay
Value of variable = XCompare scene/global variable
Object A is in collision with BHit-test two objects
Key [X] is pressedKeyboard input check
Mouse button pressed (left)Mouse click check
Object X is off-screenBounds check for cleanup
Force on Y of Player < 0Is falling (top-down/platformer)
Variable "hp" of Player ≤ 0Death check on object variable

⚡ Common Actions

Change variable X of objectAdd, set or subtract a value
Create an objectSpawn at position or expression
Delete an objectRemove from scene
Play a sound/musicTrigger audio file
Change the sceneTransition to another scene
Modify the position of ObjectChange X/Y directly
Add a force (direction & speed)Push/move an object
Hide / Show an objectToggle visibility
Restart the sceneReload current level
Display a textChange text object content

FlashFlash object colour periodically
TweenSmooth property animation
DraggableMouse/touch drag objects
AnchorPin to screen edge (UI)
Destroy outside screenAuto-remove off-screen
Camera extensionFollow player, zoom, shake

📊 Variables

── OBJECT VARIABLES ──
-- per-instance, on each object
Change variable "hp" of Player: = 10
Change variable "score" of Player: + 1
Condition: Variable "hp" of Player ≤ 0

── SCENE VARIABLES ──
-- shared within the current scene
Change variable "wave": = 3
Condition: Variable "enemies_alive" = 0

── GLOBAL VARIABLES ──
-- persist across all scenes
Change variable "high_score": = 999
Condition: Variable "level" ≥ 5

🧮 Key Expressions

Random(min, max)Random number in range
Random(0, 100)Random integer 0-100
Timer("name")Seconds since timer started
ObjectCount("Enemy")Number of object instances
Count(VariableName)Count a scene variable
Player.X() / Player.Y()Object position
CameraX() / CameraY()Camera position
TimeDelta()Time since last frame
SceneVariable("name")Read a scene variable
GlobalVariable("name")Read a global variable

🔁 Loops & Repeat

── REPEAT X TIMES ──
Repeat 5 times:
    Create object "Coin"
        at (Random(0,800), Random(0,600))

── FOR EACH OBJECT ──
For each object "Enemy":
    If distance(Player, Enemy) < 100:
        Change variable "alert" of Enemy: = 1

── WHILE LOOP ──
While variable "i" < 10:
    Change variable "i": + 1

🛠️ Common Patterns

── HEALTH SYSTEM ──
Condition: "Player" is in collision with "Enemy"
  Then: Change variable "hp" of Player: - 1
  Then: Delete object Enemy

Condition: Variable "hp" of Player ≤ 0
  Then: Change scene to "GameOver"

── SCORE TRACKING ──
Condition: "Player" is in collision with "Coin"
  Then: Change variable "score": + 10
  Then: Delete object Coin
  Then: Play sound "coin.ogg"
  Then: Display text "Score: " + VariableString(score)

── ENEMY AI (CHASE) ──
Condition: Always
  Then: Add force to Enemy
    towards Player, speed 150

── INVENTORY SYSTEM ──
Condition: Variable "has_key" = 1
  Then: Delete object "Door"

── DIALOGUE BOX ──
Condition: Key [E] pressed
  Then: Show object "DialogBG"
  Then: Display text "Hello!" on "DialogText"
  Then: Pause the game
