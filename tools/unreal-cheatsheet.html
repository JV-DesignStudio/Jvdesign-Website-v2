Unreal Engine 5 Cheat Sheet

A one-page printable reference for UE5 Blueprints and C++ covering classes, UPROPERTY, UFUNCTION, movement, input, collision and common gameplay patterns.

🎮 Blueprint Nodes

// Core lifecycle
Event BeginPlay       — runs once on spawn
Event Tick            — runs every frame
Event Any Damage      — receives damage

// Actor spawning & control
Get Player Character  — reference to player
Get Player Controller — player controller ref
Spawn Actor from Class — spawn an actor
Destroy Actor         — remove from world

// Transform
Set Actor Location    — move to vector
Get Actor Location    — current world pos

// Movement
Add Movement Input    — push movement dir
Get Forward Vector    — actor forward dir

📦 C++ Classes

AActorBase spawnable object in the world
APawnActor that can be possessed by a controller
ACharacterPawn with CharacterMovementComponent built in
APlayerControllerHandles player input and HUD
AGameModeBaseServer-side rules, spawning, game state
UActorComponentNon-attached reusable component
USceneComponentComponent with transform (position, rotation)

🏷️ UPROPERTY Specifiers

EditAnywhereEditable in any Details panel
BlueprintReadWriteRead & write from Blueprints
VisibleAnywhereVisible but not editable in Details
CategoryGroup properties in panel sections
meta=(ClampMin)Minimum allowed value for numerics
meta=(ClampMax)Maximum allowed value for numerics
UPROPERTY(EditAnywhere, Category="Stats")
float Health = 100.f;

UPROPERTY(BlueprintReadWrite, meta=(ClampMin="0", ClampMax="100"))
float Speed = 600.f;

⚡ UFUNCTION Specifiers

BlueprintCallableCan be called from Blueprints
BlueprintPureNo side effects, no exec pin needed
BlueprintImplementableEventOverride in Blueprint only
BlueprintNativeEventOverride in C++ or Blueprint
UFUNCTION(BlueprintCallable)
void TakeDamage(float Amount);

UFUNCTION(BlueprintPure)
float GetHealthPercent() const;

UFUNCTION(BlueprintNativeEvent)
void OnDeath();
void OnDeath_Implementation();

🏃 Movement

GetMovementComponent()  — access CMC

// Movement input
AddMovementInput(GetActorForwardVector(), 1.0f);

// Jumping
Jump()          — initiate jump
StopJumping()   — stop jump early

// In C++
CharacterMovement->MaxWalkSpeed = 600.f;

🎯 Input (Enhanced Input)

// Assets needed
InputAction          — defines an action
InputMappingContext  — maps keys to actions

// In C++ (BeginPlay)
EnhancedInput->BindAction(
    IA_Move, ETriggerEvent::Triggered,
    this, &AMyCharacter::Move);

// Reading input value
void Move(const FInputActionValue& Value) {
    FVector2D Input = Value.Get<FVector2D>();
    AddMovementInput(GetActorForwardVector(), Input.Y);
    AddMovementInput(GetActorRightVector(), Input.X);
}

// BindAction in Enhanced Input
BindAction(IA_Jump, ETriggerEvent::Started,
           this, &ACharacter::Jump);
BindAction(IA_Jump, ETriggerEvent::Completed,
           this, &ACharacter::StopJumping);

💥 Collision

// Overlap callbacks (C++)
OnComponentBeginOverlap(Component, OtherActor,
    OtherComp, OtherBodyIndex, bFromSweep, SweepResult);

OnComponentEndOverlap(Component, OtherActor,
    OtherComp, OtherBodyIndex);

// Hit callback
OnHit(HitComponent, OtherActor, OtherComp,
    NormalImpulse, Hit);

// Line trace (C++)
FCollisionQueryParams Params;
Params.AddIgnoredActor(this);

LineTraceSingleByChannel(
    HitResult, Start, End,
    ECC_Visibility, Params);

📐 Math Types

FVector3D vector: FVector(X, Y, Z)
FRotatorRotation: FRotator(Pitch, Yaw, Roll)
FTransformPosition + rotation + scale combined
FMath::LerpLinear interpolation between two values
FMath::ClampClamp value between min and max
FMath::SqrtSquare root of a value
FMath::Atan2Angle from Y and X components
// Common usage
FVector Pos = GetActorLocation();
FVector Dir = Target - Pos;
float Dist = Dir.Size();
FVector Norm = Dir.GetSafeNormal();

float Speed = FMath::Lerp(0.f, MaxSpeed, Alpha);
float Val = FMath::Clamp(Val, 0.f, 1.f);

🛠️ Common Patterns

── PLAYER CONTROLLER SETUP ──
void AMyGameMode::BeginPlay() {
    Super::BeginPlay();
    DefaultPawnClass = AMyCharacter::StaticClass();
    PlayerControllerClass = AMyPlayerController::StaticClass();
}

── ENEMY AI ──
void AEnemy::Tick(float DeltaTime) {
    Super::Tick(DeltaTime);
    FVector Dir = Player->GetActorLocation() - GetActorLocation();
    Dir.Z = 0;
    AddMovementInput(Dir.GetSafeNormal(), 1.0f);
}

── HEALTH SYSTEM ──
void AMyCharacter::TakeDamage(float Amount) {
    Health = FMath::Clamp(Health - Amount, 0.f, MaxHealth);
    if (Health <= 0.f) OnDeath();
}

── SPAWN ACTOR ──
FActorSpawnParameters Params;
Params.Owner = this;
GetWorld()->SpawnActor<AProjectile>(
    ProjectileClass, MuzzleLoc, MuzzleRot, Params);

── SAVE GAME ──
USaveGame* Save = CreateObject<USaveGame>();
UGameplayStatics::SaveGameToSlot(Save, "Slot1", 0);
UGameplayStatics::LoadGameFromSlot("Slot1", 0);

── CAMERA FOLLOW ──
void AMyCharacter::Tick(float DeltaTime) {
    Super::Tick(DeltaTime);
    FVector Target = GetActorLocation();
    FVector CamLoc = FVector(Target.X, Target.Y, Target.Z + 500.f);
    SpringArm->SetWorldLocation(
        FMath::Lerp(SpringArm->GetComponentLocation(), CamLoc, DeltaTime * 5.f));
}
