Scratch Block Reference Cheat Sheet

A one-page printable reference for Scratch blocks — motion, looks, sound, events, control, sensing, operators and variables. Pin it next to your monitor!

➡️ Motion Blocks

move() stepsMove sprite forward by N steps
turn right () degreesTurn clockwise N degrees
turn left () degreesTurn counter-clockwise N degrees
go to x: () y: ()Teleport to position
go to [random position]Move to random spot on stage
glide () secs to x: () y: ()Smooth move over time
point in direction ()Face a compass direction (0-360)
if on edge, bounceReverse at stage edges
set x to ()Set horizontal position
set y to ()Set vertical position
change x by ()Move horizontally
change y by ()Move vertically
x positionReporter: current X
y positionReporter: current Y

👁️ Looks Blocks

say () for () secsShow speech bubble with timer
say ()Show speech bubble (until changed)
think () for () secsShow thought bubble with timer
think ()Show thought bubble (until changed)

hideMake sprite invisible
switch costume to ()Change sprite appearance
next costumeCycle to next costume
switch backdrop to ()Change stage background
next backdropCycle to next backdrop
change size by ()Grow or shrink by percent
set size to () %Set exact size
change graphic effect by ()Alter visual effect
clear graphic effectsReset all effects
go to front layerMove to top of draw order

🔊 Sound Blocks

volumeReporter: current volume
change pitch effect by ()Alter pitch
set pitch effect to ()Set exact pitch

stop [other scripts in sprite]Kill sibling scripts

when I start as a cloneClone entry point

── ARITHMETIC ──

── COMPARISON ──
( 5 > 3 )     -- greater than

── LOGIC ──
<> and <>  -- both true
<> or <>   -- either true

── STRINGS ──

🛠️ Common Patterns

── GAME LOOP (forever) ──
when green flag clicked
forever
    if <key [left arrow] pressed?> then
        change x by (-5)
    end
    if <key [right arrow] pressed?> then
        change x by (5)
    end
end

── COLLISION DETECTION ──
when green flag clicked
forever
    if <touching [enemy] ?> then
        change [lives] by (-1)
        go to x: (0) y: (0)
    end
end

── SCORE TRACKING ──
when green flag clicked
set [score] to (0)
forever
    if <touching [coin] ?> then
        change [score] by (10)
        hide
        wait (0.5) secs
        go to x: (pick random -200 to 200) y: (150)
        show
    end
end

── TIMER / COUNTDOWN ──
when green flag clicked
set [timer] to (60)
forever
    wait (1) secs
    change [timer] by (-1)
    if <(timer) = 0> then
        say ("Game Over!") for (3) secs
    end
end

── CLONE ENEMIES ──
when green flag clicked
forever
    wait (2) secs
    create clone of [ myself ]
end
when I start as a clone
go to x: (pick random -220 to 220) y: (180)
forever
    change y by (-3)
    if <touching [edge] ?> then
        delete this clone
    end
end
