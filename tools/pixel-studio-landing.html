Features

A real editor, not a toy

Everything you need to go from blank canvas to game-ready sprite.

🖌️

Full Tool Set

Pencil, eraser, fill bucket, eyedropper, line and rectangle tools, with brush sizes up to 16px and right-click background drawing.

🗂️

Layers

Stack up to 8 layers per frame with visibility toggles, duplication, thumbnails and merge-down.

🎬

Animation Frames

Unlimited frames, adjustable FPS playback, duplicate frames and onion skinning for smooth walk cycles.

⇋

Mirror Mode

Symmetry drawing that mirrors every stroke across the canvas, perfect for faces, badges and icons.

⬇️

GIF + Spritesheet Export

Export animated GIFs, PNG spritesheets and scaled PNGs up to 512px. Import existing PNGs and sheets too.

💾

Autosave + Project Files

Work autosaves as you draw and restores on return. Save re-openable project files to keep or share.

👆

Touch First

A dedicated mobile tool bar, palm-friendly layout and pinch-friendly canvas. Draw on a phone, finish on a laptop.

🎮

Straight Into Your Game

One click sends your sprite to the JVDS Arcade Game Maker. Draw it, then play with it immediately.

How it works

From blank canvas to sprite in 3 steps

1

Draw

Pick a canvas size from 8x8 to 128x128, choose colours and sketch with pencil, fill and mirror mode.

2

Animate

3

Export

FAQ

Questions, answered

Is Pixel Studio really free?

Yes, completely free, no account, and no watermark on anything you export.

Can I use the art I make commercially?

Yes. Everything you draw is yours, including use in commercial games, apps and products.

Does it work on phones and tablets?

Yes. There's a touch-first mobile layout, and you can install Pixel Studio as an app on Android, iOS, Windows and macOS. It then works offline.

What can it export?

Animated GIFs, PNG spritesheets, scaled PNGs, and .json project files you can re-open later. It also imports PNGs and existing spritesheets.
