Before you start

A few useful details

Do I need an account or installation?

No. Open Pixel Studio in your browser - start in Simple, then try Character or Draw when ready.

Where is my saved work?

Save stays in this browser on this device. Clearing browser data can remove it, so export PNG / spritesheet / GIF to keep finished art.

Where is my old Pixel Character Studio link?

It now redirects to the unified Pixel Studio. Your old jvds_chars saves are still on this device.
