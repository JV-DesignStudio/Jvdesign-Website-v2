## Achievement Rarity Tiers

**Common** (🎮) — First play, intro achievements — **25 XP**
**Uncommon** (⭐) — Skill-based, milestone achievements — **50-75 XP**
**Rare** (👑) — Challenge achievements, high scores — **100-150 XP**
**Epic** (🔥) — Mastery, grind achievements — **200-250 XP**
**Legendary** (🏆) — Perfection, cross-game, ultimate challenges — **300+ XP**

---

## Implementation Notes

1. **Rarity Distribution:** Per game, aim for: 1-2 Common, 2-3 Uncommon, 1-2 Rare, 1 Epic
2. **XP Rewards:** Sum to ~500-750 XP per game when completing all achievements
3. **Progression:** One achievement per 15-20 minutes of playtime
4. **Testing:** Every achievement should have clear unlock condition
5. **Naming:** Use emoji prefix for quick visual identification

---

## Adding New Achievements

When creating achievements for a new game:

1. Reserve IDs: `gameId-achievementName` format
2. Use existing emoji set for consistency
3. Target 5-8 achievements per game
4. Include one "first play" achievement
5. Include one "extreme grind" achievement
6. Include one "perfect/flawless" achievement
7. Distribute across rarities
8. Document unlock conditions clearly
