Send your game to the Gallery

Made something you are proud of? Send it in. Pip plays every game before it appears, so the gallery stays fun and safe for everyone.

🛠 Back to the maker 👀 See the gallery

How it works. 1. Build your game in the maker. 2. Press Publish to Gallery: it saves your playable file and a cover picture. 3. Fill in this form and attach both files. 4. We check it, then it goes live.

Send it in

Ask a grown-up to help with the email if you are under 13. Nothing is published until we have checked it.
