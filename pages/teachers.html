Printable Lesson Plans

Three ready to teach plans matched to popular workshops. Each fits a single lesson on locked down school computers: a browser is the only equipment. Open the plan, press Print, and it prints cleanly on its own.

Do Not Drop It: Fruit Catch in Scratch

Workshop: Do Not Drop It! Build a Fruit Catch Game in Scratch

Ages 7 to 1060 minutesBeginnerKS2 Computing

Learning objectives

  • Use loops to keep a game running and spawning fruit.
  • Describe what collision detection does in your own words.
  • Change one variable and predict what happens to the score.

You will need

  • One browser per pair. Nothing to install and no accounts.
  • Projector or whiteboard for the starter demo.

Starter, 10 minutes

  1. Play the finished game once as a class. Ask: what repeats, and what happens on a catch?
  2. Introduce three words: sprite, loop, collision. Pupils repeat each back with an action.

Main, 35 minutes

  1. Steps 1 and 2 of the workshop: bowl sprite and movement. Checkpoint: every bowl moves left and right.
  2. Steps 3 and 4: falling fruit and catching. Checkpoint: catches add to the score.
  3. Fast finishers: change the fall speed variable and record the effect.

Plenary, 10 minutes, plus 5 spare

  1. Pairs playtest each other's game and name one improvement.
  2. Exit ticket on paper: finish the sentence, collision detection means...

Support and stretch

  • Support: work in threes with roles for driver, navigator and checker.
  • Stretch: add a second fruit type worth double points.

My First Python Game: Fruit Catch

Workshop: My First Python Game Ep 1: Fruit Catch

Ages 9 to 1360 minutesBeginnerKS2 and KS3 Computing

Learning objectives

  • Store and update a score in a variable.
  • Read x and y coordinates to place the catcher.
  • Explain what the game loop does, line by line.

You will need

  • One browser per pair. The code runs on the workshop page itself.
  • Mini whiteboards for the starter predictions.

Starter, 10 minutes

  1. Show three lines from the workshop: score equals zero, move, and draw. Pupils predict what each line changes.
  2. Agree definitions: variable, coordinate, loop.

Main, 35 minutes

  1. Work through the workshop steps in pairs. Checkpoint: fruit falls and the catcher moves.
  2. Checkpoint: the score goes up on every catch and misses do nothing.
  3. Fast finishers: raise the fall speed and note the new high score.

Plenary, 10 minutes, plus 5 spare

  1. Each pair demonstrates one change they made and what it did.
  2. Exit ticket: what does the game loop repeat, and why does the game need it?

Support and stretch

  • Support: pair a confident reader with each beginner, and read code aloud before running it.
  • Stretch: add a lives counter that ends the game at zero.

My First Browser Game: Snake

Workshop: My First Browser Game Ep 4: Snake

Ages 10 to 1460 to 90 minutesIntermediateKS3 Computing

Learning objectives

  • Store the snake body in an array and explain head versus tail.
  • Use a direction vector to move the snake each frame.
  • Detect wall and self collisions and end the game cleanly.

You will need

  • One browser per pair. Nothing to install and no accounts.
  • Printed arrow cards for the unplugged starter, or draw arrows on the board.

Starter, 10 minutes

  1. Unplugged: one pupil is the head and calls directions while a line of pupils follows. The line shows what the array holds.
  2. Agree definitions: array, vector, collision.

Main, 40 to 60 minutes

  1. Build movement and food. Checkpoint: the snake eats and grows.
  2. Add wall and self collision. Checkpoint: the game ends and restarts.
  3. Fast finishers: raise the speed each time food is eaten.

Plenary, 10 minutes

  1. Tournament: highest score on each table, then a class final.
  2. Exit ticket: draw the array after three moves right and one move down.

Support and stretch

  • Support: complete movement together as a class before pairs continue alone.
  • Stretch: add a high score that survives a restart.

Classroom Starter Pack

Five lessons that take a class from their first game to certificates in about four hours of teaching time. Everything runs in the browser with no install and no accounts. Print the pack for your desk, then send the matching class link to your pupils.

Five lessons from first click to certificates

About 4 hours totalAges 7 to 14No install
  1. Lesson 1, 15 minutes, taster. Build a Game in 15 Minutes: Dot Smash. Whole class on the whiteboard. Goal: every pupil sees a finished game fast.
  2. Lesson 2, 60 minutes, Scratch and loops. Do Not Drop It! Build a Fruit Catch Game in Scratch. Pairs build the bowl, the fruit and the score. Lesson plan.
  3. Lesson 3, 60 minutes, Python and variables. My First Python Game Ep 1: Fruit Catch. Same game idea, real typed code. Lesson plan.
  4. Lesson 4, 60 to 90 minutes, JavaScript and arrays. My First Browser Game Ep 4: Snake. The snake body is an array pupils can draw. Lesson plan.
  5. Lesson 5, 30 minutes, showcase. Free build in Click Frenzy! Build an Idle Clicker Game in Scratch, then certificates from the tracker below.

First day checklist

  • Open lesson 1 on the whiteboard before pupils arrive. One tab, full screen.
  • Seat pupils in pairs with one browser between two. No logins needed anywhere.
  • Bookmark the class link (below) on every machine so pupils land on the right lesson.
  • End lesson 5 with printed certificates while the work is fresh.
