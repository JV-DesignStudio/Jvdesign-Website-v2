What is game design, exactly?

Game design is deciding how a game works: what the player can do, what makes it fun, and how it ends. You do not need to be able to draw or code to start. The tools here help you make those decisions by building a real thing, not by reading a textbook.

What a child will learn

  • How to break a problem into small steps
  • How rules and logic create a player experience
  • How to test an idea and improve it based on feedback
  • How to finish something and feel proud of it

These are the same skills used in real game studios, and they transfer to other creative and technical work too.

Common questions

Does my child need a coding background?

No. The Scratch and GDevelop workshops use visual blocks. The Godot and Python workshops introduce code gradually, starting from zero. Every workshop assumes the learner is starting fresh.

Will it work on a school computer?

Yes. All browser tools run on any computer without admin rights, plugins or installs. Scratch runs in a browser. Godot and GDevelop have web editors that work the same way.

How long does a first project take?

The shortest workshops produce a working game in 15 minutes. A first full workshop (Scratch or GDevelop) usually takes two to three one-hour sessions.

Can a child use this alone or do they need supervision?

The browser tools and Scratch workshops are designed to be used independently. Godot and code-based workshops are recommended with a parent or teacher nearby for the first session, but most children 12 and up can follow them alone.
