Free Game Making Tools in a Browser

Every tool on this page runs in a browser with no download, no account and no powerful computer required. They all work on a locked-down school computer.

Looking for workshops that teach you how to use these tools step by step? The workshop hub has guided courses for each engine. Or jump straight into the Create hub to open a tool now.

Design and art tools

Design

Pixel Character Studio

Design a pixel art game character, animate it, and download the sprite sheet. No account, works offline.

 Design

Game Colour Palette Builder

Pick a colour scheme that works for games. Saves as a file you can use in any tool.

Game planning tools

Planning

Game Design Document Builder

Fill in a guided template and export your game idea as a PDF. Good for school projects and game jams.

 Planning

Quest Board

Track what to build next in your game. A visual task board that saves in your browser.

Browser game builders

Make

Arcade Game Maker

Build and share a browser game without writing a single line of code. Download it or share a link.

 Workshop

Build a Game in 15 Minutes

A guided workshop that produces a working game by the end. No prior experience needed.

Why browser-based tools?

Most game engines require a download, admin rights or a powerful graphics card. That locks out students on school computers and families sharing a low-spec laptop. Browser tools remove that barrier. The trade-off is that browser tools are simpler, but that is also what makes them the right place to start.

Once you have made your first game in a browser tool, moving to Godot, GDevelop or Scratch feels natural because you already understand what a game needs to be fun.
