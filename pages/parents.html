Safety

Safety & data, plain English

🔒
No accounts

No login, no password, nothing to create.

💬
No chat, no comments

Children cannot contact each other on this site.

📦
All progress stays in this browser

Stored in localStorage. Export a backup file or transfer code when you need to move devices. No server copy.

📊
Analytics denied until you accept

Google Analytics loads only after the cookie banner's Accept. Decline or ignore = no tracking. Cookie settings

🎮
No advertising on the website

Apps may show ads, the website never does.

🔗
Off-site links are explicit

Scratch, Roblox Studio, itch.io workshops open in a new tab. We label them as leaving jvdesignstudio.co.uk.

UK GDPR / Age Appropriate Design Code

Withdrawal is as easy as consent: footer → Cookie settings clears the choice and re-shows the banner. No personal data beyond analytics (if consented) is collected. Contact for data questions: via Contact.
