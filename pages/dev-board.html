Bitmap Font Maker — No BMFont XML Export
BMFont XML (.fnt + spritesheet PNG) is the universal bitmap font format supported by Unity, Godot, LibGDX, Phaser. Without it, the tool output can't be used in any engine.
ToolsHighbitmap-font-maker.html
Tileset Builder — No Engine Export

BuildLab — Mislabelled Export Formats
GLTF export is labelled "Blender" but Godot 4 also imports GLTF natively. OBJ is labelled "Unreal" but works in Unity, Godot, and Blender too. Devs on Godot won't know they can use GLTF.
ToolsMediumbuildlab.html
Colour Palettes — No Lospec Export
No .hex or .gpl (GIMP palette) export. Lospec format is the universal standard for pixel art palettes — every pixel artist imports from Lospec. PNG export only is insufficient.
ToolsMediumcolour-palettes.html
Sprite Sheet Animator — No Aseprite JSON
Aseprite JSON is the standard sprite sheet format supported by Godot, Unity, Phaser, and most engines. Without it, devs must manually recreate frame data.
ToolsMediumsprite-animator.html
Game Logo Maker — No SVG Export
Logos must be scalable. PNG only export means the logo degrades at different resolutions. SVG is essential for print, store pages, and press kits.
ToolsMediumgame-logo-maker.html
