READ THIS BEFORE WORKING ON JVDS

JVDesignStudio exists so young people can learn, create and play without barriers.

JVDS grew from a family of characters and stories that inspired creativity, and from the real-world need to teach young people on restricted school computers where downloads, installs, accounts and traditional creative software often are not available. The toolbox is not extra clutter: browser-first tools are the solution to those restrictions.

Creativity shouldn't need permission.
Agents: read JVDS_PRODUCT_VISION.md before architectural, UX, content or feature decisions.

Core Creative Loop

Every meaningful experience should help a learner move through the JVDS loop and come back braver for the next idea.

ImagineStardust
LearnLumo
CreateEmber
PlayPip
ImproveEcho

Then return to Imagine again, with Stardust pulling the next possibility into view.

Before You Build Anything

  • Does it help a young person make, understand, play or improve something?
  • Does it strengthen the core creative journey?
  • Can it work in a restricted school/browser environment?
  • Can an existing tool be improved instead of adding a disconnected one?
  • Does it respect the characters as the heart and identity of JVDS, not decoration?
  • Is it genuinely more important than the learner's first successful creation?

If not, don't build it yet.

The School-Computer Rule

Core JVDS experiences should require:

No installation No admin rights No paid software No powerful PC No account to start

Open the browser. Start creating.

Current Product Goal

A new learner should be able to arrive at JVDS and make something they are proud of within 15 minutes.

Do not measure progress by how many pages ship. Measure progress by what learners are able to create.

CURRENT MISSION

Make the first successful creation feel obvious, joyful and achievable on a locked-down school computer: arrive, understand the path, make something, save or export it, and know what to improve next.

Define the First Project Mission

Chosen: Make your first pixel character in the merged Pixel Character Studio. The mission starts from the homepage Create path and toolbox callout.

Acceptance: 15-minute path opens Character Designer, lets learners design, pixel-edit, animate, export and improve. Classic Pixel Studio remains for general sprites/tiles.
Make the Start Path Obvious

Give new learners a visible entry route from arrival to first action, with Stardust and Lumo guiding the first choice.

Outcome: learner knows what to click first.
Guarantee Save or Export

Check the chosen first tools let learners keep evidence of their work without accounts, installs or paid software.

Outcome: creation can be saved, downloaded or copied.
Connect Tools Into the Loop

Started: Toolbox now has outcome-led Start Here paths, key tool cards explain the next handoff, and core tools show in-tool next-step panels.

Acceptance: keep expanding handoffs after save/export events, then run a learner through the whole first-creation loop.
Test the First 15 Minutes

Run JVDS as a new learner and record where confusion, friction, blocked exports or missing guidance interrupt the first creation.

Outcome: dated notes and fixes against the North Star.
