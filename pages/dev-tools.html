    Start with what you want to make

    Pick a path and make something shareable

    Each path is three small steps through tools you already have. Every one ends with something you can save, export or share.

    🧑‍🎨

    Make a character

    Draw a sprite, animate it, then share a character card.

    Skip the blank page Start with a template Remix a finished sprite Surprise me
    1. 1 Draw your sprite Pixel Studio. Start with a simple 8x8 or 16x16 character. Export PNG or GIF. Keep sprites between 8x8 and 256x256.
    2. 2 Animate it Sprite Animator. Add a few frames and set the timing. Upload a PNG (or GIF) spritesheet. Frames up to 512x512.
    3. 3 Share the card Trading Card Designer. Drop in your art and export a PNG. Upload PNG, JPG or WebP art. Export PNG or 300 DPI print PNG. Export
    🕹️

    Make a game

    Draw a hero, build a level, then share a playable game.

    Skip the blank page Start with a game template Remix a finished game Surprise me
    1. 1 Make the hero Pixel Studio. Draw one character sprite for your game. Export PNG. Sprites between 8x8 and 256x256 load best.
    2. 2 Build the world World Builder. Lay out a small level with platforms. Import a PNG tileset. Export JSON, Godot data or PNG.
    3. 3 Ship and share it Arcade Game Maker. Load your art and level, then share a playable link. Sprites PNG up to 512x512 (2.8 MB). Backgrounds JPG or PNG up to 800x600 (3.5 MB). Share
    🎵

    Make music and sound

    Start a loop, add a sound effect, then hear it in a game.

    Skip the blank page Start with a beat Remix a finished loop Surprise me
    1. 1 Make a loop Audio Studio. Use Music mode for a short backing loop. Export WAV, ready for a game.
    2. 2 Add a sound effect Audio Studio. Switch to SFX and make a jump or coin sound. Export WAV (or load a MIDI file to start).
    3. 3 Put it in a game Arcade Game Maker. Load your sounds and share the build. Upload MP3 or WAV sound files. Share
    🧭

    Get unstuck

    Find the fix, copy working code, then plan your next move.

    Skip the blank page Start from a working snippet Remix a working fix Surprise me
    1. 1 Find the bug Error Guide. Look up the error in plain language.
    2. 2 Grab a working snippet Code Snippet Generator. Copy a starter for the pattern you need.
    3. 3 Plan the fix Game Planner. Turn the fix into quests and export the plan. Export
