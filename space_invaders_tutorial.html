How to Use This Guide

Read this first it makes everything easier!

This guide is split into short chapters. Each chapter builds one small part of the game. You do NOT need to read it all at once just do one chapter, test it, then move to the next.

🟣 DO THIS boxes numbered steps to follow in order. Always do every step before moving on.
✅ Checkpoint boxes after every chapter, check these things in Godot to make sure it worked.
💡 Tip boxes helpful hints to make things easier.
⚠️ Watch Out boxes common mistakes to avoid.
🎉 Well Done boxes celebration! These appear when you finish something big.
📖 Info boxes explain a tricky idea in plain language before you need to use it.
💡

Rule number one

Type the code yourself don't copy-paste.

Your fingers learn coding the same way they learn piano: by doing it.

It's okay to be slow. It's okay to make mistakes. That's how you learn!
💡

If something breaks

Read the red error message it always tells you which line has a problem.

Check for missing tabs at the start of lines inside functions.

Check for missing quotes around words like "aliens".

Close and reopen Godot if everything looks weird.

You can always come back and re-read the step you were on.

Godot is a free program that turns your code into a real game.

It handles the window, the graphics, the sounds all the boring stuff.

You focus on the fun part: telling the game what to DO.

Download it free at: godotengine.org

What is an Autoload?

A normal script only works while its scene is open.

An Autoload script runs ALL the time forever.

Perfect for score and lives, because we need them to stay even when scenes change.

Here is the first part of the Player script. Type this first, then we will add more:

# Player.gd — part 1: variables and signals

extends Area2D

# Signals are messages this script can send

# When the player shoots, tell Main where the bullet starts

signal bullet_fired(pos)

# When the player is hit, tell Main

signal player_hit

# @export lets you change these numbers in the Inspector

@export var speed: float = 200.0

@export var shoot_cooldown: float = 0.35

# Private variables (start with _ so we know they are internal)

var _cooldown: float = 0.0

var _alive: bool = true

const SCREEN_W = 480.0

const HALF_W = 20.0
💡

What is a signal?

Imagine the player shouts 'I got hit!' that's a signal.

Other parts of the game can listen for that shout and react.

Signals keep different parts of your code from getting tangled up.

Now type the movement and shooting code below the lines you already typed:

# Player.gd part 2: movement and shooting

# _process runs every frame about 60 times per second

func _process(delta: float) -> void:

if not _alive:

return

_cooldown -= delta

# Check which keys are held down

var dir := 0.0

if Input.is_key_pressed(KEY_LEFT) or Input.is_key_pressed(KEY_A):

dir = -1.0

if Input.is_key_pressed(KEY_RIGHT) or Input.is_key_pressed(KEY_D):

dir = 1.0

# clamp keeps the ship inside the screen

position.x = clamp(position.x + dir * speed * delta,

HALF_W, SCREEN_W - HALF_W)

# Shoot when SPACE or Z is pressed

if _cooldown <= 0 and (

Input.is_key_pressed(KEY_SPACE) or

Input.is_key_pressed(KEY_Z)

):

_cooldown = shoot_cooldown

bullet_fired.emit(position + Vector2(0, -20))
📖

What is delta?

delta is the time since the last frame usually 0.016 seconds.

We multiply speed by delta so the game runs the same on all computers.

On a fast computer, delta is small. On a slow one, delta is bigger.

Either way, distance = speed × delta gives the same movement per second!

Finally, add the die() function at the bottom:

# Player.gd — part 3: the die function

# Called when an enemy bullet hits us

func die() -> void:

if not _alive:

return

_alive = false

player_hit.emit()

hide()

Press Ctrl+S to save.

Chapter 4

The Bullet

Both the player and the aliens fire bullets. We build ONE bullet scene and reuse it for both we just change the direction.

DO THIS

11

Create the Bullet scene

→ Click Scene → New Scene

→ Create an Area2D root node, rename it: Bullet

→ Add a Sprite2D child

→ Add a CollisionShape2D child set shape to CapsuleShape2D

→ Save as: Bullet.tscn

→ Attach a new script: Bullet.gd

Type this code in Bullet.gd:

# Bullet.gd

extends Area2D

# -1.0 = flies UP (player bullet)

# +1.0 = flies DOWN (enemy bullet)

@export var direction: float = -1.0

@export var speed: float = 400.0

@export var is_enemy: bool = false

var _anim_t: float = 0.0

func _process(delta: float) -> void:

# Move the bullet up or down

position.y += speed * direction * delta

# Enemy bullets zigzag flip between 2 frames

if is_enemy:

_anim_t += delta * 8

$Sprite2D.frame = int(_anim_t) % 2

# Delete the bullet if it leaves the screen

if position.y < -20 or position.y > 650:

queue_free()
💡

queue_free() what does that do?

queue_free() tells Godot to delete this node.

It doesn't delete it RIGHT now it waits until the end of the frame.

That is safer than deleting it instantly while the game is still using it.

One Alien

We build a single alien scene. Later the AlienGrid script will create 55 copies of it automatically.

DO THIS

12

Create the Alien scene

→ Scene → New Scene

→ Create an Area2D root, rename it: Alien

→ Add an AnimatedSprite2D child (NOT Sprite2D this one animates!)

→ Add a CollisionShape2D child set shape to RectangleShape2D

→ Save as: Alien.tscn

→ Attach a new script: Alien.gd
📖

AnimatedSprite2D — how does it work?

You give it several frames (pictures) and it flips through them like a cartoon.

We need 3 animations: 'a' (squid alien), 'b' (crab alien), 'c' (ufo alien).

Each animation has 2 frames open legs and closed legs to make them walk.

We will set up the actual images in Chapter 8 when we do the artwork.

Type this in Alien.gd:

# Alien.gd

extends Area2D

# This signal fires when the alien dies

# It sends the points and the position so Main can add to the score

signal alien_killed(points, pos)

# 0 = squid (10pts) 1 = crab (20pts) 2 = ufo-row (30pts)

@export var alien_type: int = 0

@export var points: int = 10

func _ready() -> void:

# Add to group lets Main find all aliens at once

add_to_group("aliens")

# Play the right walking animation

match alien_type:

0: $AnimatedSprite2D.play("a")

1: $AnimatedSprite2D.play("b")

2: $AnimatedSprite2D.play("c")

func die() -> void:

alien_killed.emit(points, global_position)

queue_free()
📖

What is a group?

A group is a label you put on nodes.

add_to_group("aliens") puts this alien in the "aliens" group.

Later, Main can ask: get_nodes_in_group("aliens") and get every alien at once.

Much easier than keeping track of them one by one!

Chapter 6

The Alien Grid

This is the most complex script in the game. Take your time — read each section carefully before typing it.

The AlienGrid script does three jobs:

• Fills the screen with 55 aliens (11 columns × 5 rows)

• Marches them sideways, drops them down when they hit an edge

• Picks a random alien to shoot at the player

DO THIS

13

Create the AlienGrid script

→ In FileSystem, right-click res:// → New Script

→ Name it: AlienGrid.gd

→ Click Create

→ We will attach it to a node in the Main scene later

Type the variables section first:

# AlienGrid.gd part 1: variables

extends Node2D

signal all_dead

signal reached_bottom

signal enemy_bullet_fired(pos)

const COLS = 11

const ROWS = 5

const SPACING_X = 36

const SPACING_Y = 32

const SCREEN_W = 480.0

const ROW_POINTS = [30, 20, 20, 10, 10]

var aliens: Array = []

var _dir: float = 1.0

var _step_timer: float = 0.0

var _step_interval: float = 0.8

var _drop_next: bool = false

var _shoot_timer: float = 1.5

var _alive_count: int = 0

const AlienScene = preload("res://Alien.tscn")

const ExplosionScene = preload("res://Explosion.tscn")
💡

preload what does that mean?

preload loads a scene file when the game starts.

Later we can call AlienScene.instantiate() to create a new copy of that scene.

Think of it like loading a cookie cutter then you can stamp out as many cookies as you want!

Now add the _ready and _spawn_grid functions:

# AlienGrid.gd — part 2: spawning

func _ready() -> void:

_spawn_grid()

func _spawn_grid() -> void:

aliens = []

_alive_count = 0

for r in range(ROWS):

var row = []

for c in range(COLS):

var a = AlienScene.instantiate()

# Top row = type 2, middle = type 1, bottom = type 0

var atype = 2 if r == 0 else (1 if r < 3 else 0)

a.alien_type = atype

a.points = ROW_POINTS[r]

a.position = Vector2(c * SPACING_X, r * SPACING_Y)

a.alien_killed.connect(_on_alien_killed)

add_child(a)

row.append(a)

_alive_count += 1

aliens.append(row)

Now the _process function that runs every frame:

# AlienGrid.gd — part 3: process loop

func _process(delta: float) -> void:

_step_timer -= delta

if _step_timer <= 0:

_step_timer = _step_interval

_march()

_shoot_timer -= delta

if _shoot_timer <= 0:

_shoot_timer = randf_range(0.6, 2.2)

_random_shoot()

Now the marching logic:

# AlienGrid.gd part 4: marching

func _march() -> void:

if _drop_next:

_drop_next = false

_dir = -_dir

position.y += 12

if position.y > 420:

reached_bottom.emit()

return

position.x += _dir * 12

var world_right = global_position.x + _rightmost_x()

var world_left = global_position.x + _leftmost_x()

if world_right > SCREEN_W - 10 or world_left < 10:

_drop_next = true

func _leftmost_x() -> float:

for c in range(COLS):

for r in range(ROWS):

if is_instance_valid(aliens[r][c]):

return c * SPACING_X - SPACING_X * 0.5

return 0.0

func _rightmost_x() -> float:

for c in range(COLS - 1, -1, -1):

for r in range(ROWS):

if is_instance_valid(aliens[r][c]):

return c * SPACING_X + SPACING_X * 0.5

return 0.0

Now the shooting and death handling:

# AlienGrid.gd part 5: shooting and death

func _random_shoot() -> void:

var shooters = []

for c in range(COLS):

for r in range(ROWS - 1, -1, -1):

if is_instance_valid(aliens[r][c]):

shooters.append(aliens[r][c])

break

if shooters.is_empty():

return

var shooter = shooters[randi() % shooters.size()]

enemy_bullet_fired.emit(shooter.global_position + Vector2(0, 14))

func _on_alien_killed(pts: int, pos: Vector2) -> void:

_alive_count -= 1

for r in range(ROWS):

for c in range(COLS):

if is_instance_valid(aliens[r][c]) and not aliens[r][c].is_inside_tree():

aliens[r][c] = null

var expl = ExplosionScene.instantiate()

expl.global_position = pos

get_parent().add_child(expl)

# Speed up as fewer aliens are left

_step_interval = max(0.08, 0.8 * (_alive_count / float(COLS * ROWS)))

if _alive_count <= 0:

all_dead.emit()

func reset_for_wave(wave: int) -> void:

for c in get_children(): c.queue_free()

aliens = []

_dir = 1.0

_step_interval = max(0.15, 0.8 - (wave - 1) * 0.08)

_drop_next = false

position = Vector2(20, 40 + (wave - 1) * 4)

_spawn_grid()

Save AlienGrid.gd.

✅ Checkpoint your game should now:

☐ AlienGrid.gd is saved with no error lines

☐ The script has all 5 parts typed in
🎉

The hardest script is done!

AlienGrid.gd is the most complex part of the whole game.

If you got through that, the rest will feel easy!

Chapter 8

Drawing the Sprites

Every game needs pictures! Here are all the images you need to draw and save as PNG files.

📖

How to make sprites:

Use any drawing program MS Paint, Krita (free), or Aseprite (great for pixel art).

Draw small and simple 32×32 pixels is plenty for an alien!

Save every image as a .png file.

Drag PNG files from your computer into Godot's FileSystem panel to import them.

Images to draw:

Image file
player.png 48 × 32 Your spaceship a triangle or rocket shape works great
alien_a.png 64 × 24 2 frames side by side (32px each) small squid shape
alien_b.png 64 × 24 2 frames side by side wider crab shape
alien_c.png 96 × 20 2 frames side by side (48px each) flying saucer shape
bullet_player.png 4 × 16 Thin bright rectangle green or white
bullet_enemy.png 8 × 16 2 frames (4px each) zigzag red lines
barrier.png 24 × 18 Arch/bunker shape bright green
explosion.png 128 × 32 4 frames (32px each) circles getting bigger then fading
⚠️

Important!

Sprite sheets (like alien_a.png) have BOTH frames side by side in ONE file.

So alien_a.png is 64px wide (2 frames × 32px each) and 24px tall.

When you set up the AnimatedSprite2D in Godot, set HFrames to 2.

Assigning images in Godot:

1. Open the Player scene. Click the Sprite2D node.

2. In the Inspector, drag your player.png onto the Texture slot.

3. Do the same for Barrier (drag barrier.png onto its Sprite2D).

4. For Alien: click the AnimatedSprite2D, then click SpriteFrames in Inspector.

5. In the animation editor, drag alien_a.png into the 'a' animation. Set HFrames to 2.

6. Do the same for 'b' (alien_b.png) and 'c' (alien_c.png).

7. For Explosion: open its AnimatedSprite2D, drag explosion.png into 'explode'. Set HFrames to 4.

Now the collision checking. This uses simple maths to check if two rectangles overlap:

# Main.gd part 4: collision checking

# Returns true if two rectangles overlap

# ap/bp = centre positions ah/bh = half-sizes

func _overlaps(ap: Vector2, ah: Vector2, bp: Vector2, bh: Vector2) -> bool:

return (abs(ap.x - bp.x) < ah.x + bh.x and

abs(ap.y - bp.y) < ah.y + bh.y)

func _check_collisions() -> void:

for bullet in bullets_node.get_children():

if not is_instance_valid(bullet):

continue

var bpos = bullet.global_position

var bhalf = Vector2(3, 8)

if not bullet.is_enemy:

# Player bullet vs aliens

for alien in get_tree().get_nodes_in_group("aliens"):

if not is_instance_valid(alien): continue

if _overlaps(bpos, bhalf, alien.global_position, Vector2(14, 10)):

GameState.score += alien.points

GameState.hi_score = max(GameState.score, GameState.hi_score)

alien.die()

if is_instance_valid(bullet): bullet.queue_free()

_refresh_hud()

break

# Player bullet vs barriers

for bar in get_tree().get_nodes_in_group("barriers"):

if is_instance_valid(bar) and _overlaps(bpos, bhalf, bar.global_position, Vector2(11,8)):

bar.hit()

if is_instance_valid(bullet): bullet.queue_free()

break

else:

# Enemy bullet vs player

if player._alive and _overlaps(bpos, bhalf, player.global_position, Vector2(18,12)):

player.die()

if is_instance_valid(bullet): bullet.queue_free()

# Enemy bullet vs barriers

for bar in get_tree().get_nodes_in_group("barriers"):

if is_instance_valid(bar) and _overlaps(bpos, bhalf, bar.global_position, Vector2(11,8)):

bar.hit()

if is_instance_valid(bullet): bullet.queue_free()

break

Fixing common errors

If the game doesn't run, don't panic. Here's how to fix the most common problems:

Error message says... What to do
Expected indented block A function body is empty add a tab and type pass on a new line inside it.
Expected end of statement You have a typo on that line look for a missing colon : or bracket.
Identifier not declared You used a variable name that doesn't exist check your spelling.
Could not preload The scene file path is wrong check the file name matches exactly.
Invalid get index on null You used a node that doesn't exist check the node name in the scene tree.
⚠️

Tabs vs spaces

GDScript ONLY works with tabs for indentation not spaces.

If you copied code from somewhere and used spaces, replace them with tabs.

In Godot's editor, pressing Tab inserts a proper tab character.
