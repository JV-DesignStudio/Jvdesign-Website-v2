📋 Roblox Studio Cheat Sheet

🖱️ Viewport Navigation

Orbit cameraRight Mouse Button + drag
Move cameraW A S D (while right mouse held)
ZoomScroll Wheel
Focus on partSelect part, press F
Pan up/downQ / E (while right mouse held)

🧱 Building Tools

MoveR-key tool or Move tool (1)
ScaleScale tool (2)
RotateRotate tool (3)
Insert a PartHome tab → Part
Group selectionCtrl + G
UngroupCtrl + Shift + G
DuplicateCtrl + D

▶️ Testing

Play (test as one player)F5 or Play button
Play here (spawn at camera)F7
Stop testingShift + F5
Enter a VehicleSeatWalk into it / press E

📜 Script Types

ScriptRuns on the server — game logic, damage, scoring
LocalScriptRuns on each player's device — GUI, camera, input
ModuleScriptReusable code shared between other scripts
Where scripts runServerScriptService, or inside Parts/Models

💾 General

Save placeCtrl + S
Publish to RobloxFile → Publish to Roblox
UndoCtrl + Z
Open Output windowView → Output (shows script errors)
