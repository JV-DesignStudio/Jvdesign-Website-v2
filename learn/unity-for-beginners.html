Unity for Beginners

Unity is a friendly way to make real 2D and 3D games. These free step-by-step workshops start with a game you can finish in one sitting, then build up to bigger projects. You install the free Unity editor once, then follow along. No account is needed to start.

Stardust says: start with one small game you can play today. Make My First Unity Game, press play, and you have made something real.
