Best Free Game Making Tools for Kids

There has never been a better time to make games for free. These are the tools we would recommend to a child or a classroom, sorted so you can find the right fit by age and interest. Everything here can be started without paying, and most of it runs right in a browser.

Stardust says: start with the tool that matches what they already love. Scratch for the youngest, Minecraft or Roblox if they already play those, then a real engine when they are ready.
